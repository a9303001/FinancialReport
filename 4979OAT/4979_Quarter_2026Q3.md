- `（１）当四半期連結累計期間の経営成績の概況` 

```
 当第３四半期連結累計期間（2026年１月１日～2026年９月30日）におけるわが国経済は、雇用・所得環境の改
善、インバウンド需要や設備投資意欲の継続などを背景に、緩やかな回復基調が続きました。一方で、中東情勢を
はじめとする地政学リスクや自然災害の影響、金融資本市場の変動など、外部環境の不確実性から依然として先行
き不透明な状況が続いております。
```

```
 このような経営環境のもと、当第３四半期連結累計期間の売上高は260億51百万円（前年同四半期比24億45百万
円増加、同10.4％増）、営業利益は34億47百万円（前年同四半期比４億７百万円増加、同13.4％増）、経常利益は
32億７百万円（前年同四半期比１億99百万円増加、同6.6％増）、親会社株主に帰属する四半期純利益は20億20百
万円（前年同四半期比77百万円増加、同4.0％増）となりました。
```

 農薬分野においては、国内市場では、当社主力製品の病害虫防除資材「ハチハチ」「ダニサラバ」「オンコル」

た。一方、「オンコル」「カリグリーン」は売上高が前年同期比で減少いたしました。それらの結果、農薬分野全体
の売上高は95億97百万円（前年同四半期比４億84百万円増加、同5.3％増）となりました。
```

```
 肥料・バイオスティミュラント分野において、国内市場では「ハウス肥料」「養液土耕肥料」等の販売が好調と

結果、肥料・バイオスティミュラント分野等の売上高は164億53百万円（前年同四半期比19億60百万円増加、同
13.5％増）となりました。
