## 2. 三句話看懂（白話總結）

1. **這家公司在賺什麼錢**：春泉是一檔在香港上市的「收租基金」，手上只有兩大核心資產——北京市中心長安街東端的兩棟超甲級辦公大樓（華貿中心寫字樓 1 & 2 座），以及廣東惠州的一座大型指標性購物商場（華貿天地）；主要業務就是把收進來的房租扣掉物業維護與銀行借款利息後，依法將 90% 以上的現金直接分發給投資人。
2. **現在好不好**：現金面非常健康，但帳面會計數字不好看。壞處是北京辦公室市場過去幾年租金一直在降，會計師依規定把大樓估價往下調，導致上半年帳面認列了 3.67 億元人民幣的「非現金跌價損失」，帳面出現虧損；好處是房子租金實打實收進口袋，上半年扣掉維護開銷後賺了 2.05 億元人民幣的物業淨收益，而且辦公室出租率逆勢回升到 91%，宣布發出每股 0.040 港元的現金股息。
3. **最該擔心與期待什麼**：最該擔心的是北京辦公室市場的新增供給何時完全消化，以及有一筆 192 億日圓的銀行借款沒有買匯率保險（如果日圓大幅升值，帳面會有匯兌損失）；最值得期待的是目前股價（1.18 港元）只有真實房產淨值（每股 4.08 港元）的不到三成（打 2.9 折），只要北京租金不再惡化，投資人每年光領近 7% 的現金利息就能立於不敗之地，更享有極大的資產折價收斂空間。

### 6.2 EXTRA_ANALYSIS 五大專案深度剖析（完全解答）

#### 專題 1：每股營業現金流量、每股營運現金流（FFO）與每股調整後營運現金流（AFFO）
> **這段在講什麼**：房託不能看 EPS，要看 FFO 與 AFFO。以下為 2026 H1 完整推導與每單位金額：

1. **每單位營業現金流量（OCF per unit）**：
   - 2026 H1 營運活動淨現金流量 = 175,235 千元人民幣。
   - 每單位 OCF = 175,235,000 ÷ 1,481,041,212 = **0.1183 元人民幣 = 每單位 0.1346 港元**。
   - 年化每單位現金流約 0.27 港元，相對股價 1.18 港元，經營收現倍數僅 **4.4 倍**。
2. **每單位營運現金流（FFO per unit / 可供分派收入）**：
   - 公式還原：會計虧損 (-241,770) + 物業公允價值減損 (+342,869) + 衍生工具虧損 (+53,550) + 管理費以單位支付 (+16,422) + 借款攤銷費用 (+10,922) - 未實現匯兌收益 (-115,109) - 遞延所得稅 (-8,741) = **58,143 千元人民幣**。
   - 每單位 FFO = 58,143,000 ÷ 1,481,041,212 = **0.0393 元人民幣 = 每單位 0.0447 港元**。
3. **每單位調整後營運現金流（AFFO per unit）**：
   - 公式還原：FFO (58,143) - 維持性資本開支 CapEx (2,408) = **55,735 千元人民幣**。
   - 每單位 AFFO = 55,735,000 ÷ 1,481,041,212 = **0.0376 元人民幣 = 每單位 0.0428 港元**。
   - 2026 H1 實際每單位派息 0.0400 港元，**AFFO 對 DPU 的覆蓋率達 107.0%**，現金分派具備 100% 內生盈利支撐。
4. **純現金口徑 AFFO（Cash AFFO）**：
   - 若進一步扣除以單位支付之管理費（16,422 千元人民幣），純現金 AFFO 為 39,313 千元人民幣（每單位 **0.0302 港元**），覆蓋率 75.5%，顯示管理層 80% 費用收取單位的機制有效捍衛了短期現金儲備。

#### 專題 2：所有財務數據換算成每股港幣（匯率傳導與敏感度）
- 全檔所有損益表、資產負債表及現金流量項目均已完成每單位港幣換算（見 §4.3 每股化總表）。
- **匯率傳導效應**：春泉 REIT 資產與租金 100% 收取人民幣，分派與股票交易以港幣計價。
  - 2026 中期分派基準匯率為 `1 HKD = 0.8792 RMB`（即 `1 RMB = 1.1374 HKD`）。
  - 若人民幣兌港幣升值 1%（即 1 RMB 換得更多港幣）：每單位可供分派收入增加約 **+0.00045 港元**（年化約 +0.0009 港元），每單位 NAV 增加約 **+0.041 港元**。人民幣升值對港幣投資人具實質紅利。

#### 專題 3：每年管理費用計算機制與佔淨值（NAV）百分比
依據《信託契約》（Trust Deed），管理人春泉資產管理有限公司收費架構如下：
1. **基本費用（Base Fee）**：
   - **計算方式**：按信託**存置財產價值（總資產）的 0.40% / 年** 計算，按半年支付。
   - **支付方式**：管理人可自行選擇現金或新單位形式。2025 年及 2026 年均選擇 **20% 現金 + 80% 新發行基金單位**。新單位按公告日前 10 個交易日加權平均市價（VWAP）發行。
2. **浮動費用（Variable Fee）**：
   - **計算方式**：按信託每年度**物業收入淨額（NPI）的 3.0% / 年** 計算（扣除基本及浮動費用前），**100% 現金支付**。
3. **處分費用（Divestment Fee）**：處分物業代價的 0.5%（2026 H1 為 0）。
4. **管理費用佔 NAV 百分比精算**：
   - 2026 H1 管理費用總額：**2,678 萬元人民幣（約 3,046 萬港元，每單位 HK$ 0.0206）**。
   - 年化管理費用總額：約 **5,356 萬元人民幣（約 6,092 萬港元）**。
   - 佔 2026-06-30 淨資產（NAV 52.46 億元人民幣）百分比：
     $$\text{管理費佔 NAV 百分比} = \frac{5,356 \text{ 萬元}}{52.46 \text{ 億元}} \times 100\% = \mathbf{1.02\%}$$
   - **歷史對照**：2025 全年為 1.10%（含英國資產處分費 0.11%），2024 年為 0.96%。香港上市房託平均介於 0.8%~1.3%，春泉佔 1.02% 處於市場標準合理水平。

   - **實質持有角度（剩餘營運期累計現金股息）**：
     - 房託的本質是持有期間的持續現金分派。假設未來 25 年平均年化 DPU 維持保守的 **0.08 ~ 0.10 港元**：

## 7. 必備財務指標公式算式與就地還原

> **這段在講什麼**：所有自定義與關鍵指標，把官方財報數字帶入公式，就地算出結果供查核。

1. **負債比率（Debt Ratio，依 AGENTS.md §3.1 規範）**：
   $$\text{負債比率} = \frac{\text{負債總額}}{\text{總資產}} \times 100\% = \frac{5,158,183 \text{ 千元}}{11,396,987 \text{ 千元}} \times 100\% = \mathbf{45.26\%}$$
   - *判讀*：上年末為 44.74%，半年微增 0.52 個百分點，主因總資產因物業減損縮水，負債比率仍處健康安全區間。
2. **資本負債比率（Gearing Ratio，房託守則口徑）**：
   $$\text{資本負債比率} = \frac{\text{計息借貸總額}}{\text{總資產}} \times 100\% = \frac{4,487,218 \text{ 千元}}{11,396,987 \text{ 千元}} \times 100\% = \mathbf{39.37\%} \quad (\approx \mathbf{39.4\%})$$
   - *判讀*：2025 年末為 39.3%，維持穩定，距離 50% 法定上限有 10.63 個百分點之安全邊際。
3. **自定義 OPM（依 AGENTS.md §3.2 規範）**：
   $$\text{OPM} = \frac{\text{營業利益率}}{\text{稅前淨利率}} \times 100\%$$
   - 2026 H1 核心營業利益率 = 193,656（扣減損前經營利益）÷ 289,617 = 66.87%
   - 2026 H1 稅前淨利率 = -247,224 ÷ 289,617 = -85.36%
   - 代入公式：`66.87% ÷ (-85.36%) * 100%` = **-78.34%**。
   - *判讀*：因非現金物業減損導致稅前利潤為負，此指標發生數學失真。
4. **股價淨值比（P/B Ratio）**：
   $$\text{P/B} = \frac{\text{現行股價}}{\text{每單位資產淨值 NAV}} = \frac{\text{HK\$ } 1.180}{\text{HK\$ } 4.080} = \mathbf{0.2892 \text{ 倍}} \quad (\approx \mathbf{0.289 \text{ 倍}})$$
   - *判讀*：相較於資產淨值折價幅度高達 `(1 - 0.2892) * 100%` = **71.08%**。
5. **租金報酬率（Gross Cap Rate）**：
   $$\text{租金報酬率} = \frac{\text{年化租金營收}}{\text{投資物業總估值}} = \frac{289,617 \times 2}{10,714,730} = \frac{579,234}{10,714,730} = \mathbf{5.405\%} \quad (\approx \mathbf{5.40\%})$$
   - *判讀*：物業毛租金回報率達 5.40%，明顯高於其整體融資借貸成本 4.10%，形成正向利差 Carry。
