## 2. 三句話看懂（白話總結）

1. **這家公司在賺什麼錢**：它是一檔在香港掛牌的「收租基金」，只有兩塊資產——北京市中心的兩棟高級辦公大樓，和廣東惠州的一座大型購物中心。收到房租、扣掉開銷和銀行利息後，把剩下的九成發現金給投資人。
2. **現在好不好**：不好。上半年房租收入比去年同期少了一成，發給投資人的錢直接砍掉快一半（每單位由 7.6 港仙降到 4.0 港仙）。更要留意的是，**這 4.0 港仙裡面有大約 1.3 港仙，是因為管理公司今年同意「不要現金、改拿基金單位」才省下來的**——等於是多印單位給管理公司，換錢發給你，你手上那一股會被稀釋。
3. **最該擔心與期待什麼**：最該擔心的是「便宜」可能是假象——帳面說每單位值 4.08 港元、股價只要 1.22 港元，但北京那塊地 2053 年到期、惠州那塊 2048 年到期，把年期折現進去後每單位實質只值大約 1.87 港元，折價一下子從七折變成三成五。可以期待的是北京辦公室出租率已經回升到 91%、比北京 CBD 同業好，而且管理公司從 8 月下旬起天天在市場上買回自家單位。

## 3. 投資亮點與風險速覽（1-Page Summary）

> **這段結論**：利多利空同時存在，但**利空的每單位金額明顯大於利多**。最大的問題不是「賺不賺錢」，而是「發出去的錢是不是真的賺來的」以及「帳面資產值不值這個價」。

### 🔴 核心風險（依每單位影響幅度排序）

- 🔴 **[帳面資產價值被土地年期高估]** 🆕：北京物業土地使用權 2053-10-28 到期（剩 27.3 年）、惠州 2048-02-01 到期（剩 21.6 年）。把估值按剩餘年期折現後，**每單位實質淨值約 HK$ 1.87，而非帳面的 HK$ 4.08，每單位縮水 −HK$ 2.24（−54.8%）**（結構性，一次調整）。　重要性：極高　資料日期：2026-06-30　※本檔自算，非官方數字，推導見 §6.7
- 🔴 **[分派有三分之一靠稀釋撐起來]** 🆕：1H2026 分派總額 RMB 5,233 萬元，其中 RMB 1,642 萬元（**每單位 HK$ 0.0129，佔 DPU 的 32.2%**）是「管理費改用基金單位支付」省下來的現金。**若管理費全付現金，(營業現金流 − 現金利息 − 資本支出) ÷ 分派 = 0.95 倍，發不出來**（常態性，年年都有）。　重要性：極高　資料日期：2026-08-20
- 🔴 **[分派金額腰斬，且還沒止跌]** 🆕：1H2026 DPU **HK$ 0.040**，年減 47.4%（1H2025：HK$ 0.076）。同時派息率由 100% 降為 **90%**，等於「可分派金額變少 × 分得比例也變少」雙重打擊。**每單位少領 HK$ 0.036，佔前一年同期 DPU 的 −47.4%**（常態性）。　重要性：極高　資料日期：2026-08-20

- 🔴 **[日圓借款無避險，7–8 月已再度浮虧]** 🔄：JPY 192.2 億元無避險借款（每單位 HK$ 0.6189）。自 6/30 至 9/3，人民幣兌日圓由 24.35 貶到 23.22（日圓升值 4.9%），**帳面再增匯損約 RMB 3,835 萬元＝每單位 −HK$ 0.0301**（非現金，但直接扣淨值）。日圓兌人民幣每再升 1%，每單位再減 **HK$ 0.0065**。　重要性：中　資料日期：2026-09-03

## 6. 基本面七大支柱與專題分析

### 6.1 支柱一：賺什麼錢（商業模式）

> **這段結論**：兩塊資產、兩個中國城市、一種收入——房租。**沒有第三條腿，任一資產出事就是全公司出事。**

- **北京華貿中心 1 & 2 座辦公樓（CCP Property）**：總樓面 120,245 ㎡（含 25,127 ㎡ 車位），187 個租約，超過一半面積租給外商。1H2026 收益 RMB 1.7616 億元（**每單位 HK$ 0.1381**），佔 60.8%；NPI 約 RMB 1.276 億元（**每單位 HK$ 0.1000**）。
- **惠州華貿天地購物中心（68% 權益）**：總樓面 144,925 ㎡，548 個租約。1H2026 收益 RMB 1.1346 億元（**每單位 HK$ 0.0890**），佔 39.2%；NPI 約 RMB 7,743 萬元（**每單位 HK$ 0.0607**）。
- **英國組合已於 2025 年 3 月全數出售**，FY2026 起收入歸零——上一版還在追蹤的英國部分，本輪依 §7.3 刪除。
- **客戶集中度**：CCP 前五大租戶佔已出租樓面 **21.4%**（Epson 5.8%、中德證券 4.4%、環球律師事務所 4.3%、德事商務中心 4.1%、中倫文德 2.8%）；惠州前五大業種僅佔 **11.1%**。**判讀：辦公樓端有一定集中度，但 21.4% 分散在五家不同產業，尚屬健康；購物中心端非常分散。**

> **所以呢**：買這檔＝押注「北京 CBD 辦公室不再更差 ＋ 惠州消費不掉下來」。**這兩件事你要自己有看法，不能靠管理人。**

> **這段結論**：物業層面很會賺（NPI 利潤率 70.8%，環比還在回升），但**賺到的錢有一半被利息拿走**。

### 6.3 支柱三：賺的是不是真的（獲利品質）⭐ 本輪最重要的一段

> **這段結論**：**表面上分派有現金支撐，實際上有三分之一是靠稀釋來的。這是本輪推翻前一版結論的地方。**

**（1）先看「表面」——純現金覆蓋率，看起來很好**

```
可用現金 = 營業現金流 175,235 − 現金利息 106,447 − 資本支出 2,408 = RMB 66,380 千元
覆蓋率  = 66,380 ÷ 分派 52,329 = 1.27 倍   ✅ 看起來覆蓋得住
```

**（2）再看「真相」——如果管理費全部付現金會怎樣**

管理人今年選擇 **Base Fee 的 80% 改領基金單位、只領 20% 現金**。這 RMB 1,642 萬元的費用沒有付出現金，所以現金流看起來變好了。但**代價是多印了單位給管理人**——你的持股被稀釋。

```
若管理費全額付現金：
可用現金 = 66,380 − 16,422 = RMB 49,958 千元
覆蓋率  = 49,958 ÷ 52,329 = 0.95 倍   ❌ 發不出來
```

**（3）換算成每單位**

```
以單位支付的管理費 = RMB 16,422 千元 ÷ 1,488,500,230 個 × 1.1670 = 每單位 HK$ 0.01288
佔 DPU 比重 = 0.01288 ÷ 0.040 = 32.2%
```

### 6.5 支柱五：還能不能長大（成長性）

> **這段結論**：**過去五年是一路縮小，不是成長。** 唯一的成長選項是管理人自己說的「資產回收」。

> **所以呢**：**別期待有機成長。** 這檔的上漲催化劑只有三種：賣資產、私有化、或北京租金週期反轉。三種都不在管理人可控範圍。

### 6.7 支柱七：現在買貴不貴（評價）⭐ 含 EXTRA_ANALYSIS 第 4 題

> **這段結論**：**帳面看是三折，實際上比較接近六五折。** 而且估值本身還內含一個很樂觀的假設。

**（A）三種 P/B，差很多**

| 口徑 | 每單位淨值（HKD） | P/B（現價 1.220） | 說明 |
| :--- | ---: | ---: | :--- |
| 官方帳面 | **4.08** | **0.299 倍** | 2026-06-30，官方數字 |
| 本檔重算（最新單位數 × 9/3 匯率） | **4.113** | 0.297 倍 | 分子仍為 6/30 淨值，**未含 2H2026 可能的新減值** |
| **土地年期折現後（本檔推估）** | **1.871** | **0.652 倍** | 🔴 見下方推導 |

**（B）土地使用權到期問題（EXTRA_ANALYSIS 第 4 題）**

*土地年期還剩多久？*
- 北京 CCP：50 年期，**2053-10-28 到期**，自 2026-09-03 起剩 **27.15 年**。
- 惠州華貿天地：40 年期，**2048-02-01 到期**，剩 **21.42 年**。

*為什麼這件事很重要？*
估價師（仲量聯行，JLL）用 **income approach**（把未來租金收益用資本化率折算成現值），CCP 用 4.5%、惠州用 6.5% 的資本化率。**一個 4.5% 的資本化率，數學上等於假設這棟樓「永遠」都能收租**。但土地只剩 27 年，27 年後這棟樓在法律上不再屬於基金。

*量化（本檔自算，⚠️ 這是推估、可能不準）*

```
27.15 年期的收益現值 ÷ 永續收益現值 = 1 − (1+4.5%)^(−27.33) = 69.97%
21.42 年期的收益現值 ÷ 永續收益現值 = 1 − (1+6.5%)^(−21.59) = 74.32%

調整後 CCP 估值   = RMB 78.63 億元 × 69.97% = RMB 55.02 億元（−RMB 23.61 億元）
調整後 惠州估值   = RMB 28.55 億元 × 74.32% = RMB 21.22 億元（−RMB 7.33 億元，本基金佔 68% ＝ −RMB 4.98 億元）
歸屬單位持有人淨值 = 52.456 − 23.61 − 4.98 = RMB 23.859 億元
每單位 = 2,385,863 千元 ÷ 1,488,500,230 × 1.1670 = 每單位 HK$ 1.871
```

> ⚠️ **重大保留**：本檔**無法確認 JLL 是否已在估值中反映有限年期**。如果 JLL 已經做了年期調整，上面這個 −54.5% 的折減就不成立。中期報告只揭露「income approach + 資本化率 4.5%／6.5%」，未揭露現金流年期假設。**這是本檔最大的單一不確定性，已列入 §11 下一輪優先查證項目。**

*續期要花多少錢？（推估，可信度低）*
中國《民法典》第 359 條規定：住宅用地自動續期，**非住宅（商服）用地續期「依照法律規定辦理」**——也就是沒有自動續期，要申請並補繳出讓金。北京採用「基準地價」制度（京政發〔2022〕12 號；應用規則見京規自發〔2024〕236 號），但**基準地價數值表本輪仍未取得**。

以「續期成本 ＝ 物業估值 × 土地價值佔比 × 續期折扣率」粗估：

| 物業 | 估值（RMB 億元） | 土地價值佔比（假設） | 續期折扣率（假設） | 續期成本（RMB 億元） | **每單位（HKD）** |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 北京 CCP | 78.63 | 45% | 40% | 14.15 | **1.109** |
| 惠州（×68%） | 28.55 | 35% | 40% | 2.72 | **0.213** |
| **合計** | | | | **16.87** | **約 HK$ 1.32** |

> **⚠️ 這是推估、可能不準**：土地價值佔比與續期折扣率均為本檔假設，非官方數字。**續期成本約當每單位 HK$ 1.32，是現價 HK$ 1.220 的 108%。**

*如果無法續期，每單位能拿回多少？*
依中國現行法律，非住宅建設用地使用權期滿若未獲續期，**土地及地上建築物歸國家所有，補償方式由屆時的法律規定，目前並無明確的補償標準**。最保守情境下：
```
屆時可回收 = 非物業資產（現金＋受限結餘）− 有息負債
2026-06-30 口徑 = 0.1977 + 0.2927 − 3.5180 = 每單位 −HK$ 3.028（為負數）
```
> **白話**：**若完全無法續期且無補償，理論上每單位不但拿不回錢，還會是負值**（因為借款高於非物業資產）。實務上這是 2048／2053 年的事，而借款 2028 年就到期、屆時會再融資，所以這個數字是**極端情境的下限**，不是預測。**真正的風險不是「歸零」，而是「隨著年期逐年縮短，估值會被逐年壓縮」。**

**（C）估值的另一個樂觀假設：資本化率 vs 實際 NPI**

```
估價師加權資本化率 = (78.63 × 4.5% + 28.55 × 6.5%) ÷ 107.18 = 5.03%
實際年化 NPI 報酬率 = 205,027 × 2 ÷ 10,718,000 = 3.83%
→ 落差 1.20 個百分點，等於估值內含「NPI 要再漲 31%（5.03 ÷ 3.83 − 1）才對得上」的假設
```
若估價師改用當前實際 NPI 搭配同樣的資本化率：
```
CCP  ：127,600 × 2 ÷ 4.5% = RMB 56.71 億元（−27.9%）
惠州 ：77,430 × 2 ÷ 6.5% = RMB 23.82 億元（−16.6%）
歸屬淨值 = 52.456 − 21.92 − 3.22 = RMB 27.32 億元 → 每單位 HK$ 2.142
```
> **所以呢**：三種算法給出三個答案——**HK$ 4.11（帳面）／HK$ 2.14（用實際 NPI 重估）／HK$ 1.87（用土地年期折現）**。現價 HK$ 1.220 對這三個數字分別是 0.30 倍／0.57 倍／0.65 倍。**「便宜」是真的，但沒有帳面看起來那麼誇張，而且需要能承受估值繼續往下修。**

**（D）同業對照（2026-09-03）**

### 6.8 專題：管理費怎麼算、佔淨值多少（EXTRA_ANALYSIS 第 3 題）

> **這段結論**：管理費按**總資產**收，不是按淨值收。因為有 39.4% 的槓桿，等於投資人實際負擔的比率被放大了一倍以上。

**（1）費用結構（依 Trust Deed）**

| 費用項目 | 計算基礎 | 費率 | 支付方式（2026 年管理人選擇） |
| :--- | :--- | :--- | :--- |
| **Base Fee** | Deposited Property（＝存託資產，實務上約當總資產） | **0.4%／年** | **現金 20%、基金單位 80%** |
| **Variable Fee** | Net Property Income（NPI，扣費用前） | **3.0%／年** | 全部現金 |
| Divestment Fee | 出售資產對價 | 0.5% | 一次性（2025 年出售英國組合時已收） |

**（2）驗算（1H2026）**

```
Base Fee 理論值     = 總資產 RMB 113.97 億元 × 0.4% ÷ 2 = RMB 2,279 萬元
Variable Fee 理論值 = NPI RMB 2.0503 億元 × 3.0%        = RMB   615 萬元
理論合計                                                 = RMB 2,894 萬元
實際入帳                                                 = RMB 2,678 萬元（差 7.5%，因 Deposited Property 定義略窄於總資產）
```

**（3）佔淨值多少？**

```
年化管理費 = 2,678 萬 × 2 = RMB 5,356 萬元
÷ 歸屬單位持有人淨值 RMB 52.456 億元 = 1.02%／年
每單位     = 53,556 千元 ÷ 1,488,500,230 × 1.1670 = 每單位 HK$ 0.0420／年
佔年化 DPU（HK$ 0.080）比重 = 52.5%
```

**（4）為什麼「按總資產收」對投資人不利**

```
總資產 RMB 113.97 億元，其中淨值只有 RMB 52.456 億元（46.0%）
→ 0.4% 的總資產費率，換算成淨值口徑 = 0.4% ÷ 46.0% = 0.87%／年（再加 Variable Fee 才是 1.02%）
→ 白話：公司多借錢、資產做大，管理人就多拿錢，即使投資人的淨值沒有變大
```

**（5）管理人持股一路增加**
管理人（春泉資產管理）持有的單位由 2025 年底的 66,513,342 個增至 2026-06-30 的 **78,718,994 個（半年 +18.4%，佔在外單位 5.31%）**——**全部是拿管理費換來的，不是自己掏錢買的。**

> **所以呢**：**這是本檔僅次於土地年期的第二大結構性負面。** 管理費以單位支付，看起來省了現金、實際上是把成本轉嫁成你的股權稀釋，而且這個機制**每年由管理人自己選**（Trust Deed 允許）。

### 6.9 專題：EPS 什麼時候會轉正（EXTRA_ANALYSIS 第 5 題）

> **這段結論**：**帳面 EPS 轉正的唯一條件是「物業重估減損縮小到某個門檻以下」。本檔推估最可能在 FY2028，樂觀情境 FY2027。**

**（1）先算門檻**

```
1H2026 帳面虧損（歸屬）        = RMB −24,177 萬元

   帳面 EPS 就會轉正。折算 = 佔投資物業 RMB 107.15 億元的 1.72%／年。
```

| :--- | ---: | ---: | :-: |

| :--- | :--- | ---: | ---: | :--- |

## 7. 必備財務指標的公式與就地還原

> **這段結論**：所有自訂指標都攤開寫，讓你可以自己按計算機驗算。

**（1）負債比率**
```
負債比率 = 負債 ÷ 總資產 × 100%
        = 5,158,183 ÷ 11,396,987 = 45.26%
（若將非控制權益 RMB 993,234 千元併入外部求償權：(5,158,183 + 993,234) ÷ 11,396,987 = 53.97%）
```

## 9. 流通單位數變化分析（過去二年）

> **這段結論**：單位數兩年只增加 2.0%，看似無害，**但它的成因才是問題——增發全部用來付管理費**。

| 時點 | 已發行單位（不含庫存） | 較前期變化 | 主要成因 |
| :--- | ---: | ---: | :--- |
| 2024-12-31 | 1,459,041,125 | — | — |
| 2025-12-31 | 1,477,981,560 | **+18,940,435（+1.30%）** | 發新單位付管理費 +2,117.7 萬個；回購 −176.2 萬個 |
| 2026-06-30 | 1,481,041,212 | **+3,059,652（+0.21%）** | 新發 526.5 萬個付管理費；回購 957.9 萬個（持作庫存）；轉售庫存 737.4 萬個付管理費 |
| 2026-09-03 | **1,488,500,230** | **+7,459,018（+0.50%）** | 8 月以新發＋轉售庫存付管理費約 770 萬個；8/21–9/3 回購 106.2 萬個 |
| **合計（2024-12-31 → 2026-09-03）** | | **+29,459,105（+2.02%）** | |

**分析**
1. **兩年僅增 2.02%，未達 AGENTS.md 的 10% 門檻**，但成因值得警覺。
2. **每一次增發都是為了付管理費，沒有一次是為了買資產**。也就是說，稀釋沒有換來任何新的收益來源。
3. **回購並未註銷，而是「持作庫存單位」**——庫存單位日後可再轉售給管理人抵費用（8 月就發生了）。**這代表回購對每單位價值的提升效果會被打折。**
4. **對 EPS 與 DPU 的影響量化**：
```
若過去兩年完全不增發，現有單位數 = 1,459,041,125 個
1H2026 分派 RMB 52,329 千元 ÷ 1,459,041,125 = 每單位 RMB 0.03586（＋2.02%）
→ 稀釋使 1H2026 每單位分派少約 RMB 0.00071 = 每單位 −HK$ 0.00083（約當 DPU 的 −2.1%）
```
5. **回購 vs 稀釋，誰贏？** 9 月每日回購 8 萬個單位，而 8 月單月因管理費發行約 770 萬個。**以此速度需連續回購約 96 個交易日，才能抵銷 8 月一個月的稀釋。**

> **所以呢**：**別把「連日回購」當成強力護盤訊號。** 本輪累計回購 106 萬個單位，只有今年 3–4 月那一輪（1,269.6 萬個）的十二分之一，而且回購價一路走低（3 月 HK$ 1.40–1.61 → 6 月 HK$ 1.28–1.29 → 9 月 HK$ 1.165–1.22），**代表過去每一輪回購到現在都是帳面套牢，回購沒有成功托住股價。**
