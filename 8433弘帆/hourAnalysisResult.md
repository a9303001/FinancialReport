## 2. 三句話看懂（完全不用專有名詞）

1. **這家公司在賺什麼錢**：它是全世界最大的髮飾與女孩時尚配件幫人做設計和製造的公司，把髮圈、髮夾、梳子、化妝小鏡子甚至直髮器，大批賣給歐美的量販店巨頭（如美國沃爾瑪 Walmart、Target）和時尚流行小舖。
2. **現在好不好**：過去幾年賺非常多（前三年每年每股賺近 9～10 元，每年配息 5～6 元）；但 **2025 年因為美中貿易戰關稅搖擺與客戶去化庫存，獲利腰斬到每股只賺 3.17 元**。好消息是，**2026 第一季每股已經賺了 1.37 元，而且今年剛發完 4.2 元現金利息，拿利息的年化報酬率接近 8%**。
3. **最該擔心什麼**：**歐美消費氣氛與關稅風險**——如果美國景氣下滑消費者不上街買小飾品，或者關稅又大幅調升，它的生產基地從中國移往越南的陣痛期就會拉長，影響獲利恢復速度。

## 3. 最新結論摘要

> **導讀**：本節提供 8433 弘帆的核心投資論述摘要，包含主要營運亮點、風險警示以及 AGENTS.md 規範之「個股分析必備數據總表」。

### 3.1 核心投資利多（成長動能）
- 🟢 **極高殖利率保護傘（重要性：極高）**：公司長期維持高配息政策，2026 年除息 4.20 元，以目前股價 53.90 元計算，**現金殖利率達 7.79%**，過去 5 年殖利率中位數高達 **7.80%**，在台股上市櫃企業中名列前茅。
- 🟢 **東南亞（越南）產能布局成熟（重要性：高）**：公司積極推動越南北寧省光州工業區基地建置，將傳統髮飾與塑膠產品逐步由中國東莞轉移至越南生產，**有效規避美國對中國產地的 232/301 關稅懲罰**。
- 🟢 **品線延伸至個人護理小家電（重要性：中高）**：從傳統髮飾進軍個人護理電器與美妝電子代工（直髮器、捲髮器、吹風機、LED 美妝鏡、膠囊咖啡機等一站式生產鏈），拉高產品附加價值與單價。

### 3.2 核心風險與隱憂
- 🔴 **顧客集中與歐美零售景氣敏感（重要性：高）**：主要客戶為美系實體零售通路與快時尚巨頭（Walmart、Target、Claire's 等），當美國通膨加劇、消費者口袋收緊或零售商啟動降價逼迫供應商時，弘帆毛利率將面臨直接壓力。
- 🔴 **產能移轉初期成本墊高與毛利率波動（重要性：高）**：2025 年毛利率由 2024 年的 26.68% 下降至 23.30%，稅後淨利率降至 4.96%，主因雙基地營運初期固定成本與管理費用負擔較重。
- 🔴 **匯率全曝險**：外銷占比逾 **90%**，營收與應收帳款主要以美元計價，新台幣大幅升值時易產生重估匯損（如 2025 年業外即受到一定程度匯損侵蝕）。

## 4. 計算與拆解（每項可自行還原）

> **導讀**：本節將報告中所有每股化金額與財務指標之計算式完整攤開，供比對還原。

### 4.1 每股化股數基準
```
實收股本 = 545,062,000 元
面額 = 10 元
在外流通股數 = 545,062,000 ÷ 10 = 54,506,200 股 = 54,506 千股

全檔統一採用分母：54,506 千股
```

### 4.2 FY2025 全年每股化（合併財報）
```
營業收入 = 3,483,816 千元  → 每股營收 = 3,483,816 ÷ 54,506 = 63.92 元
營業毛利 =   811,692 千元  → 每股毛利 =   811,692 ÷ 54,506 = 14.89 元（毛利率 23.30%）
營業淨利 =   353,697 千元  → 每股營利 =   353,697 ÷ 54,506 =  6.49 元（營益率 10.15%）
稅前淨利 =   233,671 千元  → 每股稅前 =   233,671 ÷ 54,506 =  4.29 元（淨利率  6.71%）
本期淨利 =   172,700 千元  → 每股純益 =   172,700 ÷ 54,506 =  3.17 元（母公司業主 EPS 3.17 元）
```

### 4.3 負債比率計算
```
【公式】負債比率 = 負債總額 ÷ 資產總額 × 100%

FY2024: 2,492,028 ÷ 4,809,796 × 100% = 51.81%
FY2025: 2,154,233 ÷ 4,295,005 × 100% = 50.16%
2026Q1: 2,168,410 ÷ 4,293,880 × 100% = 50.50%
```

### 4.4 OPM（自定義）計算
```
【公式】OPM = 營業利益率 ÷ 稅前淨利率 × 100%

FY2024: 13.65% ÷ 18.76% × 100% =  72.76%  （業外收益 +1.85 億元加分）
FY2025: 10.15% ÷  6.71% × 100% = 151.27%  （業外損失 −1.20 億元扣分）
2026Q1:  7.42% ÷  9.85% × 100% =  75.33%  （業外收益重新轉正加分）
```

### 4.5 過去五年 ROE 中位數與年序
```
FY2021:  8.90%
FY2022: 20.80%
FY2023: 19.50%
FY2024: 21.90%
FY2025:  6.92%

排序：6.92% -> 8.90% -> 19.50% -> 20.80% -> 21.90%
中位數（第 3 位）：19.50%
```

### 4.6 未來三年 EPS 模型推估（FY2026E–FY2028E）
```
【FY2026E】
營收預估 = 36.5 億元（年增約 +4.8%）
淨利率預估 = 7.76%
稅後淨利 = 36.5 億 × 7.76% = 2.83 億元 (283,200 千元)
預估 EPS = 283,200 ÷ 54,506 = 5.20 元

【FY2027E】
營收預估 = 39.0 億元（越南產能全面開出，個人護理電器放量）
淨利率預估 = 8.11%
稅後淨利 = 3.16 億元
預估 EPS = 316,000 ÷ 54,506 = 5.80 元

【FY2028E】
營收預估 = 42.0 億元
淨利率預估 = 8.43%
稅後淨利 = 3.54 億元
預估 EPS = 354,000 ÷ 54,506 = 6.50 元
```

## 7. 名詞對照表（Glossary）

| 術語 | 全名（原文） | 一句白話解釋 |
| :-- | :-- | :-- |
| **ODM / OEM** | Original Design / Equipment Manufacturer | 受託設計製造／原廠委託代工。客戶給品牌，弘帆負責研發與製造 |
| **EPS** | Earnings Per Share（每股盈餘） | 公司一年幫每一股股票賺進多少台幣 |
| **本益比（PE）** | Price-to-Earnings Ratio | 股價 ÷ 每股盈餘。買進股票後靠獲利幾年能回本 |
| **trailing PE** | Trailing Price-to-Earnings | 用已經發生的近四個季度（過去 12 個月）獲利計算的本益比 |
| **Forward PE** | Forward Price-to-Earnings | 用預估未來的年度獲利算出的本益比 |
| **BPS** | Book Value Per Share（每股淨值） | 公司總淨資產扣除負債後分攤到每一股的金額 |
| **ROE** | Return on Equity（股東權益報酬率） | 股東投資的每一百元資本，公司一年能創造多少淨利 |
| **OPM** | 營業利益率 ÷ 稅前淨利率 × 100% | 本檔自定義指標，>100% 代表業外虧損扣分，<100% 代表業外收益加分 |
| **負債比率** | Debt Ratio | 負債總額 ÷ 資產總額 × 100%。評估公司財務槓桿與風險 |
| **殖利率** | Dividend Yield | 現金股利 ÷ 股價 × 100%。單純領配息的年化報酬率 |
| **8433.TW** | 弘帆股份有限公司 | 台灣證券交易所上市公司，代號 8433 |
