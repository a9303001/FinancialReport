# CBRE、「ジャパンロジスティクスマーケットビュー2026年第3四半期」発表

## 首都圏の空室率7.7％、6四半期連続の低下　賃料は対前期比＋1.3％、4四半期連続の上昇

CBRE（シービーアールイー株式会社）｜2026年10月28日 14時00分（PR TIMES 配信）

シービーアールイー株式会社は、本日「ジャパンロジスティクスマーケットビュー 2026年第3四半期」を発表しました。

**ポイント**

1. 首都圏大型マルチテナント型物流施設（LMT）空室率は7.7％、対前期比0.1ポイント低下。新規供給7棟の竣工時稼働率は5割を超え、新規需要は過去3番目の高水準。地域別では神奈川県で過去最大の新規需要を記録。実質賃料は全体では4,660円／坪、対前期比1.3％上昇。幅広いエリアで賃料が上昇している。
2. 近畿圏LMTの空室率は2.7％、対前期比0.3ポイント上昇。新規供給2棟の竣工時稼働率は5割で、既存の複数物件で空室が消化された。実質賃料は4,440円／坪、対前期比1.1％上昇。中心部で賃料上昇が継続していることに加えて、郊外立地での賃料の底上げもみられた。
3. 中部圏LMTの空室率は14.9％、対前期比1.0ポイント低下。新規供給はなく、既存物件では前期竣工の1棟が満床となるなど空室消化が進んだ。実質賃料は3,740円／坪、対前期比で横ばい。
4. 福岡圏LMTの空室率は11.9％、対前期比0.5ポイント上昇。新規供給2棟のうち1棟が満床で竣工した。今後の大量供給により、空室率は当面上昇傾向で推移する見通し。実質賃料は3,570円／坪、対前期比横ばい。
