`3. 本取得及び本譲渡の理由`

```
 本投資法人は、2026年7月期（第19期）決算発表時に公表した今後の成長戦略のもと、インフレ耐性
強化を目的としたポートフォリオのさらなる強靭化に取り組んでいます。今般の資産入替は、こうした取
組みを着実に推進するものであり、インフレ耐性の強化へ寄与する資産を組み入れる一方、収益の成長余
地が限定的な資産を売却することで、さらなるポートフォリオの進化につながるものと考えています。
 取得予定資産である「ホテルプラスホステル札幌」及び「ホテルプラスホステル東京秋葉原」は、いず
れもドミトリー（注）・個室など多彩な客室タイプを融合したハイブリッド型の宿泊施設です。多様な宿
泊ニーズの取り込みによる稼働の安定化と、限られた面積の中に多くのベッドを高密度かつ無駄なく配置
できる高効率な収益構造を特徴としています。両物件はいずれも変動賃料を採用しており、札幌及び東京
の都心部という恵まれた立地環境を活かすことにより、インフレ環境下において、ポートフォリオへのさ
らなるアップサイドをダイレクトに取り込むことを目指します。
```

```
 一方、譲渡予定資産である「ケーズデンキおゆみ野店（底地）」については、長期の固定賃料契約であ
```
