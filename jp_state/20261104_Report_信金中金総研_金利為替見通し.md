###### ~~`足元の金利・為替環境`~~

###### `主要中銀は揃って連続利上げを回避、ＡＩ株安によるリスクオフムードで長期金利は高水準`

```
10月は日米欧のいずれの中央銀行も連続利上げを避け、金利を据え置いた。依然としてインフレ圧
力は根強いものの、累積的な利上げの影響確認など現状把握を優先する考えだ。なお、金利据え置き
は市場に織り込まれており、サプライズはなかった。この間、米国の新興ＡＩ関連企業の信用状況悪
化をきっかけに、ＡＩ関連投資の是非について懸念が高まると、ハイテク株を中心とした売り圧力が
高まり、リスクオフ相場に転換した。株安、債券高といった地合いのなかで長期金利は幾分低下した
が、依然として高い水準で推移している。
```

###### `ドル円は９月日銀会合での政府発言を受け円安が進んだ後、横ばい圏内で推移`

```
月初に９月の日銀金融政策決定会合の主な意見が公表されると、政府の発言が利上げけん制と市場
で受け止められ、円安が進んだ。その後は、ＦＲＢ利上げ観測の低下、中東情勢を巡る攻撃の激化や
要人発言等を受けた原油価格の変動などを材料に多少の上下はありつつも、概ね横ばい圏内で推移
した。対ユーロでは、フランスの財政懸念を受けたユーロ安が進んだ。
```

###### ~~`１年先までの金利・為替見通し`~~

###### `中東の緊張がくすぶる中、原油高を起点としたインフレ圧力が続き、各国中銀は年度内は利上げ路線`

```
インフレ抑制を企図して各国中銀は利上げを進める。そうした中で、来春以降は原油価格上昇の影響
一巡もあって、インフレ率が徐々に鈍化する。利上げの打ち止め感が広がるなかで、長期金利は徐々
に低下トレンドに向かっていく。なお、日銀は、米欧と比べて政策金利が一段低いこともあり、物価
上振れリスクへの対応のため来年７～９月頃まで利上げを続ける。
```

###### `日米金利差が次第に縮小し、ドル円は徐々に円高方向へ`

```
既に政策金利が高い水準にある米国は速いタイミングで利上げが打ち止めとなる。そうした中で、日
欧が利上げに動くことから、金利差を背景に対ドルで円高となる。対ユーロについては、日銀、ＥＣ
Ｂともに利上げを行うなかで、概ね現状程度の為替レートで推移するものとみられる。
```

###### <u>２．日銀利上げペースは３～４か月に１回と予想</u>

日銀は９月に利上げ 日銀は、９月の金融政策決定会合で政策金利を1.25％に引き上げた。10 月 した後、状況を精査 は、「本日の時点では、リスクや今後の動向をもう少しみていく必要があると判 する必要ありとして 断」として政策金利の据え置きを決定した。 10 月は金利を据え 決定会合後の記者会見では、これまでの利上げの「累積的効果」への言及 置き もきかれた。物価上振れリスクが急に高まるなど、何某かの急激な変化が無い 限りは、様子をみる余裕があるとして、連続利上げは回避する姿勢にあるとみら れる。ただし、今後も「金融緩和の度合いを調整していく」として、利上げ局面が 続くことを明言しており、追加利上げはタイミングの問題であり、実施は間違い ない。次回の金融政策決定会合は12 月となるが、その時点では、日銀短観が 公表され、支店長会議も終え、四半期ごとの節目を経ており、状況の見極めに 必要な情報は十分収集できるとみられる。研究所では、景気を冷やし得る地政 学上のイベントなどが生じない限り、12 月に1.5％へ金利を引き上げると予想し ている。

利上げペースとしては、３～４か月に一回程度で、日々公表されるデータや ヒアリング情報から利上げによる金融環境への影響を点検していくこととなろう。 来春以降は、中東情勢に起因する原油価格上昇の影響が徐々に減衰し、物価 の前年比上昇率は縮小していくものとみられる。そうしたもとで、金融緩和度合 いを調整し、中立金利を目指していくことになろう。日本の潜在成長率がゼロ％ 台であるなか、無事に物価安定目標２％に期待インフレをアンカーできたとする と、中立金利は２％程度まで到達する可能性は十分あり得るものとみられる。政 策金利が２％に近付くにつれて、利上げの打ち止め感が意識され、長期金利 の上昇ペースは次第に鈍化し、インフレ懸念が和らぐもとで低下に転じ、金利 水準は幾分切り下がるとみている
