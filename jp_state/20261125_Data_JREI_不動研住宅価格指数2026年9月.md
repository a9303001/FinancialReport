# <mark>`「不動研住宅価格指数」9月値の公表について`</mark>

```
 当研究所は、2026年11月25日に「不動研住宅価格指数」9月値を公表いたしました。
 不動研住宅価格指数のうち首都圏総合は147.92ポイント(前月比-1.35%)でした。地域別では、東京が
173.35ポイント(前月比-2.14%)、神奈川117.61ポイント(前月比-0.34%)、千葉100.40ポイント(前月比
0.34%)で4ヶ月連続上昇、埼玉109.37ポイント(前月比2.36%)でした。
```
