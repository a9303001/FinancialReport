## `Ⅱ．気候変動対応オペの貸付条件の見直し等`

- `１．執行部からの説明`

```
気候変動対応オペについては、2021年12月の貸付開始以降、民間
における気候変動対応の取り組みが着実に進展し、金融機関の取組目
標も大幅に上方修正されるもとで、貸付残高の増加が続いており、こ
れまでのところ、所期の目的を果たしてきていると評価できる。その
うえで、2030年度末の実施期限まで概ね半分の期間が過ぎる中、今後
も、金融調節の円滑な運営を確保しつつ、民間における気候変動対応
を安定的に支援する観点から、「気候変動対応を支援するための資金
供給オペレーション基本要領」の一部改正を行い、①貸付金利を現行
の固定金利から変動金利に変更するほか、②貸付総額について50兆
円という上限を設定するとともに、貸付先ごとの貸付限度額について
も10兆円という上限を設定することが適当と考えられる。
```

```
被災地金融機関支援オペの貸付金利についても、気候変動対応オペ
に関する見直しに併せて、現行の固定金利から変動金利に変更するこ
とが適当と考えられる。また、共通担保資金供給オペの貸付金利につ
いても、金融調節の一層の円滑化を図る観点から、現行の金利入札方
式および固定金利方式に加え、変動金利方式を選択し得るとすること
が望ましい。
```

```
このほか、被災地金融機関支援オペに関し、東日本大震災について
は、足もとのオペの利用実績等を踏まえると、被災地金融機関の復旧・
復興に向けた取り組みを支援するとの所期の目的を達したと判断さ
```
