#### ２．経済・物価の現状と見通し

#### （経済動向）

わが国の景気の現状については、「中東情勢の影響もあって一部に弱めの動き もみられるが、緩やかに回復している」と評価しています。そうした点を説明す るうえで、経済を構成する様々な要素について、まず海外経済の動向からみてい きたいと思います。

#### （物価動向）

次に、物価動向を説明します。先ほど、本年入り後の資源価格の上昇について 触れましたが、わが国の輸入物価は、中東情勢やグローバルなＡＩ関連需要を背 景とした契約通貨ベースの上昇に、為替円安の影響も加わって、前年比で大幅な プラスとなっています（図表７左）。川上の物価上昇を受けて、企業間の取引価 格である国内企業物価の前年比をみると、７％程度の高い伸びとなっています （図表７右）。サプライチェーンの川上・川中で生じている物価上昇が、今後川 下の消費者物価に対して、どのくらいの早さかつマグニチュードで押し上げと なりうるのかは、大きなポイントかと思います。

そうしたもとで、消費者物価指数（ＣＰＩ）の動きをみると、「除く生鮮」の 前年比は、政府によるエネルギー負担緩和策の効果はみられるものの、賃金上昇 の販売価格への転嫁の動きが続くもとで、輸入物価上昇の影響が現れているこ とから、足もとでは２％程度となっています（図表８左）。「除く生鮮・エネルギ ー」の前年比は、前年に大きく上昇した食料品価格の伸び率低下はあるものの、 ２％台半ばとなっています。なお、日本銀行では、エネルギー負担緩和策や教育 無償化等の「特殊要因」を除いたベースのＣＰＩも公表しており、この水準は「除 く生鮮」で３％台前半となっています（図表８右）。

#### （見通しとリスク）

次に、経済と物価のそれぞれの先行きの見通しとそのリスクについて述べた いと思います。

まず、経済の見通しですが、目先は中東情勢の影響を受けた春先以降のエネル ギー・原材料価格の上昇から幾分鈍化するものの、グローバルなＡＩ関連需要の 増加に加え、政府によるエネルギー負担緩和策などの各種施策や緩和的な金融 環境などが経済を下支えする中で、伸び率を縮小しつつも緩やかな成長を続け ると考えています。 `2027` 年以降は、エネルギー・原材料高のマイナスの影響が 減衰し、所得から支出への前向きな循環メカニズムが徐々に強まっていくこと から、わが国経済は成長率を緩やかに高めていくと考えています。

物価の見通しについては、これまでのエネルギー価格上昇の影響や、グローバ ルなＡＩ関連需要の増加、最近の為替円安の影響などから、 `2026` 年度後半以降、 ２％をはっきりと上回る水準まで伸び率を高めていくと考えられます。その後、 展望レポートの見通し期間後半には、原油高の影響が減衰していくもとで、２％ 程度に向けてプラス幅を縮小していくと考えています。

経済・物価の見通しに対するリスク要因は、大きく３点あると考えられます。 １点目が中東情勢の影響、２点目がＡＩ関連需要の動向、３点目が為替相場の変 動の影響です。これらのリスクの方向性はまちまちではありますが、全体として みると、展望レポートでは、リスクバランスは「経済の見通しについては、概ね バランスしている。消費者物価の見通しについては、上振れリスクの方が大きい」 と評価しています。

#### ３．金融政策運営

#### （金融環境と基調的なインフレ率）

日本銀行では、本年６月と９月の金融政策決定会合で利上げを決定し、政策金 利はおよそ `30` 年ぶりに `1.25` ％となりました（図表９左）。

利上げが実体経済に及ぼす影響をみていく上で、名目の金利水準をみますと、 市場金利の上昇を受けて、銀行の貸出金利は上昇し、ＣＰや社債の発行利回りも 上昇しています（図表９右）。このように、金融環境の緩和度合いは縮小してい ますが、実質金利をみると、経済活動に及ぼす影響が大きい短期ゾーンはマイナ スとなっており、金融環境は、まだ緩和した状態にあるとみられています（図表 `10` 左）。中長期の実質金利はプラスの領域に入ってきていると考えられますが、 そうしたもとでも、企業の資金繰りは、短観のＤＩをみると、今のところ悪化は みられておらず、良好な水準が続いています（図表 `10` 右）。もっとも、政策金利 の引き上げが実体経済に影響をもたらすには、１年、あるいはそれ以上のラグが 存在すると考えられるため、これまでの累積的な利上げの影響も含めて、企業の 資金繰りや、家計の借入れなどへの影響はしっかりとみていく必要があると思 います。

また、金融政策を考えるうえでは、物価のトレンドも１つのポイントであると 考えられますが、この点、中長期的な予想物価上昇率をみると、２％程度となっ ており、消費者物価の基調的な物価上昇率は２％の「物価安定の目標」と概ね整 合的な水準となっています（図表 `11` ）。展望レポートでは、「従来は、基調的な 物価上昇率を２％に向けて引き上げていく過程にあり、物価の下振れリスクに

```
5
```

相応の注意を払うことが必要であったが、足もとでは局面が変化しており、今後 は、基調的な物価上昇率が２％を超えて上振れていくリスクが顕在化し、それが その後の経済に悪影響を及ぼすことがないよう、十分に留意する必要がある」と 述べています（図表 `12` ）。

こうした動向を踏まえて、展望レポートでは、経済・物価・金融情勢に応じて、 引き続き政策金利を引き上げ、金融緩和の度合いを調整していくことが適切と 述べています。これらの点を踏まえた上で、次に金融政策に対する私の考えを述 べたいと思います。

#### （金融政策運営についての考え）

私は、先ほど申し上げた、６月と９月の金融政策決定会合において、利上げに 反対票を投じました。その理由は、会合後の公表文に記されているように、足も とのインフレ率が２％を下回るなか、経済の状況も必ずしも強いとはいえない 点を踏まえると、政策金利を据え置くことが望ましいと考えたためです。また、 ７月と `10` 月の決定会合では、政策金利の据え置きに賛成しています。

私がこのように判断した背景ですが、マクロ経済学の一般的な考え方に基づ けば、「物価上昇、ないしそのリスクに対して、政策金利の引き上げで対処を図 る」ことの背景には、「金利の引き上げが消費や投資に対して押し下げ方向に働 き、それが物価上昇圧力を低下させる」といったロジックがあると考えられます。 こうした点を踏まえると、利上げの判断をする際には、先行き予想されるインフ レが経済にもたらす影響と、利上げが及ぼす経済の下振れの影響のどちらを重 視するかが論点であると考えられます。

利上げが経済に及ぼす影響については、金融環境が極めて緩和的な状況にお いては、政策金利を引き上げてもなお緩和的な環境が続くため、経済の下振れリ スクはそこまで大きくないかもしれません。一方で、利上げを続けて、金融環境 が引き締まってきている、あるいは緩和の度合いが小さくなってきている場合

```
6
```

には、利上げがもたらす経済の下振れリスクが次第に大きくなる点には留意が 必要だと思います。

この点、現在の金利水準が緩和的か否かを測る１つの指標としては、中立金利 が挙げられますが、日本銀行の推計では、自然利子率は▲１％弱～０％台半ば程 度となっており、それに期待インフレ率を加えた中立金利の水準は、１％強～ ２％台半ばであるとみられます。この推計自体は、非常に幅の広いものですが、 政策金利の水準がこのレンジに既に入ってきていることを踏まえると、足もと の金融環境が緩和的であるとしても、その度合いは徐々に縮小してきているよ うに思われます。言い換えると、利上げ開始直後の、政策金利が中立金利を明確 に下回っている状況とは異なり、政策金利の引き上げが、実体経済に対してより 影響する可能性は、以前よりも高まっていると考えられます。特に、先ほど申し 上げたように、足もとの実体経済、特に個人消費が必ずしも強いとはいえない状 況にあることを踏まえますと、利上げが経済を下振れさせ、ひいては基調的な物 価上昇率の押し下げにつながってしまうリスクには、十分に留意する必要があ るのではないかと思います。

次に、物価上昇リスクについてですが、今後基調的なインフレ率が２％を超え て上昇した場合に、経済に悪影響をもたらすリスクには注意する必要はあると 私も思います。一方で、既往の利上げや、今後の政策金利の引き上げが、実体経 済の下振れにつながった場合には、消費者物価、ひいては基調的なインフレ率を 押し下げるリスクもあると思います。家計が実際に直面している消費者物価の 前年比が、徐々に伸び率を高めつつも、足もとでは政策効果もあって２％程度に ある中で、今後消費者物価がどの程度上昇していくのか、またその際に、基調的 な物価上昇率が２％を超えて上振れていく確度がどの程度大きいのかについて は、実際の消費者物価の動向も含めて、状況を見極めつつ判断してもよいのでは ないかと考えています。

その上で、今後政策金利を引き上げていく場合には、賃金の上昇を受けて需要

```
7
```

が主導する形で物価の上昇が進み、賃金と物価が相互に参照しながら緩やかに 上昇するメカニズムが、これまで以上に働いている状況かと思います。この点、 ３年連続の高いベアに加えて賞与も増加する中で、実質賃金が本年入り後プラ スを続けていること自体は望ましいと思います。とはいえ、足もとの景気、特に 個人消費はそこまで力強い動きがみられていない中では、現在の物価上昇は必 ずしも需要主導で生じているわけではないと考えています。その意味では、今後、 政策金利を引き上げていく場合においても、そのペースには十分留意する必要 があると考えています。

#### （ＥＴＦの売却ペースの見直し）

金融政策運営の最後に、ＥＴＦの売却について説明します。

日本銀行は、 `2025` 年９月の金融政策決定会合で、ＥＴＦの売却開始を決定し、 `2026` 年１月より売却を進めてまいりました。現時点では、売却は市場に大きな 影響を与えることなく、円滑に進んでおり、また、株式市場の全体の売買代金も 拡大しています。こうしたことを踏まえて、本年 `10` 月の決定会合では、売却ペ ースを見直し、市場全体の売買代金に占める年間売却額の割合を、従来の `0.05` ％ 程度から、 `0.1` ％程度に高めることを決定しました。

これにより、年間の売却ペースは従来の `3,300` 億円から `8,600` 億円に増加し、 売却完了までにかかる年数も、従来の `112` 年から `43` 年程度へと縮小する見込み です。もっとも、市場等の状況に応じて、年間の売却ペースの範囲内で、売却額 の一時的な調整や停止を行うことができることは、従来と同じ枠組みとなって います。

長崎県経済の歴史は、常に海と深い関係を有してきました。遣唐使が大陸に渡 るとき、あるいは朝鮮通信使がわが国に来着するとき、長崎はその起点となりま した。 `1550` 年の平戸港開港は本格的な南蛮貿易の先駆けになり、長崎港は `1571` 年の開港以来、鎖国政策の下でもオランダや中国と貿易を行い、外国との交流の 窓口になりました。様々な経路を通じて伝来した海外の文化や技術は、江戸時代 においては陶磁器の生産などへの結実をみただけでなく、開国以降、造船産業や 石炭産業など新しい技術がわが国に受容されるうえでの素地を作りました。そ れらは、世界遺産に登録された「明治日本の産業革命遺産 製鉄・製鋼、造船、 石炭産業」にも垣間見ることができます。また、もう一つの世界遺産である「長 崎と天草地方の潜伏キリシタン関連遺産」では、新しい伝来宗教であったキリス ト教が、長崎や日本全体の当時の社会制度などのもとで、世界でも稀有な固有の 文化遺産となっていく過程を窺い知ることができます。

現在においても、海を持つという特性は、県内全域にまたがるテーマパーク、 温泉やマリンレジャーなどの多くの観光資源の価値を一段と高め、国内外の 人々を惹きつけています。もっとも、当地が、人口問題において課題先進県とな るもとでは、海や離島という要素が作用している部分もあります。すなわち、長 崎では、国を上回るペースでの人口構造の変化が進むもとで、企業活動あるいは 社会活動においても人手不足が目立つようになっています。高齢化も進んでい ます。

ただし、別の見方をすると、将来的に同じ課題に直面する他地域の手本となる よう、先端技術の実証と社会実装をリードしていく大きなチャンスと捉えるこ ともできます。ここでも、各所で海の活躍の余地がありそうです。現在、長崎県 では、持続的で強靭な地域経済の基盤づくりに向けて、「日本一共働き・共育て しやすい長崎県づくり」や当地の強みを活かした産業振興に向けた取り組みを 進めておられます。

一例を挙げますと、国の地域未来戦略に基づき策定した海洋関連分野（造船・ 防衛・エネルギー）の地域産業クラスター計画が認可され、今後５年間で `700` 億
