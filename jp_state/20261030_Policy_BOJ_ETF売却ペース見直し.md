# `ＥＴＦの売却ペースの見直しに関する決定（2026年10月）`

```
本年１月以降の売却の経験
```

### 処分の基本方針

```
市場に大きな影響を与えることなく円滑に進捗。
株式市場全体の売買代金も拡大。
```

```
市場の情勢を勘案市場に攪乱的な影
日本銀行の損失発
し、適正な対価に響を与えることを
生を極力回避する
よる極力回避する
```

## `売却ペースの見直し：2027年１月から実施`

|||`年間の売却ペース`<sup>`1`</sup>|`市場全体の売買代金に占める`<br>`年間売却額（時価）の割合`|`売却完了までに`<br>`かかる年数`<sup>`3`</sup>|
|---|---|---|---|---|
|`現在`|`簿価`|`3,300億円程度`|`0.05％程度`|`約112年`|
|`見直し後`|`簿価`<br>`（時価）`|`8,600億円`<br>`8,600億円程度`<br>`（２兆4,600億円程度`<sup>`2`</sup>`）`|`程度`<br>`0.1％程度`|`約43年`|

```
（注1）時期の分散に配慮しつつ、各銘柄の保有割合におおむね比例的なかたちで売却
（注2）本年１月以降に売却したＥＴＦの時価簿価比率等に基づく計算
```

```
（注3）本年９月末時点の保有ＥＴＦ残高（簿価）を年間の売却額（簿価）で除して計算
```

⚫ `市場等の状況に応じ、上記の売却ペースの範囲内で、売却額の一時的な調整、停止を行うことができる （従来どおり）。`
