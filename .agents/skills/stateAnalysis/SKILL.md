# stateAnalysis — 國家層級房地產景氣 × REIT 深度分析

**任務**：回答一般人最想知道的四件事——「{國家}的房地產信託現在該買、該等還是避開？哪幾檔？為什麼？要等到什麼時候、看什麼訊號？」——整份重寫 `{cc}_state/AnalysisResult.md`。
**讀者**：沒有財經背景、用手機看的台灣投資人。只看前 30 秒（〇章）就知道要不要動作；看完前五章（〇～四，約 3 分鐘）就知道買哪幾檔、為什麼、等什麼；第五章以後是給想查證的人看的佐證。
**分工**：`collectState` 只收原始資料到 `{cc}_state/` → 本 Skill 是**唯一**做判斷與寫結論的地方 → 單一 REIT 的完整分析交給 `StockAnalysis`。
**檔案**：`references/output_template.md`（版面唯一來源）｜`references/{cc}.md`（該國門檻、標的池、錨點、行事曆；只讀當次國家）｜`scripts/state_analysis_tools.py`（`skeleton`／`series`／`budget`／`check`／`selftest`）。
**參數**：`$ARGUMENTS`（空白或不像國家代碼 → 從使用者訊息解析；仍沒有 → 詢問，不可猜）。

## 0. 硬規則（違反任一＝任務失敗）

1. **越重要越上面**：章節順序照 §4.1；每章第一行就是結論；章內條目依重要性（對配息影響大小）由高到低排。不得把結論藏在章尾。
2. **一般人看得懂**：〇～四章零術語（§5.8 與 `<REF>` 禁用詞改白話）；五～十四章術語第一次出現寫「白話（英文）」並收進名詞小辭典。每個數字後接 👍／➖／👎 與一句白話。
3. **時間戳**：第一行 `> **更新時間（Last Updated）：yyyy/MM/dd HH:mm:ss (UTC+8)**`，全檔寫完才取真實系統時間（`TZ=Asia/Taipei date "+%Y/%m/%d %H:%M:%S"`）。
4. **防幻覺**：每個數字附來源＋資料日期；查不到寫 `N/A（原因）`；自算附公式或標 `(估)`。不用訓練記憶補數字、連結或日期。
5. **依規則判定**：溫度計、五盞燈、階段、4／5 個月規則、逐檔燈號照 §5 與 `<REF>`；長序列用 `series` 算。
6. **每單位化**：個別 REIT 金額都附每口／每單位金額，影響類再寫「配息約 ±X%」。
7. **零表格**：不得有 Markdown 表格、`<table>`、Tab 對齊、code block。
8. **整份重寫**：不接在舊內容後面；只留會改變決策的內容；長期記憶（§3.2）要完整帶過去。
9. **長度**：全檔 ≤ 1000 行（目標 ≤ 800）、≤ 60,000 字元、單行 ≤ 200 字元（一般人區 ≤ 120）；各章守 §4.1；用腳本實測。
10. **檔案隔離**：只寫 `{cc}_state/AnalysisResult.md`、`Log/stateAnalysis_{CC}_{yyyyMMdd}.md`、本 Skill（維護用）。`{cc}_state/` 其他檔是 collectState 的，只讀不改。

## 2. 流程（單項失敗記錄後繼續）

1. **準備**：讀 `<REF>`、`<TPL>`；`git fetch origin master && git merge --no-edit FETCH_HEAD`。`<FOLDER>` 沒資料或最新月檔早於 1 個月前 → 照樣做，靠 deep research，第十四章寫「建議先跑 `{cc} /collectState`」。
2. **讀回**（§3.1）：決定輪次 N 與深挖焦點（§3.3）。上一版存在 → `python <TOOLS> budget --file <OUT>`；版面不是現行樣板（章名對不上）→ `python <TOOLS> skeleton --cc {cc} > <SCRATCH>/draft.md`，把舊內容依新順序搬進骨架。
3. **Delta Scan**：依 `<REF>` 發布行事曆確認上一版之後哪些數據有新一期；沒有的標 `＝（自 yyyy-mm-dd 起未更新）`。
4. **Deep research**：先清上一版第十四章 P0，再做本輪焦點與每輪必抓（§3.1）。
5. **判定**：新月份寫進序列 → `python <TOOLS> series --file <草稿>` → 溫度計 → 五盞燈 → 階段 → 逐檔數字與燈號 → 政策劇本 → 利率敏感度。
6. **Final Rewrite**（§7）：先砍 → 寫佐證區（五～十四章）→ 名詞小辭典 → 一般人區（四 → 三 → 二 → 一 → 〇，最後寫最重要的〇章，確保它是全文的濃縮）→ 前置資訊條；寫作中可跑 `check --draft`。
7. **蓋時間戳** → `python <TOOLS> check --cc {cc} --file <OUT>` 必須 0 FAIL（WARN 逐項處理或說明）。
8. **交付**（§8）。

- **collectState 原始資料**：`<FOLDER>/0.Index.md` → 挑讀單篇（`Data`、`Policy` 優先，再 `Report`、`REIT`、`News`、`Sentiment`；上一版已引用且沒更新的不重讀）；`{yyyyMM}_{CC}_輿情新聞.md`（當月與上月）。這些是事實素材，結論由本 Skill 自己判斷。
- **本機 REIT 資料夾**（`<REF>` 本機追蹤組）的 `AnalysisResult.md`：DPU、NAV、LTV、單位數。
- **篩選結果**：`JpReitScreenerResult/0.JpReitScreenerResult.md`、`HkReitScreenerResult/0.HkReitScreenerResult.md`。
- **Gemini 版**（`Analysis/JpStateResult.md`、`Analysis/HkStateResult.md`）：只作交叉驗證與序列種子，沒回一手核對的標 `(種子)`，只能放佐證區、不進燈號判定。判斷細節沒寫到 → 回查 `Analysis/gemini_JPState.md`／`gemini_HkState.md`；衝突時 `<REF>` ＞ 本檔 ＞ gemini。

### 3.2 長期記憶（collectState 只留 1 個月，`<OUT>` 是唯一長期存放處）
- 必須帶下去：40／60 個月序列、季度與年度指標最新一期、逐檔 DPU／NAV／LTV／單位數、政策錨點與里程碑、未結待辦、仍用得到的辭典詞。
- 沿用寫 `數值（原文發布日 yyyy-mm-dd，來源）＝（自 yyyy-mm-dd 起未更新）`；有新一期就換掉標 🔄。原檔已刪的回一手核對；查不到又超過 12 個月 → 刪除或標 `(舊)`。
- 標記：🆕 新增｜🔄 更新（寫「從 X 變成 Y」）｜⏸ 沿用｜🔧 改口｜`(估)`｜`(舊)` 逾 6 個月｜`⚠️` 未證實。時效：≤ 90 天可進一般人區；91 天～12 個月只放佐證區；> 12 個月只當背景。

### 3.3 輪次與深挖焦點
- N＝上一版＋1（首輪 1）。焦點＝N ÷ 4 餘數：0＝A 利率 × 政策制度｜1＝B 長序列｜2＝C REIT 財務估值與利率防禦｜3＝D 商業地產供需 × 輿情 × 匯率。
- 每輪最多新增 2 個 `###` 深挖小節（放在對應佐證章內），新增幾個就汰除幾個，全檔 ≤ 6 個。
- **輕量輪**：距上一版 < 6 小時且 Delta Scan 全是 `＝` → 不深挖，改抽查 ≥ 5 個關鍵數字回一手來源；仍整份重寫並瘦身。

## 4. 輸出規格（版面照 `<TPL>`）

### 4.1 章節順序與行數預算（越重要越上面；`budget`／`check` 實測；改數字要同步 `<TOOLS>` 的 `BUDGET` 並跑 `selftest`）

- 前置：≤ 7 行

- 一、哪幾檔能買、哪幾檔先別碰：≤ 50 行
- 二、最重要的好消息與壞消息：≤ 26 行
- 三、接下來盯這 3 件事：≤ 6 行
- 四、房市景氣溫度計：≤ 28 行

佐證區（術語可用、要進辭典）：
- 五、逐檔體檢（完整數據）：≤ 175 行
- 六、進場時點：5 個條件與景氣四階段：≤ 45 行
- 七、利率、物價與匯率：≤ 22 行
- 八、各類房地產冷熱（分板塊細節）：≤ 45 行
- 九、房價走勢：40 個月紀錄與 4 個月規則：≤ 52 行
- 十、租金走勢：60 個月紀錄與 5 個月規則：≤ 78 行
- 十一、政策與制度會怎麼影響：≤ 32 行
- 十二、網路上大家怎麼說（輿情）：≤ 30 行
- 十三、資料來源與搜尋狀態：≤ 18 行
- 十四、資料缺口、待辦與行事曆：≤ 24 行
- 附、名詞小辭典：≤ 32 行

合計 680 行。每章行數＝`##` 標題到下一個 `##` 前一行，空行也算；標題前 1 個空行，清單內不留空行。
**不重複**：同一件事在一般人區只寫一次（〇章寫結論、一～四章各管一件事），佐證區只補數字與來源，不重抄一般人區的句子；同一數字最多出現「一般人區一處＋佐證區一處」。

### 4.2 一般人區（〇～四章；品質權重最高）
- **共通**：零表格、零術語（REIT 正式名稱後接代號不算）；先講好壞再給一個數字；能說「約 X 成」「每 100 間空 X 間」「每投入 NT$10 萬一年領 NT$X」就不用百分比與當地幣。每條 ≤ 60 字（硬上限 120）；全區 ≤ 9,000 字元。時間要具體（「2027 年第 2 季」「12 月 18 日」）；禁「持續觀察」「審慎樂觀」「有待觀察」「值得關注」；比喻 ≤ 2 個。數字必須在佐證區同值同日期出現；`⚠️`、`(舊)`、`(種子)` 不進一般人區。
- **前置**：時間戳、主標題，加兩行資訊條：資料截至｜股價日｜第 N 次｜1 台幣 = X 當地幣；最舊關鍵數據｜「不是個人化投資建議」。
- **〇、30 秒看結論**：七欄照順序、各一行：一句話結論（分批買／觀望／避開＋理由＋一個數字＋把握度）→ 房市溫度（含上次）→ 房地產信託燈號分布 → 最快何時能買（季度＋還差什麼）→ 還沒買的人 → 已經持有的人 → 跟上次比（溫度或燈號有變必寫；沒變寫「＝ 沒變」＋一句原因）。
- **一、哪幾檔能買**：🟢 → 🟡 → 🔴，同燈號配息率高到低；最多 8 檔寫完整 5 行（標題含白話結論＋它是什麼＋為什麼與 NT$10 萬收益＋等到什麼再買＋最大風險），其餘列入「其他 🟡／🔴」。收益：`X = 100,000 × 年化配息 ÷ 現價`，稅後 `Y = X × (1 − 預扣稅率)`（`<REF>`）。章末一行換匯提醒。
- **二、好消息與壞消息**：`### 🔴 壞消息`、`### 🟢 好消息` 兩小標；結論偏觀望／避開時壞消息在前，偏買進時好消息在前。各 ≤ 3 條高重要性（2 行：一句白話＋「對配息：哪幾檔、每口 ±X、約 ±Y%、長期／一次性｜重要性｜日期，來源」），中重要性一行，低的不寫。依對配息影響大小排序；本次新出現的標 🆕。
- **三、接下來盯這 3 件事**：剛好 3 件，依日期先後；每件寫「日期｜誰公布什麼：若 白話門檻 → 看法怎麼變」。
- **四、房市景氣溫度計**：圖例 → 整體（含上次）→ 各板塊一行（階段＋好壞符號＋白話數字＋上次）→ 借錢成本、便宜度、匯率 → 「為什麼房價和房地產信託不一定同方向？」≤ 3 行（用本次數字）。hk 分中國、香港兩段（`<REF>`）。
- **自檢**：不懂財經的家人只看〇章，能說出「現在要不要買、最快什麼時候」；看完〇～四章，能說出哪幾檔別買、為什麼房價漲不代表房地產信託漲、要等哪一天的什麼消息。

### 4.3 佐證區（五～十四章）
- 每章第一行 `**白話重點**：`（零術語一句，含「所以要怎麼做」）→ 章首放該章最重要的判定行（強制行）→ 其餘依重要性。不寫章尾「所以呢」（結論已在章首）。
- 第五章開頭加一行引言：「📚 第五～十四章是佐證：想知道為什麼再往下看；看不懂的詞查最後的名詞小辭典。」
- 數字三件套：`數值 ＋ 👍／➖／👎 ＋（白話）`，例 `空租率：1.6% 👍（每 100 間空不到 2 間）`。一行最多 3 個百分比（序列除外）。英文縮寫第一次寫「白話（英文）」；用到的禁用詞都要進辭典（`check` 比對）。日文、簡中原文翻成台灣白話。寫「個百分點」不寫 bps。
- 版式：條目式、欄位式（`- **指標**：數值 符號（白話）　資料日期：…`）、序列式、比較式（全形「｜」≤ 5 欄）。不用 ASCII `|`。
- 各章要點：
  - **五、逐檔體檢**：§5.5 三種格式逐檔，順序同第一章；章末 `燈號分布：🟢 X 檔｜🟡 Y 檔｜🔴 Z 檔`。
  - **六、進場時點**：五盞燈總結行（章首）→ 燈 ①～⑤ 逐盞 → 階段 ①～④ 逐條 ✅／❌ → 週期起點 → 三年三劇本（合計 100%，最可能的在前）→ 機構預測 → 提早買／再等各 3 理由。
  - **七、利率物價匯率**：依對判定影響排序：政策利率與下次會議、市場預期、10 年公債、配息率與公債差、通膨（含房租）、薪資、匯率（含 3 個月前）；hk 加 HIBOR、LPR。
  - **八、分板塊**：整體（章首）→ 依 `<REF>` 板塊逐卡「階段（上次）→ 2～3 個數字與門檻比較 → 白話」，與 REIT 持有最相關的板塊在前；hk 分 8A 香港、8B 中國。
  - **九／十、房價與租金**：強制行（章首）→（十加連動）→ 每區摘要（`series` 輸出）→ 怎麼讀 → 序列（§5.4）→ 口徑。
  - **十一、政策**：政策結論（章首）→ 劇本機率 → 里程碑 → 法規錨點 → 逐檔敏感度。非焦點 A 輪且里程碑無變化 → 標 `＝`、壓到 ≤ 15 行。
  - **十二、輿情**：「網路情緒和實際數字一致嗎」（章首，含已辨識假消息）→ 依地區小標，一則一行（來源時間｜白話翻譯｜多空｜可信度＋理由｜對投資影響），可信度高的在前。
  - **十三、資料來源**：讀了哪些 collectState 檔、一手來源成功／失敗、逐檔年報季報是否找到（`AGENTS.md` §4.3 格式）、資料新鮮度。
  - **十四、缺口與待辦**：P0 → P1 → P2，一行一項，原因只限 ① 未發布 ② 被擋 ③ 預算不足 ④ 需更多期數；P0 改變結論／P1 改變把握度／P2 背景；延宕 3 次必須做掉或結案；本次清償；30 天行事曆。
  - **附、名詞小辭典**：只收佐證區真的用到的詞，`- **白話名（英文）**：意思｜怎麼看：越高越好／越低越安全／門檻 X`。

## 5. 判定規則（各國門檻在 `<REF>`）

### 5.1 景氣溫度計
五階段 🥶 下跌 → 🧊 築底 → 🌱 回溫 → ☀️ 熱絡 → 🔥 過熱，由 🔥 往 🥶 比對，第一個符合的就是。整體＝有資料板塊卡的中位數（偶數取較保守者）；每卡寫「上次：X」，變動寫進〇章「跟上次比」並標 🔧。

### 5.2 借錢成本、便宜度、匯率
- 借錢成本：`<REF>` 指定利率與 3 個月前比，升 ≥ 0.25 個百分點 ⬆️、降 ≥ 0.25 ⬇️、其餘 ➡️。
- 便宜度：💎／👍／➖／👎（門檻見 `<REF>`），兩條件衝突取較貴一格。
- 匯率：1 TWD 換當地幣與 3 個月前比，變動 ≥ 3% 說明「當地幣變便宜／變貴」；變動 > 2% 時全檔 NT$ 換算重算。

### 5.3 五盞燈與四階段
每盞燈寫門檻、最新值、燈號、日期；四階段全部條件同時成立才算。溫度計、燈、階段與逐檔燈號在〇、一、四、五、六章必須一致。

### 5.4 長序列與 4／5 個月規則
- 格式（`series` 只認這個）：母條目 `- **房價 40 個月 MoM 序列（區1｜區2｜…；新 → 舊）**`，子條目一行一月 `  - yyyy-MM：+0.42%｜−0.05%｜N/A`，≤ 5 區，下接口徑行。房價固定 40 個月、租金 60 個月，補新刪舊；兩序列地區名一字不差。
- 達標月：MoM ≥ −0.10%；N/A 不算；最近 12 個月連續 ≥ 3 個 N/A 的地區不參與。
- 4 個月規則：單區房價近 4 月達標＋同區租金近 4 月達標＝聯合通過；≥ 3 區＝確認。
- 5 個月規則：單區租金近 5 月達標＝通過；≥ 3 區＝成立（jp 另需辦公室）；連動見 `<REF>`。
- 5 個月全落在旺季（jp 3～4 月；中國 6～8 月、春節）→ 標「⚠️ 季節性未排除」，用 YoY 交叉確認。

### 5.5 REIT 逐檔（範例見 `<TPL>` 第五章）
- 燈號：🟢 可分批買（條件已成立）｜🟡 等訊號（寫缺什麼）｜🔴 先避開（LTV 逼近上限、配息 > 20% 靠一次性收入、利息或租金壓力持續）。
- 完整版（本機追蹤組，≤ 15 行）欄位順序：結論（含「所以…」）→ 進場條件 → 它是什麼（含單位數）→ 現價 → 殖利率 → 配息品質 → 負債比率 → 利率敏感度 → 股價淨值比（P/NAV）→ 租金報酬率（註明口徑）→ 空租率 → 單位數 2 年變動 → 本期重要公告。國家加欄見 `<REF>`。
- 精簡版（板塊代表組，≤ 7 行）：結論＋進場條件 → 現價與殖利率 → 配息品質 → 負債比率與利率敏感度 → P/NAV → 租金報酬率與空租率。
- 一行版（觀察名單）：現價｜殖利率｜P/NAV｜LTV｜理由（取價日）。
- 配息品質：來自租金 ≥ 95% 🟢｜80～95% ⚪｜< 80% 🔴，寫「拿掉一次性收入，配息少 X（−Y%）」。
- 利率敏感度 `(估)`：+0.5 個百分點＝總借款 × 浮動比例 × 0.5% ÷ 單位數；+1＝總借款 ×（浮動＋1 年內到期比例）× 1% ÷ 單位數；換算佔配息 %。
- 單位數 2 年變動 > 10% → 寫數量、%、原因與對每單位配息／NAV 的影響；否則寫「穩定（±X%）」。

### 5.6 每單位化與重要性
- 每單位金額＝絕對金額 ÷ 最新期末已發行單位數（註明日期）；跨幣別先換算。
- 影響式：`換約後利息增加 3.06 億 JPY → 每口配息 −400 JPY（約 −4.6%，長期）　重要性：中　資料日期：yyyy-MM-dd`；〇～二章一律用影響式（金額可只寫「每口 −X、約 −Y%」）。
- 重要性依配息影響：> 10% 極高｜5～10% 高｜1～5% 中｜< 1% 低（佐證區或刪）；無法量化以「機率 × 衝擊」定。總體金額免每單位化，附年增率。

### 5.7 幣別
jp → JPY；hk → HKD（87001 用 RMB 附 HKD）；中國總體 → RMB。全檔一套匯率（數值、日期、來源）；一般人區收益一律 NT$。

### 5.8 禁用詞（一般人區禁用；佐證區可用但必須進辭典；各國加碼見 `<REF>`）
- REIT、房託、產業信託、投資法人 → 房地產信託（買它＝當收租房東的小股東）
- DPU、分派、可分派收入、分配金 → 配息；殖利率 → 配息率（每投入 NT$10 萬一年約領 NT$X）
- NOI、NPI、FFO、AFFO → 扣掉開銷的租金收入；LTV、借貸比率、槓桿比率 → 負債占資產幾成
- NAV、P/NAV → 資產帳面價值（股價只值資產 X 折）；Cap Rate、利差、bps、pp、pt → 配息率比公債多 X 個百分點
- MoM、環比、YoY、同比 → 跟上個月比、跟去年同月比；Idx、指數化、串接 → 直接講漲跌幅
- 出租率、空置率、空室率、空租率 → 每 100 間有 X 間租出去／空著；續租調整率、租金改定率 → 續約或換租客時租金漲跌；租金報酬率 → 租金占房價幾成
- 五盞燈、階段①～④、4 個月規則、5 個月規則、Focus、A／B 組 → 改寫成「5 個進場條件已達成 X 個」與白話條件
