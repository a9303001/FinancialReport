## ▍2. 三句話看懂（白話總結，完全不用術語）

1. **它靠什麼賺錢？** 阜豐買玉米，用發酵的方式做成三類東西賣：**做菜提鮮的味精**（全球產能第一）、**加進豬雞飼料幫牠們長肉的胺基酸**（蘇氨酸、賴氨酸），以及**讓食品和鑽油泥漿變稠的黃原膠**（全球第一，但市佔只有約四分之一）。工廠都蓋在玉米產地旁邊、還自己蓋發電廠燒煤，所以成本比同行低。

2. **現在做得好不好？** 2025 年帳面很漂亮，每股賺 1.15 港元創新高；但**真正留下來的現金只有每股 0.16 港元**，卻硬是配了 0.49 港元股息，差額是去銀行多借錢來的（每股借款一年多背 2.92 港元）。2026 年更糟：前 5 個月已經虧了，主因是公司手上一大堆美元存款、遇上人民幣大漲而帳面縮水，加上產品賣價低迷。

3. **最該擔心什麼？** **這週五（8/28）公布上半年成績單和股息**。公司配息政策是「賺多少配四成」，上半年幾乎沒賺，中期股息很可能大砍甚至不發，每股會少拿 0.28～0.37 港元。好消息是味精現貨價 8 月漲到近期高位，如果撐得住，下半年有機會賺回來；壞消息是玉米和煤炭也跟著漲，成本優勢正在被吃掉。

**⚠️ 方法與限制（請先讀）**

```

其中轉換率 = 2,465,228 ÷ 5,481,935 = 44.97%
```

## ▍7. 必備財務指標公式算式與就地還原

> **導讀**：本節把所有自定義指標攤開寫，讓讀者可以自己拿計算機驗算。原始數字全部取自本機 `00546_2025_annual_report.md`（FY2025 年報），單位為**人民幣千元**。

**① 負債比率（AGENTS.md 自定義公式）**
```
負債比率 = 負債總額 ÷ 資產總額 × 100%
FY2025 = 24,254,618 ÷ 43,714,724 × 100% = 55.48%
FY2024 = 17,746,842 ÷ 36,089,896 × 100% = 49.17%
```
*判讀*：一年上升 **6.31 個百分點**。製造業 40%–60% 屬合理區間，數值本身還行，但**上升速度**是警訊，主因短期銀行借貸從 110.16 億暴增到 174.46 億人民幣。
> ⚠️ **口徑提醒**：年報「五年摘要」另揭露一個「資產負債比率 40%」，那是用**有息負債 ÷ 總資產**算的（176.46 億 ÷ 437.15 億 ＝ 40.4%），與 AGENTS.md 定義的「全部負債 ÷ 總資產」不同。本檔全檔一律採用 AGENTS.md 定義的 **55.48%**。

**② 自定義 OPM（本業獲利純度）**
```
OPM = 營業利益 ÷ 稅前利益 × 100%
FY2025 = 2,725,858 ÷ 2,996,096 × 100% = 90.98%
FY2024 = 2,543,514 ÷ 2,837,031 × 100% = 89.65%
```
*判讀*：FY2025 稅前獲利有 **91% 來自本業**，只有 9% 來自業外（訴訟賠償、碳排放配額出售、利息淨額等），獲利品質乾淨。**⚠️ 2026 年因為 5.4 億人民幣的匯兌損失會壓低稅前利益，這個比率會遠高於 100%（分母變小），屆時解讀方式要改變。**

**③ 過去五年股東權益報酬率（ROE）序列與中位數**
```
資料來源：FY2025 年報「五年摘要」官方揭露值（ROE = 股東應佔溢利 ÷ 總權益）
2021 = 10%｜2022 = 25%｜2023 = 18%｜2024 = 13%｜2025 = 13%
排序：10 → 13 → 13 → 18 → 25
中位數（第 3 個）= 13%
```
*判讀*：五年中位數 13%，屬穩健但非優異。2022 年的 25% 是週期高點，不可視為常態。

**④ 過去五年殖利率序列與中位數**
```
2021 = 7.99%｜2022 = 14.67%｜2023 = 13.39%｜2024 = 7.30%｜2025 = 6.18%
（各年度以「當年度總每股股息 ÷ 該年最後交易日收盤價」計算）
排序：6.18 → 7.30 → 7.99 → 13.39 → 14.67
中位數（第 3 個）= 7.99%

現價即時殖利率 = 全年 DPS 0.487 HKD ÷ 現價 5.135 HKD = 9.48%
```
*判讀*：現價殖利率 9.48% 高於五年中位數 7.99%，**表面上是買點**。⚠️ **但這是後照鏡**——用 2025 年的獲利配的息，2026 年若照 40% 派息率，殖利率會掉到 1.6%–3.5%。
> ⚠️ **資料誠實聲明**：2021–2024 年度的殖利率數值沿用前輪計算結果，**本輪未能找到獨立來源重新驗證各年度年末收盤價**，屬資料缺口（見第 11 節）。2025 年度數值與現價殖利率則已用本輪查得的股息與股價重新驗算。

**⑤ 淨利潤年複合成長率（CAGR）**
```
公式：CAGR = (期末值 ÷ 期初值)^(1 ÷ 年數) − 1
分子取官方「五年摘要」FY2025 股東應佔溢利 = 24.65228 億人民幣

5 年（2020 → 2025）：(24.65228 ÷ 6.30)^(1/5) − 1
                    = 3.9130^0.2 − 1 = 1.3137 − 1 = 31.37%
10 年（2015 → 2025）：(24.65228 ÷ 5.163)^(1/10) − 1
                    = 4.7749^0.1 − 1 = 1.1692 − 1 = 16.92%
```
*判讀*：5 年 31.37% 看起來很猛，但**起點 2020 年是週期谷底（只賺 6.30 億）**，有嚴重低基期效應。10 年 16.92% 才是比較誠實的長期水準。**2026 年這條成長線會斷掉。**
> ⚠️ 2020 年（6.30 億）與 2015 年（5.163 億）的基期數字沿用前輪查證結果，本檔的 FY2025 年報「五年摘要」只回溯到 2021 年，無法就地驗證更早期數字。

**⑥ 本益比（PE）與股價淨值比（PB）還原**
```
每股盈餘 EPS = 0.9833 人民幣 × 1.1670 = 1.1474 HKD
本益比 PE   = 5.135 ÷ 1.1474 = 4.48 倍

每股淨值 BPS = 19,460,106 千元 ÷ 2,507,346 千股 = 7.7612 人民幣
             = 7.7612 × 1.1670 = 9.058 HKD
股價淨值比 PB = 5.135 ÷ 9.058 = 0.567 倍
```
> ⚠️ 富途／新浪顯示 PE 4.69–4.72 倍、PB 0.60 倍，是因為它們用 **FY2025 年底匯率約 1.1072** 換算（0.9833 × 1.1072 ＝ 1.0887 HKD ⇒ 5.135 ÷ 1.0887 ＝ 4.72 倍）。兩者都對，只是匯率時點不同。

**⑦ 自由現金流（FCF）與配息覆蓋率——本輪新增，最關鍵**
```
自由現金流 FCF = 營業活動現金流淨額 − 購置不動產廠房設備支出
FY2025 = 2,911,344 − 2,569,008 = 342,336 千人民幣
       → 每股 = 342,336 ÷ 2,507,346 × 1.1670 = 0.1593 HKD

FY2024 = 2,955,298 − 1,192,616 = 1,762,682 千人民幣
       → 每股 = 1,762,682 ÷ 2,507,346 × 1.1670 = 0.8204 HKD

一年變化 = (0.1593 ÷ 0.8204) − 1 = −80.6%

配息覆蓋率 = 每股 FCF ÷ 每股 DPS = 0.1593 ÷ 0.487 = 32.7%
反過來看：配息 = FCF 的 306%
現金缺口 = 0.487 − 0.159 = 每股 0.328 HKD（＝FY2025 EPS 的 28.6%）
```
*判讀*：**這是全檔最重要的一個計算。** 公司帳面每股賺 1.147 HKD，但扣掉維持與擴張產能所需的資本支出後，**真正能自由運用的現金只剩每股 0.159 HKD**，卻硬配了 0.487 HKD。差額每股 0.328 HKD 是從哪裡來的？答案在資產負債表——銀行借貸一年增加 62.81 億人民幣（每股 +2.92 HKD）。**這解釋了為什麼末期股息要砍 44.5%，也預告中期股息很難維持。**

**⑧ 淨利潤現金含量（獲利含金量）——本輪更正**
```
現金含量 = 營業活動現金流淨額 ÷ 股東應佔淨利
FY2025 = 2,911,344 ÷ 2,465,228 = 1.18
FY2024 = 2,955,298 ÷ 2,312,384 = 1.28
```
*判讀*：>1 代表賺到的是真金白銀不是應收帳款，**這項仍然健康**。⚠️ 本輪更正上一版誤植的 1.38。問題不在「有沒有收到現金」，而在「收到的現金全拿去蓋廠了」。

**⑨ 人民幣匯率敏感度（官方揭露值，非推估）**

| **DPS／每股股息** | Dividend Per Share | 每一股可以領到多少現金股利 |
| **殖利率** | Dividend Yield | 每股股息 ÷ 股價；等於「買一股，一年可以領回幾 % 的現金」 |
| **派息率** | Payout Ratio | 公司把賺到的錢拿出幾成配給股東；阜豐政策為「基本 35% ＋ 特別 5%」＝約 40% |
| **OCF／營業活動現金流** | Operating Cash Flow | 本業實際收進來、扣掉付出去之後剩下的現金 |
| **CapEx／資本支出** | Capital Expenditure | 買地、蓋廠、買設備所花的錢 |
| **FCF／自由現金流** | Free Cash Flow ＝ OCF − CapEx | **扣掉蓋廠買設備後，真正可以拿來配息或還債的現金**——本檔最重要的指標 |
| **配息覆蓋率** | Dividend Coverage（本檔自定義） | 每股自由現金流 ÷ 每股股息；小於 100% 代表配息超支、要靠借錢或動用老本 |
| **自定義 OPM** | Operating Profit ÷ Pretax Profit（AGENTS.md 自定義） | 營業利益 ÷ 稅前利益；衡量稅前獲利中有多少比例是本業賺的（越接近 100% 越乾淨） |
| **負債比率** | Total Liabilities ÷ Total Assets（AGENTS.md 自定義） | 負債總額 ÷ 資產總額；衡量公司欠了多少相對於它擁有的 |
| **ROE／股東權益報酬率** | Return on Equity | 淨利 ÷ 股東權益；股東每投入 1 元，一年賺回幾元 |
| **CAGR／年複合成長率** | Compound Annual Growth Rate | 把多年成長換算成「平均每年成長幾 %」 |
| **淨利現金含量** | OCF ÷ Net Profit | 帳上賺的錢有沒有真的收到現金；>1 代表獲利品質好 |
| **扣非淨利** | 扣除非經常性損益後的淨利 | 把處分利益、政府補貼、訴訟賠償等一次性項目扣掉後的淨利，更能看出本業真實實力 |
| **受限制銀行結餘** | Restricted Bank Balances | 質押給銀行當擔保（如開立銀行承兌匯票）而**不能自由動用**的存款 |
| **淨負債／淨現金** | Net Debt / Net Cash | 現金減掉有息負債；負數代表欠的比有的多 |
| **匯率敏感度** | FX Sensitivity | 年報揭露的官方數字：匯率變動 X% 時，淨利會變動多少 |
| **反傾銷稅** | Anti-dumping Duty | 進口國認為外國產品「賣得比成本還低」而課的懲罰性關稅；本案為歐盟對中國賴氨酸課 47.7%–58.2% |
| **盈利警告（盈警）** | Profit Warning | 港股制度：公司預期業績將大幅低於去年時，必須提前公告 |
| **翌日披露報表** | Next Day Disclosure Return | 港股制度：公司回購股份後，隔一個交易日必須公告明細 |
| **五年摘要** | Five-Year Summary | 港股年報慣例揭露的近 5 年損益、資產負債與財務比率彙整表，是官方認證的歷史數據來源 |
| **讀出指標** | Read-through Indicator | 用同業已公布的財報，推估還沒公布的公司大概會怎樣 |
| **低蛋白日糧** | Low-protein Diet（飼料政策） | 中國農業政策：減少豆粕用量、改加合成胺基酸；長期利多蘇／賴氨酸需求 |
| **CR3／CR5** | Concentration Ratio | 行業前 3 大／前 5 大廠商的市佔率合計；數字越高代表行業越集中、價格戰風險越低 |
| **Wind ESG 評級** | Wind ESG Rating | 萬得資訊對上市公司在環境、社會、公司治理三方面的評分；阜豐為 BBB（中等） |

| **期中加權平均股數** | Weighted Average Shares | 依股數在年度中存在的時間長短加權平均；官方每股盈餘用的分母 |
