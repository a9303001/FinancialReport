# 分化延续 驭势谋新

2026年第三季度大中华区物业摘要

作者

姚耀

钟楚如

往期报告

2026年前三季度，面对内外部多重挑战，中国经济总体保持平稳运行。前三季度，国内生产总值（GDP）同比增长4.6%。其中，三季度 GDP增速重回4.5%，比二季度回升0.2个百分点，优于市场预期。以高端制造、数智经济、现代服务等为代表的新动能对前三季度经济增长的贡献率继续保持在40%以上，新动能接续态势持续增强。9月，高技术制造业增加值增长强劲，同比增长15.3%，增速逐月提升。前三季度，出口同比增长16.4%，三季度单季增长22.3%。出口结构持续升级，高新技术产品出口增势亮眼。其中，前三季度集成电路出口同比增长99.1%。消费市场在前期修复后进入增速换挡阶段。前三季度，社会消费品零售总额同比增长1.1%，增速较上半年小幅回落0.2个百分点。服务消费动能持续释放，前三季度服务零售额同比增长5.0%。入境游消费持续扩容，1–7 月境外人员在中国消费同比增长 27.8%。

三季度，在甲级办公楼市场需求端，新经济赛道仍是需求增量核心支撑，人工智能及应用、半导体与智能终端、游戏与新零售等持续释放需求动能。短期内市场供应压力仍存，不同城市空置率走势分化。租金延续下行，板块间及楼宇间租金分化预计进一步加剧。零售市场，消费增速放缓、品类表现分化，入境游消费扩容为市场注入新增量。运动户外、潮玩杂货、消费电子租赁需求保持活跃，新鲜零食等新兴赛道快速崛起并加速渗透一线市场。服务消费类租户成为实体商业破解同质化竞争、发掘新增量的重要抓手。物流地产市场，整体需求保持韧性，部分市场经历需求结构性调整。供应压力区域分化，华南、华北新增供应维持高位。整体租金仍处下行区间，业主灵活定价策略延续。

- 甲级办公楼市场：新经济赛道仍为增量需求重要来源之一。新增供应持续入市，城市间空置率走势分化，部分城市阶段性回落。租金仍处下行通道，同比跌幅继续收窄，板块与楼宇间的分化进一步凸显。
- 优质零售地产市场：消费增长趋缓，品类表现分化，入境游消费持续扩容。运动户外、潮玩杂货、消费电子租赁需求活跃，新鲜零食等新赛道快速崛起并向一线渗透。服务消费租户成为实体商业破局同质化、挖掘新增量的关键。
- 物流地产市场：整体需求平稳，华南部分市场受跨境电商策略调整影响，经历结构性调整。新增供应压力区域分化，主要集中于华南及华北市场。租金持续深度调整，业主延续灵活定价策略以吸引新租户并巩固核心租户关系。
