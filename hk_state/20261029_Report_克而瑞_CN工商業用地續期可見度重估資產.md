 核心观点

 工商业用地续期正从“规则模糊、实施细则缺位”状态，转向“中央定调+地方试点+立法推进”的制度化通道；但续期不是普惠性自动续命，而是以绩效、规划和负面清单为门槛的“条件性常态化”。

 1. 中央信号逐级加码，续期从“定方向”进入“立法规”。2024年7月党的二十届三中全会首提“制定工商业用地使用权延期和到期后续期政策”，2026年“十五五”规划《纲要》进一步要求“完善法律法规、依法稳妥推进”，《城市房地产管理法》修法亦列入立法计划。中央层面已从方向性表态转向立法与制度框架建设。

 2. 地方演进呈三阶段：从“个案补丁”走向“可复制框架”。 2004—2015年以深圳、萧山为代表，针对历史遗留个案零星突破；2018—2021年海宁、嘉峪关、兰陵等地形成相对统一的“范围+年限+价款”框架；2024年至今进入深化创新期，一线城市和更多市级政府集中出台制度，续期资格、年限、折扣与产业绩效、规划符合性、投资强度深度绑定。

 3. 计价与折扣高度分化，但治理逻辑趋同。分化的是“怎么算钱”，趋同的是“续不续、续给谁”。绩效、规划、负面清单成为共同门槛，续期实质是地方政府对存量产业载体的再筛选工具。

 4. “续期可见度”正在成为新的定价分层标准。已完成续期、成本锁定的资产，与路径清晰但未办理的资产，以及受规划、绩效、权属制约、续期可见度低的资产，估值和风险定价明显分化。分物业看，核心区自持购物中心/优质商办偏利好，自持产业园/标准厂房中性偏利，老旧专业市场/低效批发物业承压，散售分割商铺/散售商办风险最高。

 5. 续期影响的核心，是从“不确定性折价”转向“续期期权可计价化”，但并非普惠估值修复。规则化的首要财务意义，是把土地到期从资产负债表尾部风险转化为可测算的续期成本和可定价的续期期权。估值效应高度取决于剩余年限与续期成本的关系。

 6. 趋势研判：续期治理工具箱正在形成，但“条件性常态化”是方向。续期以绩效达标、规划符合、无负面清单情形为前提，地方政府角色从“到期处置者”转向“长期预期管理者”，但保留筛选权；土地财政向绩效治理转型的方向成立，但转型是条件性的、渐进的。

### 研究背景与中央政策信号

 规则模糊与实施细则缺位

 《民法典》第三百五十九条规定，非住宅建设用地使用权期限届满后的续期"依照法律规定办理"，地上房屋及其他不动产归属有约定从约定，无约定或约定不明则依法办理。《城市房地产管理法》第二十二条要求至迟于届满前一年申请续期，经批准准予续期的应重新签订出让合同并支付出让金。但"什么情况下可以续、可以续多久、价格如何确定"在实操中长期处于模糊状态。市场对续期价格和年限缺乏统一预期，是工商业存量资产定价的主要不确定性来源之一。

 中央层面的推进信号

 中央近两年密集释放信号，且呈逐级加码、从"定方向"到"立法规"的清晰路径：

 2024年7月，党的二十届三中全会《决定》明确"制定工商业用地使用权延期和到期后续期政策"；

 2026年3月，"十五五"规划《纲要》进一步提出"完善工商业用地使用权续期法律法规，依法稳妥推进续期工作"（同期《城市更新"十五五"规划》亦重申"依法稳妥推进工商业用地使用权续期，完善地价计收规则"）；

 2026年4月，全国人大常委会法工委确认《全国人大常委会2026年度立法工作计划》将修改《城市房地产管理法》列入民生领域修法清单。

### 地方政策演进的三阶段脉络

 基于各地已落地政策原文与试点实践，本文以标志性制度突破为划分节点，将地方演进脉络归纳为三个阶段，呈现出从“个案补丁”逐步走向“可复制框架”的路径。需要说明的是，三阶段为范式归纳而非连续编年，空档期以个案办理、上一阶段规则延续和政策酝酿为主，不代表无政策活动。

 早期探索（2004—2015年）：个案补丁，点状突破

 这一阶段针对的是特定类型、特定历史成因的零星到期地块，规则简单，尚未形成全域覆盖制度。

 深圳2004年《深圳市到期房地产续期若干规定》是国内最早的系统性尝试，适用于行政划拨性质且年期届满的工业、商业、办公乃至住宅房地产，在不改变用途前提下按相应用途公告基准地价的35%补交地价（按年期修正、可一次性支付或按年付租）。这一折扣在此后二十余年成为多地参照的“锚点”，但适用范围限于划拨历史遗留项目，并不覆盖所有出让商业用地。杭州萧山2015年以萧政发〔2015〕60号（试行）起步，聚焦原出让年限低于法定最高、即将届满或已届满的工业地块，经2019、2022两轮修订后，新版办法于2025年10月起施行。

 规范推广（2018—2021年）：框架成型，有章可循

 地方政策开始给出相对统一的结构——适用范围、年限上限、价款计算三项要素同时明确。

 海宁2018年办法规定工业用地续期不超过30年、商业及其他不超过20年，原出让与续期年限之和不超过法定最高年限；续期费按办理时点土地市场评估价（结合亩产效益修正系数）的50%乘相应年期计算，并落地浙江首个商地续期实例（约3137元/平方米、续期20年）。嘉峪关2020年区分出让与租赁两种路径，出让续期工业不超过30年、商业及其他不超过20年，租赁长期不超过10年、短期不超过5年，价款以办理时点评估价为准。临沂兰陵2021年以阶段性清理行动推进，工业续期最长20年、自原合同到期日起算；其援引的市级规定于2023年更新，20年系数由0.70降至0.52。

 深化创新与精细化（2024年至今）：条件性常态化

 近两年政策不再满足于给出一个补缴公式，而是把续期资格、年限、折扣与产业绩效、规划符合性、投资强度深度绑定；参与主体从区县一级上移至一线城市和更多市级政府，节奏与中央信号高度同步。具体做法可归为五类：

 分类分档定期限：青岛西海岸按产业导向分档，重点产业链20年、鼓励类15年、限制类5年；杭州钱塘按亩均效益评级分档，A类20年、B类10年、C类4年、限制类3—4年。

 负面清单做准入：重庆綦江明确8种不予续期情形，采取“申请一宗办理一宗”，2026年9月配套出台续期地价确定规则。

 定价选择权前置：北京支持已履约产业用地协议续期，价格在“首次出让时地价”与“续期时基准地价评估”之间二选一，前后两次年期合计不超过50年。

 绩效决定资格：温州平阳与“亩均论英雄”挂钩，最近年度D类企业不符合续期条件；遂宁商业用地原则上均可续期，工业按是否正常生产分流，正常生产年限压缩至不超过20年，价款采用“双评估补价差”。

 折扣与底线分层：广州达标项目按基准地价/标定地价70%计收、一次最长20年，不达标全额计收并压缩年限；上海覆盖全品类非居住用地，价格不低于所在级别基准地价70%，并与绩效评级挂钩；佛山明确“弹性续期”导向；南京（2026.7征求意见稿）分类适用差价法，分割登记单元可由单个权利人分别申请。

### 城市间政策与实践横向比较

 比较维度框架

 为系统比较各地实践，本报告建立六个比较维度：①覆盖范围（仅工业 / 工商业并轨）；②续期年限上限；③计价基准（基准地价 / 标定地价 / 市场评估价 / 双评估）；④折扣系数（绩效挂钩的折扣比例）；⑤绩效挂钩抓手（投资强度、亩均评价、是否正常生产、绩效评级）；⑥不予续期情形。

### 代表城市政策逐条对照

 广州·上海·遂宁·北京·重庆綦江

 广州、上海、遂宁、北京、重庆綦江五城/地区分别对应五种差异化的续期模式，覆盖当前地方实践的主要取向。以下按统一对照维度逐条拆解。

 广州（2026.5《广州市工商业用地使用权续期管理试点方案》）

 -政策定位：工商业并轨、以自持为主要取向；聚焦越秀、海珠、荔湾等老城区剩余年限仅十余年、个别不足十年的专业市场与老商办。

 -覆盖范围：工业用地 + 商服用地，强调自持持有。

 -适用情形：出让合同约定的使用年期即将届满或已届满。

 -续期年限：达标项目一次续期最长20年；不达标工业按租赁方式不超过5年、商服不超过10年。

 -计价基准：工业用"同地段法定最高年限基准地价"；商服用"法定最高年限标定地价"（依标定地价系数修正法测算）；地下空间按基准地价。
