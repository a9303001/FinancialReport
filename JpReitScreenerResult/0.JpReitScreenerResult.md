## 附錄 A：白話名詞表
| 名詞 | 白話 |
|---|---|
| 分配金（DPU） | 每一口發給投資人的錢，一年 2 次 |
| NOI | 租金收入扣掉物業費用，分配金的源頭 |
| NAV 倍率 | 股價 ÷ 每口資產淨值；< 1 代表市價比估值便宜 |
| LTV | 借款占總資產比例；越高越怕升息 |
| 利益超過分配 | 發出去的錢超過當期賺的，差額等於退還本金 |
| 贊助商（スポンサー） | 背後的不動產集團，提供物件與信用 |
| 總費用率（TER） | 一年付給資產運用公司、保管銀行等的費用 ÷ 總資產 |
| 資産運用報酬 | 付給資產運用公司的管理費，按總資產、NOI 或分配金計 |
| 取得報酬 | 買物件時付給資產運用公司的手續費，算進物件成本，損益表看不到 |
| セイムボート出資 | 贊助商自己也持有投資口，和投資人同一條船 |
