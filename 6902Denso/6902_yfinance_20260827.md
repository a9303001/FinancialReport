### 計算過程（逐項列式）

**負債比率（FY2026）**
```
Total Liabilities Net Minority Interest = 3,015,007 百万円
Total Assets                           = 8,730,854 百万円
負債比率 = 3,015,007 / 8,730,854 × 100% = 34.53%
```

**OPM（自定義公式 = 營業利益率 / 稅前淨利率 × 100%）**
```
FY2026 營業利益率   = 552,538 / 7,539,975 = 7.328%
FY2026 稅前淨利率   = 617,291 / 7,539,975 = 8.187%
OPM = 7.328% / 8.187% × 100% = 89.51%
```

**淨利 CAGR**
```
FY2023 Net Income = 314,633 百万円
FY2026 Net Income = 443,755 百万円
區間 = 3 年
CAGR = (443,755 / 314,633)^(1/3) − 1 = 12.15%
⚠️ yfinance 僅回傳 4 個年度，無法計算真正的 5 年與 10 年 CAGR。
```

### 變化原因（依公司公告與新聞查證）
1. **2024/11–2025/10 執行 4,500 億円自己株式取得**（每股回購金額約 179.5 円）→ FY2026 庫藏股大增 1.25 億股。
2. **2026/4/28 決議 3,136 億円自己株式公開買付（TOB）**，標的為豐田自動織機所持有之 DENSO 股份（每股約 125.1 円）→ 反映在現行 `sharesOutstanding` 較 FY2026 期末再減 6.87%。
3. **政策保有股（交叉持股）處分**：FY2026 售出 4,509 億円、縮減至 9 檔（每股約 179.8 円），與自社股回購形成配套的資本效率改善方案。

### 對 EPS 與股東權益的影響
- 股數 2 年累減 13.87%，**單靠股數減少即可推升 EPS 約 +16.1%**（1 / (1−0.1387) − 1），是 FY2026 EPS 由 145.02 → 162.96 円（+12.4%）的重要來源之一——**淨利只成長 5.9%，EPS 卻成長 12.4%，差距主要來自回購**。
- 但 FY2027 Q1 股東權益比率已由 FY2026 的 62.9% 降至 **58.1%**（TOB 支出所致），代表回購以帳上權益換取每股價值，未來續行大規模回購的空間受限。
- `floatShares` 僅 851,289,702 股（約占 33.9%），內部人持股 27.34%、法人 31.50%，實際流通籌碼偏少。
