## 3. 計算與拆解（公式／來源／假設）

### 3.1 FY2025 營收 +29.6% 但母公司淨利 −1.6% 的背離（FY2026Q1 已現反轉）
- **FY2025 事實**：營收 592.01→767.07 億円（+29.6%）、經常利益 +6.2%，母公司淨利 94.47→92.97 億円（−1.6%）。
- **三大原因**：①非支配股東損益（有研硅42.9%＋山東有研半導体材料15%等）合計仍達32.42億円；②持分法虧損（SGRS）由6.85億円擴大至10.82億円；③CAPEX前置使營益率22.1%→18.6%。
- **FY2026Q1 反轉訊號**：營收+8.7%、營益+21.0%、經常利益+30.6%、母公司淨利+12.2%——獲利成長首度重新超車營收成長，顯示先行投資效益開始顯現（詳見§4）。

### 3.2 OPM（自定義）＝ 85.8%（FY2025）／85.5%（2026Q1）
- 公式：OPM = 營業利益率 ÷ 經常利益率 ×100。
- FY2025：14,281/76,707=18.62%；16,635/76,707=21.69%；OPM=18.62/21.69×100=85.8%。
- 2026Q1：3,630/19,153=18.96%；4,247/19,153=22.18%；OPM=18.96/22.18×100=85.5%（穩定）。

### 3.3【本輪重算】有研硅佔 RS 淨利比重 — 由持分法框架改為合併框架
- **依據**：RS FY2025 有価証券報告書「関係会社の状況」明載「有研半導体硅材料股份公司（中華人民共和国北京市）」列於「（連結子会社）」項下，議決権所有割合 **57.1%（内書30.9%為間接持有）**；FY2024報告同為連結子会社，57.2%。
- **計算**：有研硅 FY2025 歸母淨利 2.09億元 RMB ×24.08(CNY/JPY) = 50.33億円；RS 應佔 = 50.33×57.1% ≈ **28.74億円**。
- **佔比** = 28.74 / RS FY2025 母公司淨利 92.97億円 = **≈30.9%**；每股化 = 28.74億円÷26.567M ≈ **108円/股**（EPS 351.40円中，近3成源自有研硅併表貢獻）。
- **交叉驗證**：RS FY2025 合併損益表「非支配株主に帰属する当期純利益」= 32.42億円（官方数字）。拆解：有研硅NCI(42.9%×50.33億)≈21.6億 ＋ 山東有研半導体材料有限公司NCI（FY25持股85%,NCI15%，該公司FY24淨利51.5億円量級推估NCI≈7-8億）＋其餘小額子公司 ≈ 合計約32.3億円，與官方32.42億円高度吻合，驗證57.1%合併框架正確，**前版「持分法30.84%／16.8%」應予推翻**。
- **需注意的另一實體（勿混淆）**：山東有研RS半導体材料有限公司（SGRS，中國12吋再生晶圓JV）才是真正「持分法適用関連会社」（FY2025持股28.1%），且是**投資虧損**（見§2 Q3、§4），與有研硅（プライムウェーハ、合併認列）性質相反。

- **包頭子公司資本額**：4億人民元×24.08(CNY/JPY)＝96.3億円÷26.567M≈**362.5円/股**（資本投入，非當期費用，need視後續資本支出時程分期認列）。
- 兩筆交易均為**現金流出、非立即獲利貢獻**，其財務影響已反映於§2 Q3與§4多空對照，暫不影響本輪EPS/淨利預估。
