### 2.2 核心結論（3 句話）

1. **本業（再生晶圓）是真材實料**：全球市占 31% 世界第一、營益率 36.9%，且三年產能 +72.5% 的擴產計畫有官方逐年 capex 對應（520 億日圓，每股 1,955 円），資金來自 733 億日圓淨現金（每股 2,756 円）＋三年 530 億日圓營業 CF（每股 1,993 円），**不需增資**。
2. **中國子公司是最大的雙面刃**：GRITEK 貢獻 RS EPS 約 20–25%，但本身「增收不增利」；其 A 股市值 460 億人民幣（PE 220 倍）換算後，RS 的 40.96% 經濟持分每股隱含 **17,149 円**——是 RS 現價 6,270 円的 **2.74 倍**。這不是「便宜」，而是**市場正確地拒絕承認 A 股泡沫價**（見 §3.5 的雙向試算）。
3. **轉機訊號已確立但估值不再便宜**：2026 Q1 獲利成長（+12.2%）重新超越營收成長（+8.7%），營益率回升、負債比率降至 21.3%；但股價自 2/17 低點 3,415 円漲到 7/8 高點 8,650 円（+153%），現回檔至 6,270 円（距高點 −27.5%），預估 PE 16.7 倍已反映多數轉機。

### 3.4 OPM（自定義公式）

```
OPM(%) = (營業利益率 ÷ 稅前淨利率) × 100%
```

| 期別 | 營業利益率 | 稅前淨利率（税金等調整前） | **OPM** | 舊版口徑（分母＝経常利益） |
|---|---|---|---|---|
| FY2024 | 13,108÷59,200 = 22.14% | 17,168÷59,200 = 29.00% | **76.4%** | 22.14÷26.47 = 83.7% |
| FY2025 | 14,281÷76,707 = 18.62% | 16,868÷76,707 = **21.99%** | **84.7%** | 18.62÷21.69 = 85.8% |
| 2026 Q1 | 3,630÷19,153 = 18.95% | 4,247÷19,153 = 22.18% | **85.5%** | 同（Q1 無特別損益，経常＝税前） |

> **修正說明**：AGENTS.md 的「稅前淨利率」應對應日本會計的「税金等調整前当期純利益」，非「経常利益」。FY2024 兩口徑差異最大（76.4% vs 83.7%），因該年有負商譽等特別利益。**FY2025 OPM 由 76.4% → 84.7% 大幅改善**，代表營業外的補助金／匯兌等非本業依賴度下降，獲利品質變好。

### 3.5 估值錯位試算（本輪新增・重要）

**上行情境（以 A 股市價認列 GRITEK）**
```
GRITEK 總市值 = 460.36 億人民幣 × 24.19 = 11,136 億日圓
RS 經濟持分價值 = 11,136 億 × 40.96% = 4,561 億日圓
每股隱含價值 = 4,561 億 ÷ 26,597,600 股 = 17,149 円/股
→ 是現價 6,270 円的 2.74 倍（單靠這一項）
若改用議決權 56.1% 基礎：6,247 億円 → 23,487 円/股
```

**下行情境（把 GRITEK 重評到 RS 自身 PE 16.7 倍）**
```
GRITEK 合理市值 = 歸母淨利 2.09 億人民幣 × 16.7 = 34.9 億人民幣 = 844 億日圓
RS 持分價值 = 844 億 × 40.96% = 346 億日圓 = 1,300 円/股
```

**→ 兩情境差 13.2 倍（17,149 円 vs 1,300 円）。這正是為什麼「RS 市值遠低於中國子公司持分市值」不能當買進理由**：差額幾乎完全來自 GRITEK 的 PE 220 倍泡沫，而非 RS 被低估。日本 Yahoo 掲示板流傳的「權利價值超過 5,000 億円、股價有 2–3 倍空間」論述，正是踩在這個陷阱上。

**清醒版估值（本業基礎）**
```
RS 時價總額 1,668 億円 − 淨現金 733 億円 = EV 935 億円（每股 3,515 円）
再生事業 FY2025 營業利益 101.67 億円（每股 382 円）

即：以 9.2 倍營益買下全球市占 31% 的再生晶圓龍頭，GRITEK 與其他事業全部免費。
```
> ⚠ **此算式的重大保留**：733 億円淨現金為**合併數**，其中相當比例實質屬於少數股東（非支配株主持分達 775 億円／每股 2,914 円，且大多在 GRITEK）。RS 母公司可自由動用的現金遠低於 733 億円。此數字不宜直接當「母公司帳上現金」使用。
