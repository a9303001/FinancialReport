## 2. 最新結論摘要

### 2.0 三句話看懂（白話總結，完全不用術語）

1. 這家公司主要的生意，是把半導體工廠用過的舊矽晶片回收、洗乾淨磨平之後再賣回去重複使用；這門生意毛利很高、規模全球第一，是最穩定的搖錢樹。
2. 最近一季賺錢的速度（＋12%）已經跑贏收入成長的速度（＋9%），欠的錢也變少了，體質比一年前健康；**但股價最近 10 天大漲 14.5%，已經從「便宜」變成「有點貴」了**（本益比從 17 倍拉到 19 倍，比過去五年的常態 10.7 倍高出一大截）。
3. 最該擔心的有三件事：一是股價已經先跑，好消息大多反映了，**再追的風險報酬比不如 10 天前**；二是帳上看起來很多的現金，**其實有一大半是中國子公司的其他股東的**，母公司能自由動用的比帳面數字少了快三成；三是它最近開始把錢花到跟本業無關的地方——花 80 億日圓去蓋一座 2029 年才會發電的大電池，還花 107 億日圓買下一家去年幾乎沒有營業額、還在虧錢的中國公司。（至於中國那家子公司股價貴到離譜、要近 200 年才回本的老問題還在，只是這 10 天它跌、母公司漲，兩邊的價差已經縮小了。）

### 2.2 核心結論（3 句話）

1. **本業（再生晶圓）是真材實料**：全球市占 31% 世界第一、營益率 36.9%，三年產能 +72.5% 的擴產有官方逐年 capex 對應（520 億円，每股 1,955 円），資金來自淨現金與營業現金流，**不需增資**。
2. **中國子公司是最大的雙面刃**：GRITEK 貢獻 RS EPS 約 18–22%，但本身連續三年獲利衰退；其 A 股市值換算後，RS 的 **39.1%** 經濟持分每股隱含 **14,113 円**——是 RS 現價 7,180 円的 **1.97 倍**（上一版 2.61 倍，本輪因 GRITEK 跌、RS 漲、人民幣貶而收斂）。這不是「便宜」，而是**市場正確地拒絕承認 A 股泡沫價**（見 §3.5 雙向試算）。
3. **轉機訊號確立，但估值已由便宜轉貴，現金品質與資本配置紀律仍不如帳面好看**：2026 Q1 獲利成長（+12.2%）重新超越營收成長（+8.7%）；但股價 10 天內急漲 +14.5% 至 7,180 円，**預想 PE 拉到 19.1 倍（前版 16.7 倍）、扣掉少數股東後的真實 EV 倍數升到 13.64 倍（前版 11.35 倍）**（§3.5）——轉機大多已反映在價格；而先前兩個月內承諾的 **187.3 億円（每股 704 円）**非本業投資（「2029 年才發電的儲能」與「幾乎沒有營收的中國外延片廠」）仍是最值得盯的紀律風險（§3.2.2、§3.7e）。**08/13 上半期決算是驗證轉機能否撐住這個估值的即期關鍵。**

### 3.4 OPM（自定義公式）

```

      ＝ 營業利益 ÷ 稅前淨利（分母同為營收，可直接約分）
```

```
【步驟 1】GRITEK 淨現金（FY2025 末，GRITEK 2025 年報）
  貨幣資金 6.6687 億元 ＋ 交易性金融資產 8.2434 億元 = 14.9121 億元

【步驟 2】其中不屬於 RS 母公司股東的部分（用官方持分 39.1%）
  346.4 億円 × (1 − 39.1%) = 346.4 × 60.9% = 211.0 億円 → 每股 793 円

【步驟 3】母公司股東實質可支配淨現金
  733 億円 − 211.0 億円 ≈ 522.0 億円 → 每股 1,963 円（僅為帳面 2,756 円的 71.2%）

【步驟 4】重算 EV（企業價值）與本業估值倍數
  EV = 時價總額 1,909 億 − 522.0 億 = 1,387 億円 → 每股 5,214 円
```

```
【買到的帳面淨值】

【溢價（未來大概率認列為商譽）】
  4.5071 − 1.03734 = 3.46976 億元 ≈ 3.47 億元
  × 23.72 = 82.3 億円  → RS 每股 309 円

【付出的股價淨值比 PBR】
  4.5071 ÷ 1.03734 = 4.34 倍
```

|---|---|---|
| 付出的 PBR | **4.34 倍** | 🔴 買方 GRITEK 自己的 PBR 是 10.2 倍（泡沫價），但**標的沒有營收也沒有獲利**，4.34 倍很難用資產價值解釋 |

### 3.7(f) 🆕 成長率的口徑陷阱：GRITEK 到底是 +18% 還是 +36%？

**(b) 為什麼會這樣 — 一句話：因為 RS 把自己的日本子公司賣給了 GRITEK**

| 時間 | 事件 |


### 3.8 🆕 Q6 — 有研硅到底做不做 12 吋晶圓？

**(c) 一個最容易搞錯的地方：「刻蝕設備用矽材料」不是 12 吋晶圓**

> GRITEK 有 **29.74% 的營收（2.99 億元／每股 0.24 元／62.2 億円）**來自「刻蝕設備用矽材料」。這是賣給 **12 吋晶圓廠的蝕刻機**用的大尺寸矽電極、矽環等**耗材零件**——

## 7. 名詞對照表（Glossary）

> 這段在講什麼：本檔用到的所有縮寫、自定義指標、日文／中文財經術語，一次列出白話解釋，方便沒讀過這家公司年報的讀者查閱。

| 術語 | 全名（原文） | 白話解釋 |
|---|---|---|
| **EPS** | Earnings Per Share，每股盈餘 | 公司賺的錢 ÷ 股票總股數，代表「每一股幫股東賺了多少錢」 |
| **PE／本益比** | Price to Earnings Ratio | 股價 ÷ 每股盈餘，代表「要花幾年的獲利才能賺回買股票的錢」，越高代表越貴（或市場期待越高） |
| **PBR／股價淨值比** | Price to Book Ratio | 股價 ÷ 每股淨資產，代表「股價是帳面淨資產的幾倍」 |
| **BPS** | Book Value Per Share，每股淨資產 | 公司淨資產（資產減負債）÷ 股數 |
| **ROE** | Return On Equity，股東權益報酬率 | 淨利 ÷ 股東權益，代表「股東每投 1 元，公司能賺回多少」 |
| **加權平均淨資產收益率** | 中國財報用語，即加權 ROE | 分母用「按時間加權的平均淨資產」，是中國年報的法定揭露口徑 |
| **平均／期末自己資本（ROE 分母）** | — | 分母用「期初期末平均」還是「期末餘額」會算出不同 ROE；成長期用平均會算出較高值。本檔一律用有報的**平均**口徑 |
| **CAGR** | Compound Annual Growth Rate，年複合成長率 | 把「總成長幅度」平均攤到每一年，方便跨不同年數比較速度 |
| **TTM** | Trailing Twelve Months，過去 12 個月 | 用最近 4 個季度加總，而非單一年度財報 |
| **Forward EPS／預估 EPS** | — | 對「還沒發生」的未來一年獲利所做的預估，**不是實績** |
| **EV** | Enterprise Value，企業價值 | 時價總額 − 淨現金，代表「連債一起買下整家公司實際要付多少」 |
| **OPM（本檔自定義）** | — | ＝營業利益率 ÷ 稅前淨利率 ×100%（可約分成營業利益 ÷ 稅前淨利）。越高代表獲利越不依賴業外（匯兌、補助），品質越好。⚠ 中日會計口徑不同，兩國公司的 OPM 不可直接比較 |
| **負債比率** | — | ＝負債 ÷ 總資產 ×100%，代表資產有多少比例靠借錢／欠款支撐，越低越穩健 |
| **有価証券報告書（有報）** | Yūka Shōken Hōkokusho | 日本上市公司年度公告書，類似台股年報／美股 10-K，最權威的官方財報 |
| **決算短信** | Kessan Tanshin | 日本的季／年度「財報速報」，比正式有報更早公布 |
| **決算説明資料** | Kessan Setsumei Shiryō | 法說會簡報，含展望與產能規劃，官方一次資料 |
| **経常利益** | Keijō Rieki | 日本會計特有科目＝營業利益＋常態性業外損益（利息、匯兌），不含一次性特別損益 |
| **税金等調整前当期純利益** | — | 日本會計的「稅前淨利」（含特別損益），本檔 OPM 的分母 |
| **期中平均相場** | — | 日本會計換算海外子公司收益費用時用的「整個期間的平均匯率」，與期末即期匯率不同 |
| **持分法（權益法）適用関連会社** | Equity Method Associate | 持股通常 20%～50%，**不併入**合併營收，只按持股比例認列對方賺賠 |
| **連結子会社** | Consolidated Subsidiary | 持股／控制力超過門檻，子公司營收獲利**全部併入**，再扣「非支配股東」該拿的部分 |
| **非支配股東持分（少數股東權益）** | Non-Controlling Interests | 合併子公司裡不屬於母公司的那部分股權；即使 100% 併表，這部分利潤仍不屬母公司股東 |
| **第三者割当（第三方配售增資）** | — | 只把新股賣給特定對象（如策略夥伴），常用於併購或引入策略投資人 |
| **議決權** | Voting Rights | 股東會投票權比例，與「經濟持分」（實際分得獲利的比例）可能不同 |
| **科創板** | 上海證券交易所科創板 | 中國專為科技創新企業設的板塊，漲跌幅上限 **20%**（即散戶說的「20cm」） |
| **龍虎榜** | — | 中國交易所公布「當日成交異常」個股的券商營業部買賣明細，用來揭露主力動向 |
| **交易異常波動公告** | — | 中國股價短期漲跌過大時，公司必須發公告提醒風險 |
| **一致行動人** | Persons Acting in Concert | 名義上不同股東，但實際會共同決策的關係人，法規要求合計揭露持股 |
| **摘牌（公開摘牌）** | — | 中國國有資產在產權交易所公開掛牌出售，由買方競價取得，屬公開交易程序 |
| **信用倍率** | — | 日股「融資餘額 ÷ 融券餘額」，越高代表借錢做多的人遠多於放空的人，籌碼偏多但獲利了結賣壓風險大 |
| **矽拋光片（Polished Wafer）** | — | 把矽晶棒切片、研磨拋光後的裸晶圓，是做晶片的基本原料 |
| **矽外延片（Epitaxial Wafer）** | — | 在拋光片表面再長一層更純的單晶薄膜，功率元件、CIS 等需要，單價高於拋光片 |
| **再生晶圓（Reclaimed Wafer）** | — | 把半導體廠用過的測試／控片回收，研磨清洗後再賣回去重複使用，RS 的本業 |
