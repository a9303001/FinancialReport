## 2. 最新結論摘要（直接回答第 1 節的核心問題）

### 2.0 三句話看懂（白話總結，完全不用術語）

1. 這家公司的主要生意是「把半導體工廠用過的舊矽晶片回收、清洗處理後再賣出去重複使用」，這門生意賺錢比例很高、而且做到全球規模最大，是公司最穩定的搖錢樹。
2. 最近這一季賺的錢成長速度（12%）已經超過營收成長速度（9%），代表賺錢效率在變好；公司欠的錢也變少了，體質比一年前更健康。
3. 最該擔心的是它在中國的一家子公司——這家中國子公司的股價最近暴漲暴跌、貴到不合理的程度（等於要 220 年才能靠賺的錢回本），如果這顆「中國泡沫」有一天破掉，市場原本覺得「母公司股價被低估」的想像空間會跟著消失；加上母公司股價已經從低點漲了超過一倍才回檔，現在買進的安全邊際比較薄。

### 2.2 核心結論（3 句話）

1. **本業（再生晶圓）是真材實料**：全球市占 31% 世界第一、營益率 36.9%，且三年產能 +72.5% 的擴產計畫有官方逐年 capex 對應（520 億日圓，每股 1,955 円），資金來自 733 億日圓淨現金（每股 2,756 円）＋三年 530 億日圓營業 CF（每股 1,993 円），**不需增資**。
2. **中國子公司是最大的雙面刃**：GRITEK 貢獻 RS EPS 約 20–25%，但本身「增收不增利」；其 A 股市值 460 億人民幣（PE 220 倍）換算後，RS 的 40.96% 經濟持分每股隱含 **17,149 円**——是 RS 現價 6,270 円的 **2.74 倍**。這不是「便宜」，而是**市場正確地拒絕承認 A 股泡沫價**（見 §3.5 的雙向試算）。
3. **轉機訊號已確立但估值不再便宜**：2026 Q1 獲利成長（+12.2%）重新超越營收成長（+8.7%），營益率回升、負債比率降至 21.3%；但股價自 2/17 低點 3,415 円漲到 7/8 高點 8,650 円（+153%），現回檔至 6,270 円（距高點 −27.5%），預估 PE 16.7 倍已反映多數轉機。


### 3.5 估值錯位試算（本輪新增・重要）

**上行情境（以 A 股市價認列 GRITEK）**
```
GRITEK 總市值 = 460.36 億人民幣 × 24.19 = 11,136 億日圓
RS 經濟持分價值 = 11,136 億 × 40.96% = 4,561 億日圓
每股隱含價值 = 4,561 億 ÷ 26,597,600 股 = 17,149 円/股
→ 是現價 6,270 円的 2.74 倍（單靠這一項）
若改用議決權 56.1% 基礎：6,247 億円 → 23,487 円/股
```

**下行情境（把 GRITEK 重評到 RS 自身 PE 16.7 倍）**
```
GRITEK 合理市值 = 歸母淨利 2.09 億人民幣 × 16.7 = 34.9 億人民幣 = 844 億日圓
RS 持分價值 = 844 億 × 40.96% = 346 億日圓 = 1,300 円/股
```

**→ 兩情境差 13.2 倍（17,149 円 vs 1,300 円）。這正是為什麼「RS 市值遠低於中國子公司持分市值」不能當買進理由**：差額幾乎完全來自 GRITEK 的 PE 220 倍泡沫，而非 RS 被低估。日本 Yahoo 掲示板流傳的「權利價值超過 5,000 億円、股價有 2–3 倍空間」論述，正是踩在這個陷阱上。

**清醒版估值（本業基礎）**
```
RS 時價總額 1,668 億円 − 淨現金 733 億円 = EV 935 億円（每股 3,515 円）
再生事業 FY2025 營業利益 101.67 億円（每股 382 円）

即：以 9.2 倍營益買下全球市占 31% 的再生晶圓龍頭，GRITEK 與其他事業全部免費。
```
> ⚠ **此算式的重大保留**：733 億円淨現金為**合併數**，其中相當比例實質屬於少數股東（非支配株主持分達 775 億円／每股 2,914 円，且大多在 GRITEK）。RS 母公司可自由動用的現金遠低於 733 億円。此數字不宜直接當「母公司帳上現金」使用。

### 3.6 5 年殖利率中位數（本輪精算，取代舊版概估）

**方法**：年末股價 = 該年 EPS × 有報揭露的「株価収益率」；殖利率 = 分割調整後 DPS ÷ 年末股價。

## 7. 名詞對照表（Glossary）

> 這段在講什麼：本檔用到的所有縮寫、自定義指標、日文／中文財經術語，一次列出白話解釋，方便沒讀過這家公司年報的讀者對照查閱。

| 術語 | 全名（原文） | 白話解釋 |
|---|---|---|
| **EPS** | Earnings Per Share，每股盈餘 | 公司賺的錢 ÷ 股票總股數，代表「每一股幫股東賺了多少錢」 |
| **PE／本益比** | Price to Earnings Ratio | 股價 ÷ 每股盈餘，代表「要花幾年的獲利才能賺回買股票的錢」，數字越高代表市場對未來成長的期待越高（也越貴） |
| **PBR／股價淨值比** | Price to Book Ratio | 股價 ÷ 每股淨資產，代表「股價是公司帳面淨資產的幾倍」 |
| **BPS** | Book Value Per Share，每股淨資產 | 公司淨資產（資產減負債）÷ 股數 |
| **ROE** | Return On Equity，股東權益報酬率 | 淨利 ÷ 股東權益，代表「股東每投入 1 元自己的錢，公司能賺回多少」 |
| **CAGR** | Compound Annual Growth Rate，年複合成長率 | 把「總成長幅度」平均攤到每一年的成長率，方便跨不同年數比較成長速度 |
| **TTM** | Trailing Twelve Months，過去 12 個月 | 用最近 4 個季度加總，而非用單一年度財報 |
| **Forward EPS／預估 EPS** | — | 公司或分析師對「還沒發生」的未來一年獲利所做的預估，**不是已經實現的實績數字** |
| **EV** | Enterprise Value，企業價值 | 時價總額 − 淨現金（或 + 淨負債），代表「若要買下整家公司（含還債），實際要付多少錢」 |
| **OPM（本檔自定義指標）** | Operating Profit Margin 相關自定義比率 | ＝營業利益率 ÷ 稅前淨利率 ×100%，衡量「本業獲利」占「稅前總獲利」的比重，數字越高代表獲利越不依賴業外（匯兌、政府補助等）收入，獲利品質越好 |
| **負債比率** | — | ＝負債 ÷ 總資產 ×100%，代表公司資產有多少比例是靠借錢／欠款支撐，數字越低代表財務越穩健 |
| **有価証券報告書（有報）** | Yūka Shōken Hōkokusho | 日本上市公司的年度公告書，性質類似台股的年報／美股的 10-K，是最權威的官方財報來源 |
| **決算短信** | Kessan Tanshin | 日本上市公司的季度／年度「財報速報」，比正式有報更早公布，類似台股的自結財報 |
| **決算説明資料** | Kessan Setsumei Shiryō | 公司法說會用的簡報資料，通常有經營層對未來展望、產能規劃等的詳細說明，官方一次資料 |
| **経常利益** | Keijō Rieki | 日本會計特有科目，＝營業利益＋業外收支中「常態性」的損益（如利息、匯兌），不含一次性特別損益 |
| **税金等調整前当期純利益** | — | 日本會計的「稅前淨利」，即繳稅前的全部淨利（含特別損益），本檔 OPM 公式的分母採用此科目 |
| **持分法（權益法）適用関連会社** | Equity Method Associate | 公司持股通常介於 20%～50%，**不併入**集團合併營收，只依持股比例認列「對方賺或賠的錢」到自己的損益表 |
| **連結子会社** | Consolidated Subsidiary | 公司持股／控制力超過門檻（通常 >50% 或有實質控制權），子公司的營收、獲利**全部 100% 併入**集團合併財報，再扣除「非支配股東」該拿走的部分 |
| **非支配股東持分（少數股東權益）** | Non-Controlling Interests | 合併子公司裡「不是母公司持有」的那一部分股權所對應的淨資產／損益，即使子公司 100% 併表，這部分利潤仍不屬於母公司股東 |
| **第三者割当（第三方配售增資）** | — | 公司發行新股，只賣給特定對象（如策略夥伴），而非公開對所有股東配股，常用於併購或引入策略投資人 |
| **議決權** | Voting Rights | 股東大會投票權比例，決定對公司經營決策的控制力，與「經濟持分」（實際分得的獲利比例）可能不同 |
| **龍虎榜** | — | 中國股市交易所公布「當日成交異常」個股的買賣券商營業部明細，用來揭露主力資金動向，登上龍虎榜代表交易異常活躍 |
| **交易異常波動公告** | — | 中國交易所規定股價短期內漲跌過大時，公司必須發布公告提醒投資人注意風險 |
| **一致行動人** | Persons Acting in Concert | 雖然是不同股東名義，但實際上會共同行動、一起決策的關係人，中國證券法規要求揭露其合計持股比例 |
| **信用倍率** | — | 日股信用交易中文「融資餘額 ÷ 融券餘額」，數字越高代表看多（借錢買進）的人遠多於看空（借股票賣出）的人，籌碼面偏多但也代表未來獲利了結賣壓風險較大 |
| **想定株価レンジ／理論股價** | — | 券商模型依財務指標（如 PBR、PER）反推出的「合理股價區間」，非官方保證，僅供參考 |
| **VRFB** | Vanadium Redox Flow Battery，釩液流電池 | 一種大型儲能電池技術，適合電網等級的長時間儲能，非本業半導體相關的新事業嘗試 |
| **GRITEK（有研硅）** | 有研半導体硅材料股份公司，688432.SH | RS Technologies 的中國連結子公司，於中國 A 股上海科創板掛牌，主要生產 8 吋矽晶圓 |
| **SGRS（山東有研艾斯）** | 山東有研 RS 半導体材料有限公司 | RS Technologies 以持分法（權益法）投資的中國 12 吋矽晶圓廠，RS 僅持股 28.1%、無控制權 |
| **扣非歸母淨利** | 扣除非經常性損益後歸屬母公司股東淨利 | 中國財報用語，把「一次性」的業外收支（如政府補助、資產處分）剔除後的「真實本業獲利」，比單純的歸母淨利更能反映經常性獲利能力 |
