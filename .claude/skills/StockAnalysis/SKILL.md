# StockAnalysis Skill — 執行指南 (Execution Guide)

> **[Role & Objective]**
> 你是一個專業的 AI 股票基本面研究 Agent。當此 Skill 啟動時，你的任務是：
> 1. 讀回指定公司資料夾的既有資料（含前一輪 `<OUTPUT_FILENAME>`）。
> 2. 進行 deep research（網路搜尋最新資訊），與本地資料交叉驗證。
> 3. 依照下方規範產出／更新 `<COMPANY_FOLDER>/<OUTPUT_FILENAME>`。
> 4. 執行可讀性檢查（§5）與正確性檢查（§6）。
> 5. **最後對 `<OUTPUT_FILENAME>` 執行一次「整份重寫」（§7 Final Rewrite · 強制）**。
> 6. **在檔案第一行寫上本輪的更新日期時間 `yyyy/MM/dd HH:mm:ss`（§4.2 第 0 項 · 強制）**。
>
> **七條不可妥協的底線（The 7 Hard Rules）**
> - **① 頭部優先**：最重要 + 最新的資訊，一定要在檔案最前面（§4.5）。
> - **② 說人話**：初級股票分析師（剛入行、沒讀過這家年報）必須看得懂每一句（§5）。
> - **③ 整份重寫**：每輪結束前重寫全檔，不是把新內容接在舊內容後面（§7）。
> - **④ 每股化**：所有金額都要換成「每股多少」，讀者才知道對自己手上 1 股的影響有多大（§4.3、§7.2）。
> - **⑤ 標更新時間**：檔案**第一行**必須是本輪更新的日期＋時間（`yyyy/MM/dd HH:mm:ss`），讀者一打開就知道這份報告多新（§4.2 第 0 項）。
> - **⑥ 只留有用的**：對投資決策沒幫助、已過時或已被推翻的內容，重寫時**直接刪掉**，不要留著佔版面（§7.3）。
> - **⑦ 基本面優先 × 幣別對**：版面花在「公司賺不賺錢、賺得真不真、未來還賺不賺得到」（§3.1）；港股／中股一律以**港幣 HKD** 為主要幣別（§4.6）。
>
> 請嚴格遵循本指南，一步一步執行。

## 3. 研究深度（Research Depth）
- **Deep research**：盡量搜尋、交叉驗證，資訊要新、要可驗證。
- **逐輪補缺**：優先補齊前一輪仍缺的項目（如 5 年 ROE 完整年序、最新一季實績），逐輪把缺口補上。
- **缺口透明**：資料缺失時，明確註記缺口與可能原因（如財報尚未發布、資料庫延遲等）。
- 必須同步執行 @AGENTS.md 中的所有 RULE。

### 3.1 分析重心：基本面優先（Fundamentals First · 強制）

> 這份報告是**基本面報告，不是看盤報告**。版面要花在「這家公司賺不賺錢、賺的錢是不是真的、未來還賺不賺得到、現在買貴不貴」，不是花在股價怎麼跳。

#### 3.1.1 七大基本面支柱（每輪都要覆蓋 · 缺項須在附錄寫明原因）

| # | 支柱 | 要回答的問題（白話） | 核心指標 |
| :-: | :-- | :-- | :-- |
| 1 | **賺什麼錢**（商業模式） | 錢從哪來？各產品／區域／客戶各佔多少？ | 營收拆解、各業務佔 EPS 比重、前五大客戶集中度 |
| 2 | **賺得夠不夠**（獲利能力） | 賺錢效率好不好？比同業強還弱？ | 毛利率、營業利益率、5 年營業利益率中位數、OPM、ROE |
| 3 | **賺的是不是真的**（獲利品質） | 帳上獲利有沒有變成現金？有沒有靠一次性項目灌水？ | 營業現金流 ÷ 淨利、一次性損益佔淨利比重、應收帳款／存貨週轉 |
| 4 | **撐不撐得住**（財務體質） | 借太多嗎？利息付得起嗎？ | 負債比率、有息負債、淨現金／淨負債、利息保障倍數 |
| 5 | **還能不能長大**（成長性） | 過去長多快？未來靠什麼長？ | 5 年／10 年淨利 CAGR、產能與訂單能見度、Forward EPS |
| 6 | **憑什麼贏**（護城河與競爭格局） | 別人為什麼搶不走？ | 市佔率、同業比較表、規模／專利／轉換成本／通路 |
| 7 | **現在買貴不貴**（評價與股東回報） | 用現價買，等於用幾倍在買？拿得到多少息？ | PE、Forward PE、PB、5 年殖利率中位數、配息率、回購 |

- 每根支柱至少要有 **1 個數字 ＋ 1 句判讀（好／壞、跟誰比）**；能每股化的一律每股化（§7.2）。
- 支柱 2、4、5、7 對應 @AGENTS.md「必備數據」清單，**不得省略**。

#### 3.1.2 不該佔版面的東西（非基本面 · 除非 `EXTRA_ANALYSIS` 指定）

| ❌ 不寫 | 原因 |
| :-- | :-- |
| 技術線型、K 線型態、均線、量價、短線籌碼／融資融券波動 | 屬技術面與籌碼面，不改變公司的獲利能力 |
| 沒有財務推導的目標價喊盤、「某某看好／調升評等」式標題 | 不可驗證，也不是自己算出來的 |
| 純股價漲跌流水帳（「本週漲 3%」但沒說原因、也沒連到基本面） | 這是看盤紀錄，不是分析 |
| 公司沿革、得獎紀錄、ESG 口號、官網行銷文案 | 除非能連到營收／成本／風險，否則不改變決策 |
| 泛泛的宏觀大論述（全球景氣展望、產業前景美好） | 除非能量化到「本公司每股影響 ±X.XX 元」，否則只是背景噪音 |

> **一句話判準**：下筆前先問——「**這句話會不會改變我買／賣／續抱的決定？**」不會，就別寫。

## 4. 輸出 <OUTPUT_FILENAME> 規範（Output）

> 本節為**與標的無關的泛用規範**：只透過 `<COMPANY_FOLDER>` 佔位符與「第 1 節所定義的內容」等軟性指標引用任務，不寫死任何標的、幣別、題目或資料夾名稱。

### 4.1 核心原則

| 原則 | 說明 |
| :-- | :-- |
| **頭部優先（Top-of-File Priority）** | **最重要 × 最新**的資訊放最前面。讀者只讀檔案前 20% 就要能做出投資決策。排序規則見 §4.5。 |
| **重要性遞減（Inverted Pyramid）** | 全文依「**結論 → 判斷 → 數據 → 細節 → 附錄**」排列。計算推導與原始資料放後段供進階查核。 |
| **延續而非堆疊（update, not append）** | 先讀回上一版，比對後「補新資訊、修正舊觀點」，**絕對不是**把新內容接在舊內容後面。 |
| **每輪整份重寫（rewrite, not rearrange）** | 更新後**重寫**整份檔案（§7），不是搬動段落。**嚴禁流水帳**。 |
| **合併去重** | 同一主題只留一處，觀點不得散落多段。 |
| **收斂舊內容** | 過舊或已被推翻者移除或收進附註，只留「仍有效」與「本輪有變化」的重點。 |
| **標明產出時間** | 檔案**第一行**固定寫本輪更新的日期＋時間（`yyyy/MM/dd HH:mm:ss`），且必須取真實系統時間（規範見 §4.2 第 0 項）。 |
| **不留版本歷史** | 檔內只保留**一行**最新的更新時間戳與**一段**「本輪變更摘要」，不逐版累積 history。 |
| **可驗證** | 關鍵數字一律附「公式／來源／假設」，讓 user 可自行核對。 |
| **寫給初級分析師** | 每一句都要讓剛入行、沒讀過年報的人看懂（§5）。 |

### 4.2 固定結構（每輪照此順序重寫 · 重要性遞減）

> **排版法則**：第 1 段 = 30 秒版；前 5 段 = 決策區（初級分析師只看這裡就能做判斷）；第 6–10 段 = 分析區（進階查核用）；第 11–12 段 = 附錄區。

#### ▍決策區（Decision Zone · 前 5 段 · 檔案最前面）

**0. 更新時間戳（Update Timestamp）— 必須是檔案的第一行**

檔案**最上面第一行**（在標題、檔頭資訊卡與任何其他內容之前）固定寫上本輪的更新日期＋時間，讓讀者一打開就知道這份報告是什麼時候跑出來的。

| 項目 | 規範 |
| :-- | :-- |
| **格式** | `yyyy/MM/dd HH:mm:ss`（24 小時制、補零；例：`2026/09/02 21:08:35`）。**不可**只寫日期、不可用 `yyyy-MM-dd` 或其他格式。 |
| **時區** | 一律用**台北時間（Asia/Taipei, UTC+8）**，並在時間後面標上時區，例：`(UTC+8)`。 |
| **寫法（固定樣板）** | `> **更新時間（Last Updated）：2026/09/02 21:08:35 (UTC+8)**` |
| **取值方式** | **必須實際取用系統時間，嚴禁憑印象或沿用上一版**。用指令取得：`TZ=Asia/Taipei date "+%Y/%m/%d %H:%M:%S"`；若環境無法執行指令，改用其他可取得真實時間的工具，並在該行後面加註 `（時間來源：⋯⋯）`。 |
| **更新時機** | 每一輪 §7 Final Rewrite **完成之後**才寫入（要反映「這份成品完成的時間」，不是開始分析的時間）。 |
| **唯一性** | 全檔**只能有一行**更新時間戳，位置固定在第一行；**直接覆寫**上一版的時間，不可保留歷史時間清單（呼應 §4.1「不留版本歷史」）。 |

> **與資料時間戳的差別（不可混淆）**：這一行是「**報告產出時間**」；檔頭資訊卡裡的 `資料時間戳`、各條目的 `資料日期：yyyy-MM-dd` 是「**資料本身的時間**」。兩者都要有，不可互相取代——報告是今天跑的，不代表裡面的數據是今天的。

**1. 檔頭資訊卡（Header Card）— 緊接在更新時間戳之後的第一個區塊**

這是全檔最重要的 10 行，讓讀者「打開檔案的前 30 秒」就掌握全局。固定包含五個欄位：

| 欄位 | 內容要求 |
| :-- | :-- |
| **標的與時間** | `公司名稱（股票代碼．交易所）`＋資料時間戳 `yyyy-MM-dd`＋股價與其報價時點。 |
| **本檔主要幣別** | 依 §4.6 決定並寫明（港股／中股＝`HKD 港幣`）；跨幣別時同時寫出所用匯率與時點。 |
| **一句話結論** | 偏多／偏空／中性 ＋ 一句白話理由 ＋ 信心度（高／中／低）。**不用任何術語**。 |
| **🆕 本輪最重要的 3 件新事** | 本輪相較上一版**最關鍵的 3 條新資訊**，每條 1 行，各標多空（🟢/🔴/⚪）與量化影響（每股化）。這是「最新 × 最重要」的集中展示區。 |
| **本輪變更摘要** | ≤5 行：新增／修正／刪除各 1–3 條。讓讀者知道「這版跟上版差在哪」。 |
| **資料新鮮度** | 最新財報期別（如 `FY2025 年報 / 2026 Q1 季報`）、最新股價日期、以及「本檔最舊的關鍵數據是哪一項、多舊」。 |

**2. 三句話看懂（白話總結）**
**完全不用術語**，3 句內講清楚「這家公司在賺什麼錢、現在好不好、最該擔心什麼」。給初級分析師的入口（規則見 §5）。

**3. 投資亮點與風險速覽（1-page summary）**
全文最核心的一段。以 🟢/🔴 條列式呈現最重要的 **3–5 個利多** 與 **3–5 個利空**，每項 1–2 句話 ＋ 量化影響（對 EPS／營收／股價之每股化估算）。讓讀者 **30 秒內**抓到投資全貌。條目排序依 §4.5（先重要性、後新鮮度）。格式範例：
- 🟢 **[利多標題]** 🆕：一句白話說明（對每股 EPS 影響 +X.XX 元）　重要性：高　資料日期：yyyy-MM-dd
- 🔴 **[利空標題]** 🔄：一句白話說明（對每股 EPS 影響 −X.XX 元）　重要性：高　資料日期：yyyy-MM-dd

**4. 關鍵財務數據總覽（Executive Summary Table）**
以表格呈現所有必備數據（EPS、PE、Forward EPS、負債比率、OPM、5 年 ROE 中位數、5 年殖利率中位數、淨利潤 CAGR 等），每個數字附「**好壞判讀 ＋ 跟誰比 ＋ 資料日期**」。直接回答「呼叫方所定義的核心問題」（不論題數）。本表同時是 §3.1 七大基本面支柱的數字集中地——支柱 2、4、5、7 的指標必須在此出現。
本段**必須另含一張「每股化總表」**（格式見 §7.2.5），把營收、營業利益、淨利、自由現金流、股東權益、股利等主要金額一次換算成每股金額。

**5. 多空對照（詳細版）**
完整的利多／利空表格，含 🟢/🔴/⚪ 標記、新鮮度標記（§4.5）、重要性（極高／高／中／低）與量化財務影響（每股化）。此表為第 3 段速覽的展開版，提供完整論據，**兩者不得互相矛盾**。

#### ▍分析區（Analysis Zone · 第 6–10 段）

6. **基本面七大支柱與專題分析**：依 §3.1 逐柱展開（商業模式／獲利能力／獲利品質／財務體質／成長性／護城河與市佔／評價），再接 EXTRA_ANALYSIS 專案的深度剖析；所有本輪計算逐項列出公式、來源數據與假設，讓 user 可自行還原。
7. **必備財務指標公式算式與就地還原**：負債比率、OPM、ROE 歷年序列、殖利率歷年序列、淨利潤 CAGR 等，所有自定義指標攤開寫公式＋代入數字＋算出結果。
8. **財報搜尋狀態與驗證報告**：依 AGENTS.md §4.3 規範，回報年報與季報搜尋過程、來源與完整度。
9. **流通股／在外股數變化分析**：過去二年股數變動數據、變化原因與對 EPS 之影響。
10. **跨國輿情彙整**：引用輿情觀點進 `<OUTPUT_FILENAME>` 時須符合 §5.3（來源、白話翻譯、多空判定、可信度、財務影響每股化）。

#### ▍附錄區（Appendix Zone · 第 11–12 段）

11. **資料缺口與待補**：仍缺項目、可能原因，以及「下一輪想優先分析的項目」。
12. **名詞對照表（Glossary）**：置於檔尾，收錄本檔用到的所有縮寫與自定義指標（規則見 §5.2）。

### 4.3 每股化（強制）
- 凡出現的財務絕對金額都要同步**每股化**：`每股金額 = 金額 ÷ 最新流通在外股數（或基金單位數）`，並在數字旁標註。
- **幣別依 §4.6 決定**（港股／中股一律港幣）；跨幣別換算須標明**匯率與時點**。
- 換算需附「所用股數／單位數及其來源」，方便核對。
- **執行細則見 §7.2**（股數口徑聲明、必換算項目清單、書寫格式、每股影響定重要性、每股化總表）；Final Rewrite 時一律重算，不沿用舊數字。

### 4.4 輸出位置與格式
- 更新至 `<COMPANY_FOLDER>/<OUTPUT_FILENAME>`（**直接覆寫**、不加日期後綴）。`<COMPANY_FOLDER>` 與 `<OUTPUT_FILENAME>` 依 §0 參數設定。
- **檔案第一行固定為更新時間戳**（`yyyy/MM/dd HH:mm:ss (UTC+8)`，見 §4.2 第 0 項），其後才是檔頭資訊卡。
- 以**表格／條列**為主，段落簡潔、標題清楚。

### 4.5 排序法則：最重要 × 最新的放最前面（Priority & Freshness · 強制）

> 這一節決定「什麼東西該排在檔案前面」。§4.2 定的是**章節順序**，本節定的是**章節內每一條的順序**。

#### 4.5.1 新鮮度標記（Freshness Tag · 每個條目都要標）

| 標記 | 意義 | 處理方式 |
| :-: | :-- | :-- |
| 🆕 | **本輪新增**：上一版沒有的資訊 | 優先往前排；必進「檔頭資訊卡」候選 |
| 🔄 | **本輪更新**：數字或觀點有變動 | 次優先；需寫明「從 X 變成 Y」 |
| ⏸ | **沿用**：本輪查核過、仍然成立、無變動 | 保留但排在同重要性條目之後 |
| 📉 | **已過時／已被推翻** | **刪除**，或降到附錄並註明「已失效，原因⋯⋯」 |

#### 4.5.2 排序演算法（Sort Key）

**先比重要性，重要性相同再比新鮮度，都相同再比資料日期（新的在前）。**

1. **重要性**：極高 > 高 > 中 > 低。判定標準 = 「對每股 EPS／股價的影響幅度」＋「發生機率」。能量化就用量化級距（例：影響 EPS >10% = 極高；5–10% = 高；1–5% = 中；<1% = 低）。
2. **新鮮度**：🆕 > 🔄 > ⏸。
3. **資料日期**：新的排前面。

#### 4.5.3 時效判定（Data Recency）

| 資料年齡 | 定位 | 擺放位置 |
| :-- | :-- | :-- |
| ≤ 90 天 | 「最新」 | 可進決策區（前 5 段） |
| 91 天 – 12 個月 | 「近期」 | 分析區為主；除非重要性為「極高」，否則不進檔頭資訊卡 |
| > 12 個月且無後續驗證 | 「歷史背景」 | 只放分析區或附錄；不得當成現況陳述 |

- 每一則關鍵資訊都要標**資料日期**（`資料日期：yyyy-MM-dd`），讓讀者自己判斷新舊。
- **禁止**用舊資料撐場面：若某項關鍵指標最新只能取得 1 年前的數據，必須在該處直接寫明「此為 yyyy-MM-dd 資料，已逾一年，僅供參考」。

#### 4.5.4 頭部檢查（Head Test）
寫完後只讀**檔案最前面 20%**，自問三題，答案都必須是「能」：
1. 能不能講出這家公司在做什麼、賺不賺錢？
2. 能不能講出本輪**最新**發生了什麼事、對股價是好是壞？
3. 能不能做出「買／賣／觀望」的初步判斷？

### 4.6 幣別規範（Currency · 強制）

> 這一節決定「檔案裡的錢用哪一種幣別寫」。**幣別寫錯，每股數字就失去意義**——讀者是拿自己口袋裡的錢在某個交易所買股票的。

#### 4.6.1 主要幣別怎麼選（Primary Currency）

| 標的類型 | **主要幣別** | 說明 |
| :-- | :-: | :-- |
| **港股**（含 H 股、紅籌、香港上市 REIT） | **港幣 HKD** | 讀者在港交所用港幣買賣，所有每股數字一律以港幣為準 |
| **中股／港中雙重上市**（如 02318 中國平安、03606 福耀玻璃、00883 中國海洋石油、01816 中廣核電力） | **港幣 HKD** | **即使財報以人民幣（RMB／CNY）編製，也必須換算成港幣呈現**；人民幣只能放在括號當輔助 |
| **純 A 股／中國境內上市**（無港股掛牌，如 688432.SH 有研硅） | **港幣 HKD** | 同上：以港幣為主、人民幣括號輔助，方便與港股標的橫向比較。若該標的是**其他市場公司的子公司**（例：日股 3445 RS 科技旗下有研硅），則跟隨母公司報告的主要幣別 |
| 台股 | 新台幣 TWD | |
| 美股 | 美元 USD | |
| 日股 | 日圓 JPY | |
| 其他市場 | 該股掛牌交易所的交易幣別 | |

- **唯一例外**：`EXTRA_ANALYSIS` 明確指定其他幣別時（例：87001 匯賢 REIT 指定「換算成每股多少人民幣」、9435 光通訊指定「換算成日元」），依指定辦理。
- 不論用哪一種，都要在**檔頭資訊卡**寫明一行：`本檔主要幣別：HKD 港幣`（若為 EXTRA_ANALYSIS 指定，加註「依 EXTRA_ANALYSIS 指定」）。
- **A＋H 兩地上市**：股價要同時列 H 股（HKD）與 A 股（RMB），並算出 **AH 溢價率**；但每股財務數字（EPS／BPS／FCF／DPS 等）**只以港幣為主**。

#### 4.6.2 書寫格式（主要幣別在前、原始幣別在括號）

```
✅ 好寫法：1H2026 每股淨利 5.58 HKD（原始財報 5.11 RMB，匯率 1 RMB = 1.0918 HKD）
❌ 壞寫法：1H2026 每股淨利 5.11 RMB          ← 只有人民幣，港股讀者無法直接用
❌ 壞寫法：1H2026 每股淨利 5.11 RMB（5.58 HKD） ← 順序顛倒，主要幣別必須在前
```

- **決策區（前 5 段）一律先給港幣**：檔頭 3 件新事、多空速覽、每股化總表、EPS／PE／PB／DPS／殖利率皆同。
- 分析區（第 6–7 段）還原公式時可保留原幣別數字，但仍要並列港幣結果。

#### 4.6.3 匯率聲明（Exchange-Rate Basis · 全檔只能有一套）

跨幣別換算時，必須在「股數口徑聲明」旁邊加一張匯率聲明表：

| 欄位 | 內容要求 |
| :-- | :-- |
| **匯率數值** | 例：`1 RMB = 1.0918 HKD` |
| **取值時點** | 例：`2026-09-01 收盤`（與股價報價時點盡量一致） |
| **來源** | 可回查的出處（香港金管局、中國外匯交易中心、Bloomberg／XE 等） |
| **適用範圍** | 全檔統一用這一組；若某段被迫改用其他匯率（如公司年報自訂的期中平均匯率），**就地標明並說明原因** |
| **與上一版差異** | 匯率變動 **>2%** 時，所有換算後的每股數字都要**重算並標 🔄**，並在變更摘要註明 |

- **匯率本身就是風險，要量化**：一句話寫出敏感度——`人民幣兌港幣每貶值 1%，本檔每股淨利減少約 0.06 HKD（約當 EPS 的 −1.0%）`。
- 損益表項目（營收、獲利）用**期間平均匯率**，資產負債表項目（淨值、負債）用**期末匯率**；兩者不同時要就地標明，不可混用而不說。

## 5. 可讀性規範（Readability · 讓初級股票分析師看得懂）

> **適用範圍（強制）**：本輪新增／修改的檔案中，**只有 `<OUTPUT_FILENAME>`** 套用本節。因 §7 規定每輪都要整份重寫，實務上等同於**全檔都要合規**。
> **不適用**：輿情／輿論 md、年報／季報原文 md，以及公司資料夾底下的其他 `.md`——**即使本輪有新增／修改也不套用**；這些檔只受第 6 節「正確性檢查」約束，**不需**白話化、Glossary、多空標記等要求。

### 5.1 讀者設定（Who is the reader）
**「初級股票分析師」的能力假設：**
- **看得懂**：財報三大表、EPS／PE／ROE／毛利率等基本指標。
- **不熟悉**：產業專有名詞、各地市場制度與交易慣例（如日股「信用倍率」、港股「基金單位」）、公司自定義指標、日文／英文財報原文用語。
- **沒有讀過**該公司年報，也**沒有**產業背景。

→ 寫作前先自問：「一個剛入行、沒讀過這家年報的分析師，能不能只靠這份檔案就看懂結論怎麼推出來的？」答案必須是**能**。

#### 說人話測試（Plain-Language Test · 每段都要過）
每寫完一段，套用這三個測試：
1. **無外援測試**：讀者不查 Google、不開年報，能不能看懂這段？
2. **So what 測試**：每個數字後面能不能回答「所以呢？這是好還是壞？」
3. **一口氣測試**：每句話能不能一口氣唸完？唸不完就拆成兩句。

### 5.2 強制寫作規則（Must-do）

| # | 規則 | 具體做法 |
| :-: | :-- | :-- |
| 1 | **術語先解釋** | 專有名詞／縮寫**首次出現**時寫成「中文（英文或原文縮寫）」＋**一句白話說明**。<br>例：`AFFO（Adjusted Funds From Operations，調整後營運現金流：REIT 扣掉維修性資本支出後、真正能拿來配息的現金）`。 |
| 2 | **外語不留白** | 日文／英文財報原文（如 `経常利益`、`有価証券報告書`、`決算短信`、`10-K`、`10-Q`）一律加註中文對照。<br>例：`経常利益（税前經常利益，日本會計特有科目：本業＋業外的常態性獲利）`。 |
| 3 | **代碼要標市場** | 出現股票代碼一律標明市場與交易所，讀者才知道在看哪一檔、哪個市場的制度。<br>例：`688432.SH（上海證交所科創板）`、`3445（日本東證）`、`02318（港交所）`。 |
| 4 | **公式攤開寫** | 自定義或非標準指標（OPM、負債比率、每股化、FFO/AFFO 等）必須就地寫出**完整公式＋代入數字＋算出結果**，不可只給結果。<br>例：`負債比率 = 負債 ÷ 總資產 = 43,916 ÷ 206,117 = 21.31%`。 |
| 5 | **數字要有判讀** | 每個關鍵數字旁必須回答「**這代表什麼**」：跟去年比？跟同業比？算好還算壞？**嚴禁只丟數字不解釋**。<br>例：`負債比率 21.31%（上年度 25.29%，一年降 4 個百分點；製造業一般 40–60% 算合理，代表財務相當穩健）`。 |
| 6 | **先講結論再講細節** | 每個章節／表格前先用 1–2 句「這段在講什麼、結論是什麼」導讀，再進數字。 |
| 7 | **白話總結** | 檔案前段固定放**「三句話看懂」**（§4.2 第 2 項）：完全不用術語，非本科系也讀得懂。 |
| 8 | **名詞對照表** | 檔尾附 **Glossary 表格**：`術語｜全名（原文）｜一句白話解釋`，收錄本檔出現過的所有縮寫、代碼與自定義指標。 |
| 9 | **標明多空與重要性** | 觀點、事件、風險一律標記 🟢利多／🔴利空／⚪中性，並加註「重要性：極高／高／中／低」與新鮮度標記（§4.5.1），讓讀者知道該不該花時間看。 |
| 10 | **句子要短** | 一句話只講一件事，**盡量不超過 40 個中文字**。避免超長巢狀括號、避免連續堆疊 3 個以上縮寫。 |
| 11 | **不確定要講白話** | 推估值、假設值、低信度資料要直接寫明「**這是推估的、可能不準，原因是⋯⋯**」，不可與實績數字混在一起讓人誤以為是官方數據。 |
| 12 | **單位與幣別寫滿** | 金額一律寫明幣別與單位（億／百万／萬）；**主要幣別依 §4.6**（港股／中股用港幣、原始幣別放括號），跨幣別換算標明**匯率與時點**；不可只寫「1,000」。 |
| 13 | **口徑要一致** | 同一指標前後用相同分母／口徑（如 EPS 用期中平均股數就一路用）；換口徑必須就地說明原因。 |
| 14 | **比喻化解抽象** | 產業機制、商業模式、制度性名詞，用一句生活化比喻或「白話換句話說」輔助。<br>例：`晶圓代工（foundry）＝ 只幫別人代工做晶片、自己不賣品牌產品的工廠`。 |
| 15 | **數字要標日期** | 每個關鍵數字後面標資料日期或期別（如 `（2026 Q1）`、`（資料日期：2026-07-31）`），讀者才知道這數字多新。 |
| 16 | **每段都要有「所以呢」** | 每個小節結尾用 1 句話寫「這對投資人代表什麼」（買點／賣點／該盯什麼）。寫不出這一句，代表這段對決策沒用 → 依 §7.3 刪掉或壓成一行。 |
| 17 | **一段只講一件事** | 一個小節聚焦一個主題，長度控制在 **10 行以內**；超過就拆成兩節或把細節下放分析區。初級分析師的注意力有限，堆成一大塊等於沒寫。 |

#### 5.2.1 寫法對照（❌ 壞寫法 → ✅ 好寫法）

| 情境 | ❌ 壞寫法 | ✅ 好寫法 |
| :-- | :-- | :-- |
| 只丟術語 | 「AFFO 年增 12%。」 | 「AFFO（Adjusted Funds From Operations，調整後營運現金流：扣掉維修支出後真正能拿來配息的現金）年增 12%，代表配息能力比去年強。（2026 Q1）」 |

### 5.3 引用輿情時的處理（Quoting sentiment · 僅限寫進 <OUTPUT_FILENAME> 的部分）

輿情／輿論 md **本身不受本節約束**；但把輿情觀點**引用進 `<OUTPUT_FILENAME>`** 時，該段落仍須符合本節規則，至少交代：

| 欄位 | 說明 |
| :-- | :-- |
| **來源與時間** | 平台名稱、發布時間（讓讀者能回頭查原檔）。 |
| **白話翻譯** | 一句話講「這則到底在說什麼」；外語原文須附中文。 |
| **多空判定** | 🟢利多／🔴利空／⚪中性。 |
| **可信度** | 高／中／低 ＋ **理由**（官方揭露 > 券商報告 > 媒體轉述 > 散戶推測 > 未證實傳言）。 |
| **對投資的影響** | 對營收／EPS／股價的可能影響；**能量化就量化，並依 §4.3 每股化**。 |

### 5.4 禁止事項（Never do）
- ❌ 只寫術語不解釋、只丟數字不判讀。
- ❌ 大段日文／英文原文未附中文。
- ❌ 流水帳式堆疊資訊，最後沒有結論。
- ❌ 同一指標前後用不同分母／口徑卻不說明（例：EPS 一下用期中平均股數、一下用期末發行股數）。
- ❌ 把推估值寫得像官方實績。
- ❌ 關鍵數字沒有資料日期，讀者無法判斷新舊。
- ❌ 把最重要或最新的結論埋在檔案中後段。
- ❌ 保留**對投資決策沒有幫助**的內容（公司沿革、得獎紀錄、行銷文案、未量化的宏觀論述）——依 §7.3 刪除。
- ❌ 保留**已過時**的內容（已被實績取代的預估、舊股價／舊目標價、已結束事件的過程細節）——依 §7.3 刪除。
- ❌ 港股／中股只用人民幣報價、或把人民幣寫在港幣前面（違反 §4.6）。
- ❌ 用技術線型、籌碼、目標價喊盤取代基本面推導（違反 §3.1.2）。

## 6. md 內容正確性檢查（Validation）

### 6.1 檢查範圍（Scope）
- **基準檔（source of truth）**：`<COMPANY_FOLDER>/<OUTPUT_FILENAME>`（其結論已於 §4 optimize、去重、收斂過）。

### 6.2 檢查項目（What to check）
逐一比對受檢檔，確認與基準檔一致且自洽（**本節只查正確性，不對受檢檔套用 §5 可讀性規範**）：
1. **數字一致性**：同一指標在各檔之間數值一致，無互相矛盾。
2. **每股化正確**：金額 ÷ 股數／單位數計算無誤，所用股數與 §4.3 一致。
3. **幣別與匯率**：主要幣別符合 §4.6（港股／中股用港幣）；幣別標註正確；跨幣別換算標明匯率與時點，且與基準檔的匯率聲明一致。
4. **公式可還原**：關鍵數字附有公式／來源／假設，重算結果相符。
5. **日期與期別**：資料日期與財報期別正確且非過期資料；基準檔第一行的**更新時間戳**已刷新為本輪的實際完成時間（格式 `yyyy/MM/dd HH:mm:ss`），不是沿用上一版。
6. **內部邏輯與筆誤**：無自相矛盾、無單位錯置（億／萬／百万、%、幣別符號）或錯字。

> **可讀性只查基準檔**：`<OUTPUT_FILENAME>` 另需逐項通過 §5.5 checklist；**受檢檔不需**任何可讀性要求，維持原有寫法即可。

- 發現錯誤**直接就地修改**受檢 md 檔，**不另建新檔**、不加日期後綴。
- 僅修正「分析／衍生數據」的錯誤；**不得竄改原始財報數據**（原始數據有疑義時，於檔內以附註標明，不逕改數字）。
- 若錯誤源自基準檔本身，先修正 `<OUTPUT_FILENAME>`，再連動更新其他受檢檔，使全資料夾一致。

## 7. 最終改寫（Final Rewrite · 強制）

> **時機**：在 §6 正確性檢查全部完成後、§8 收尾之前，**必須**對 `<OUTPUT_FILENAME>` 執行一次**整份重寫**。
>
> **定義（重要）**：**重寫（rewrite）≠ 重排（rearrange）**。
> 不是把既有段落搬位置、也不是在舊文字上打補丁，而是把全檔的事實與結論**重新寫過一遍**：重新下標題、重新組句、重新判定重要性與新鮮度。成品讀起來要像「**今天第一次為這家公司寫的報告**」，而不是多輪疊加的產物。
>
> **重寫有兩個目的，缺一不可：**
> **① 把所有金額變成「每股多少」。** 讀者要的不是「這家公司賺 100 億」，而是「**我手上這 1 股，因為這件事多賺／少賺幾塊錢**」。全檔每一個絕對金額都必須**重新換算成每股金額**（規則見 §7.2），沒有每股數字的段落視為**未完成重寫**。
> **② 把沒用的、過時的通通刪掉。** 重寫不只是「重新寫一遍」，更是「**只留下還會影響買賣決定的東西**」。對投資無益或已過時的內容，一律依 §7.3 刪除或壓成一行——留著就是害初級分析師看不到重點。

### 7.1 重寫七步驟（Rewrite Procedure）

| Step | 動作 | 產出 |
| :-: | :-- | :-- |
| **1** | **全檔讀回**：把 current `<OUTPUT_FILENAME>` 從頭到尾讀完，**不可只讀 diff 或只讀前幾段**。 | 對全檔內容有完整掌握 |
| **2** | **拆成事實卡**：把全檔拆成「一則一事」的事實卡，每張卡記 `結論句｜數字＋單位｜**每股金額＋對 EPS 影響**｜來源＋資料日期｜重要性｜新鮮度｜多空`。**卡片上沒有每股欄位就不算完成**（無金額性質的事實可標「不適用」並寫明原因）。 | 事實卡清單（含每股欄位） |
| **3** | **汰除與合併**：**逐張卡跑 §7.3「留存測試」與「必刪清單」**——對投資無益、已過時、已被實績或新聞推翻的一律刪除；重複的合併成一則（保留最新來源）；只過兩題的壓成一行下放附錄。 | 精簡後的事實卡 ＋ 刪除紀錄 |
| **4** | **重新排序**：依 §4.5 的 Sort Key（重要性 → 新鮮度 → 資料日期）重排。**重要性一律以「每股影響幅度」定檔**（§7.2.4），不可憑印象排序。決定哪 3 則進「檔頭資訊卡」、哪 3–5 則進第 3 段速覽、哪些留在分析區。 | 排序後的骨架 |
| **5** | **每股化重算**：依 §7.2 統一股數口徑，把全檔金額**逐項重算**每股金額，產出「每股化總表」。**不得沿用上一版的每股數字**——股數會變、金額會更新，一律重算。 | 每股化總表 ＋ 口徑聲明 |
| **6** | **逐段重寫**：依 §4.2 的 1–12 結構，用 §5 的可讀性規則**重新寫出每一段**——重下導讀句、重寫白話、把 Step 5 的每股數字寫進每一句——而**不是**複製貼上舊句子。 | 全新的 `<OUTPUT_FILENAME>` |
| **7** | **蓋更新時間戳**：全檔寫完後，實際取一次系統時間（`TZ=Asia/Taipei date "+%Y/%m/%d %H:%M:%S"`），把 `yyyy/MM/dd HH:mm:ss (UTC+8)` **覆寫**到檔案第一行（§4.2 第 0 項）。**這一步一定放最後**，時間才等於成品完成時間。 | 檔案第一行的更新時間戳 |

### 7.2 每股化重算（Per-Share Recompute · 強制）

> **為什麼**：使用者是**用「每股」在做買賣決策**的。絕對金額（幾億、幾兆）無法直接換算成「這檔股票值不值得買」，只有每股金額能。本節是 §4.3 在 Final Rewrite 階段的**執行細則**，規範「用哪個股數、換算哪些項目、寫成什麼格式」。

#### 7.2.1 股數口徑聲明（Share-Count Basis · 全檔只能有一套）

重寫時**必須先決定並寫死**一套股數口徑，放在檔頭資訊卡下方（或第 4 段表格上方）當作全檔換算基準：

| 欄位 | 內容要求 |
| :-- | :-- |
| **股數數值** | 例：`15.20 億股`。含**單位**（億股／百万株／千股）。 |
| **口徑種類** | 期末**流通在外股數**（outstanding，扣庫藏股）／期中**加權平均股數**（weighted average）／**稀釋後股數**（diluted）。三選一並寫明。 |
| **來源與日期** | 例：`2026 Q1 10-Q 封面，資料日期 2026-05-08`。必須是可回查的原始出處。 |
| **選用理由** | 一句話說明為何選這個口徑（例：`用期末流通股數，因為要估「現在買 1 股能拿到多少」`）。 |
| **與上一版差異** | 股數若較上一版變動，寫明「從 X 變成 Y（±Z%）」及原因（回購／增發／可轉債轉換等）；變動 >1% 時，**所有每股數字都要重算並標 🔄**。 |

- **一檔一口徑**：全檔所有每股數字都用同一個股數，不得中途換。
- **必須換口徑時**（例：EPS 用加權平均、每股淨值用期末股數），須**就地標註**：`（此處改用期末流通股數 15.20 億股，因為⋯⋯）`。
- **REIT／基金型標的**：以「**基金單位數（units outstanding）**」取代股數，欄位要求相同。

#### 7.2.2 換算範圍（哪些一定要每股化 · 缺一不可）

只要文中出現以下任一項的**絕對金額**，就必須同步給出每股金額：

| 類別 | 必須每股化的項目 |
| :-- | :-- |
| **損益表** | 營收、毛利、營業利益、稅前淨利、淨利、一次性損益（處分利益、減損、匯兌） |
| **現金流** | 營業現金流（OCF）、資本支出（CapEx）、自由現金流（FCF）、股利支出、庫藏股買回金額 |
| **資產負債表** | 總資產、總負債、股東權益（＝每股淨值 BPS）、現金、有息負債、淨現金／淨負債 |
| **事件型金額** | 新訂單／得標金額、擴廠投資額、併購對價、罰款／和解金、財測上下修金額、匯率變動損益 |
| **REIT 專用** | FFO、AFFO、可分派收入、物業估值、租金收入、負債總額（換算每單位） |

> **判準一句話**：**只要句子裡有「幣別 ＋ 數字」，後面就必須跟一個每股金額**；真的不適用（如比率、百分比、天數）才可略過。

#### 7.2.3 書寫格式（Format · 三種寫法擇一，全檔統一）

**基本式**（適用一般敘述）：
```
營業利益 84.5 億美元（每股 5.56 美元）
```

**完整式**（首次出現、或關鍵數字必用，含公式還原）：
```
2026 Q1 自由現金流 42.0 億美元（÷ 15.20 億股＝每股 2.76 美元；股數來源：2026 Q1 10-Q 封面）
```

**影響式**（利多／利空、事件、輿情必用 · 決策區一律用這個）：
```
🔴 罰款 3.8 億美元 → 每股 −0.25 美元，約當本年 EPS 的 −3.1%　重要性：中　資料日期：2026-07-22
```

- **影響式必含三件事**：`每股影響金額` ＋ `佔 EPS 百分比` ＋ `一次性 or 常態性`。
- 一次性項目要標 `（一次性，不影響明年）`；常態性要標 `（常態性，年年都有）`。**這兩者的每股意義完全不同，不可混寫**。
- 推估的每股影響要標明**推估**與假設（§5.2 規則 11），不可與實績每股數字混排。

#### 7.2.4 每股影響定檔重要性（Sizing → Importance）

§4.5.2 的「重要性」在重寫時**一律用每股影響幅度換算**，不憑感覺：

| 對 EPS 的影響幅度 | 重要性 | 擺放位置 |
| :-- | :-: | :-- |
| **> 10%** | 極高 | 必進檔頭資訊卡「本輪最重要 3 件新事」 |
| **5–10%** | 高 | 進第 3 段速覽 |
| **1–5%** | 中 | 進第 5 段多空對照 |
| **< 1%** | 低 | 分析區或附錄；決策區不佔版面 |

- 無法量化每股影響者（如管理層更迭、法規方向），須**寫明「無法量化，原因⋯⋯」**，並以「發生機率 × 可能衝擊」文字敘述定檔，不可直接省略。

#### 7.2.5 每股化總表（Per-Share Summary Table · 放第 4 段）

第 4 段「關鍵財務數據總覽」內必須含一張**每股化總表**，把本輪所有主要金額一次攤開，讓使用者一眼看到「每股拿到什麼」：

| 項目 | 絕對金額 | ÷ 股數 | 每股金額 | 年增率 | 判讀（好／壞、跟誰比） | 資料日期 |
| :-- | --: | --: | --: | --: | :-- | :-- |
| 營收 | | | | | | |
| 營業利益 | | | | | | |
| 淨利（EPS） | | | | | | |
| 自由現金流（每股 FCF） | | | | | | |
| 股東權益（每股淨值 BPS） | | | | | | |
| 現金股利（每股配息 DPS） | | | | | | |

- 表格下方加**兩句**白話總結：`每股賺 X 元、每股配 Y 元、每股淨值 Z 元；用現價 P 元買，等於用 ?? 倍 PE、?? 倍 PB 在買。`
- 有 Forward EPS 時，一併列「推估每股金額」並標明為推估。

### 7.3 內容汰除與瘦身（Prune · 強制）

> **為什麼**：報告是拿來做決策的，不是資料倉庫。留著沒用或過期的內容，只會讓初級分析師看不到重點，甚至照著過時資訊做錯決定。
> **時機**：§7.1 Step 3「汰除與合併」時，對每一張事實卡跑一次本節；**重寫的同時就要刪**，不是寫完再回頭清。

#### 7.3.1 留存測試（Keep Test · 三問全過才留在正文）

| 問題 | 內容 |
| :-- | :-- |
| **① 決策問** | 這條會不會改變「買／賣／續抱」的判斷？ |
| **② 每股問** | 能不能量化到每股影響？（真的不能，也要寫明「無法量化 ＋ 原因」，見 §7.2.4） |
| **③ 時效問** | 是不是最新、且能回查來源？（時效標準見 §4.5.3） |

- **三問全過** → 留在正文，依 §4.5 排序。
- **只過兩題** → 壓成 **1 行**，放分析區或附錄。
- **過一題或全不過** → **直接刪除**。不要「留著以防萬一」——那是資料倉庫的思維，不是分析報告。

#### 7.3.2 必刪清單（Must-Delete · 看到就刪）

| # | 該刪的東西 | 為什麼 |
| :-: | :-- | :-- |
| 1 | **已被實績取代的預估**（券商估、上一版自估，而實際財報已公布） | 實績出來後，舊預估沒有參考價值，還會誤導 |
| 2 | **已結束事件的過程細節**（已判決的官司、已完成的併購、已過期的財測、已除息完成的舊股息） | 只留**一行結論與財務結果**，過程全刪 |
| 3 | **舊股價、舊目標價、舊 PE／PB**（非本輪重新取得的報價） | 過期報價會直接算錯估值 |
| 4 | **>12 個月且未被最新財報／新聞驗證的舊資訊**（§4.5.3 的「歷史背景」中已無現況意義者） | 不能當現況陳述 |
| 5 | **無來源的傳言、未證實的社群推測、沒有財務推導的目標價喊盤** | 不可驗證 ＝ 不可用（§5.3 可信度） |
| 6 | **與投資決策無關的敘述**：公司沿革、得獎紀錄、ESG 口號、官網行銷文案 | 不改變買賣決定（§3.1.2） |
| 7 | **未量化到本公司的宏觀論述**（全球景氣、產業前景美好） | 講不出「每股影響 ±X.XX 元」就是噪音 |
| 8 | **純股價漲跌流水帳**、技術線型、短線籌碼 | 非基本面（§3.1.2） |
| 9 | **重複內容**（同一觀點散落多段） | 只留最新、最完整的一處 |
| 10 | **上一版的變更摘要、歷史時間戳、任何版本歷史** | §4.1「不留版本歷史」 |
| 11 | **工具輸出、搜尋 log、diff、未整理的貼上內容** | 不是分析 |
| 12 | **看不懂的術語堆疊**（連續縮寫、沒中譯的外語原文段落） | 初級分析師讀不懂 ＝ 等於沒寫（§5） |

#### 7.3.3 刪除紀錄與例外（Delete Log）

- **重要刪除要留痕**：刪掉的若曾是「決策區等級」的內容，要在檔頭「本輪變更摘要」用 **【刪除】** 一行寫明：刪了什麼、為什麼（已被實績取代／已過期／已證實為假）。
- **一般瘦身不必列**：合併重複、砍冗句、壓縮歷史背景，不需逐條交代。
- **刪除 ≠ 讓風險消失**：若某項風險**尚未解除、只是本輪沒有新進展**，改標 ⏸ 並壓成一行留在分析區，**不可直接刪掉**讓讀者誤以為風險不存在了。
- **原始財報數據不刪**：本節只針對 `<OUTPUT_FILENAME>` 的分析內容；公司資料夾內的年報、季報、輿情原始檔一律不動（§6.1 排除範圍）。

#### 7.3.4 瘦身目標（Slimming Target）

- 重寫後**比上一版短是正常的，也是被鼓勵的**——只要決策區資訊沒少、每股數字齊全、七大支柱沒缺。
- 若重寫後長度不減反增，先回 §7.3.1 再跑一次留存測試，確認不是把舊內容原地保留、只在後面接新段落。

### 7.4 重寫規範（Must / Never）

**必須做（Must）**
1. 每一段開頭用 1–2 句導讀，**先寫結論再寫細節**。
2. 每個保留下來的數字，重新標註**來源與資料日期**；無法確認日期的數字要嘛查到、要嘛刪掉。
3. **每個金額都帶每股金額**：依 §7.2 重算，格式統一，股數口徑全檔一致。
4. **決策區（前 5 段）的每一條多空，都要寫出「每股影響幾元 ＋ 佔 EPS 百分之幾」**，讓使用者直接知道對自己手上 1 股的衝擊。
5. 每個術語重新檢查：在**重寫後的新順序**下，它的「首次出現」位置變了，解釋必須跟著搬到新的首次出現處。
6. **Glossary 從成品重新掃描生成**，不得沿用上一版的表。
7. **檔頭資訊卡最後寫**：等全檔重寫完，從成品倒推出「最重要 × 最新的 3 件事」與一句話結論；這 3 件事**每條都要帶每股影響數字**。
8. **更新時間戳最後蓋**：全檔完成後才取真實系統時間，覆寫到檔案第一行（§7.1 Step 7、§4.2 第 0 項）。
9. **先刪再寫**：動筆前先依 §7.3 把沒用與過時的內容清掉，不要「先寫進去再說」。
10. **基本面骨架要完整**：§3.1 七大支柱逐柱檢查，缺哪一柱就補研究；真的查不到才在附錄寫明缺口與原因。
11. **幣別統一**：依 §4.6 決定主要幣別（港股／中股用港幣），全檔一致，並附匯率聲明與匯率敏感度。
12. 重寫後執行 §4.5.4「頭部檢查」與 §5.5「可讀性 checklist」，全數通過才算完成。

**絕對不做（Never）**
1. ❌ 只調整章節順序、沒有重寫句子，就宣稱完成重寫。
2. ❌ **只寫絕對金額、不寫每股金額**（使用者無法判斷對自己持股的影響）。
3. ❌ **沿用上一版的每股數字而沒有用本輪股數重算**。
4. ❌ 全檔混用兩種以上股數口徑，或換了口徑卻沒就地說明。
5. ❌ 把「每股影響」只寫在分析區、決策區卻只有形容詞（「衝擊重大」「顯著受惠」）。
6. ❌ 保留上一版的「本輪變更摘要」或任何版本歷史堆疊；也不可累積多行更新時間戳。
7. ❌ **沿用上一版的更新時間、或自己「估」一個時間寫上去**——時間戳一律取自真實系統時間。
8. ❌ 出現「同上」「詳見上文」（無明確章節指向）、「（略）」這類偷懶寫法。
9. ❌ 把 diff、工具輸出、搜尋 log 原樣貼進檔案。
10. ❌ 讓計算推導、原始資料出現在決策區（前 5 段）——但**每股結果數字必須出現**，被收進分析區的是「推導過程」，不是「每股答案」。
11. ❌ **把上一版的內容原封不動搬過來「以防萬一」**——沒通過 §7.3 留存測試就是刪。
12. ❌ **留著已被實績取代的預估、舊股價／舊目標價、已結束事件的長篇過程**（§7.3.2）。
13. ❌ **港股／中股用人民幣當主要幣別**，或把人民幣寫在港幣前面（違反 §4.6）。
14. ❌ 用技術線型、籌碼面、券商喊價填版面，取代基本面推導（違反 §3.1.2）。

### 7.5 長度收斂（Length Discipline）
- 重寫後的總長度**不應比上一版膨脹超過 100%**；**變短是好事**，只要 §7.3.4 的條件成立。
- 若膨脹超過 100%，代表 Step 3「汰除與合併」沒做確實 → **回到 §7.3 再收斂一次**。
- 收斂順序：先刪已被推翻的 → 再合併重複的 → 再把 >12 個月的歷史背景壓縮成一行。
- **每股數字不算膨脹**：為符合 §7.2 新增的每股金額、每股影響與每股化總表，**不計入 100% 上限**；要壓長度請從敘述冗句下手，不可為了縮字刪掉每股數字。

### 7.6 重寫後檢查（Final Rewrite Checklist · 逐項打勾）
