## 2. 三句話看懂（白話總結）

1. **公司在賺什麼錢？** 大東建託是全日本最大的「租賃包租代管巨頭」，幫全日本地主蓋房子並包辦出租管理，靠著管理 128 萬戶房子、維持 97.9% 的超高入住率來賺取源源不絕的穩定服務費與租金。
2. **現在營運好不好？** 公司獲利穩健並持續創新高，配息率達 50% 且持續買回股票，雖然帳面負債看起來有 63.6%，但其中七成以上是不用付利息的「客戶預收款與準備金」，真正要付利息給銀行的負債只有 17.1%，財務非常安全。
3. **最該擔心什麼？** 日本少子化與空屋率居高不下（現已高達 13.8%），加上建材與工資大漲，可能讓鄉下地主蓋房意願降低，並考驗未來 35 年包租保證租金的調整能力；加上近期股價已大漲至 ¥3,601，殖利率降至 4.53%，安全邊際有所收斂。

## 3. 最新結論摘要

### 核心問題深度解答

#### Q1: 日本少子化與空屋率上升對公司代管業務的長期威脅及對 EPS 的影響？
- **現狀與結構威脅**：日本總家戶數已於 2023 年見頂反轉，總務省調查 2023 年全國空屋率已達 **13.8%**（史上最高，約 900 萬戶空屋）；野村總研預測 2043 年空屋率恐攀升至 25%。非都市圈（鄉村與郊區）人口流失尤為嚴重。
- **對包租代管業務（一括借上）的機制影響**：大東建託管理約 128–129 萬戶租賃住宅，入居率高達 97.9%。公司對地主承諾「35 年租金保證」，每 2–10 年會檢討並調整保證租金。若地方空屋率持續攀升，公司必須向地主提出「家賃減額（調降保證租金）」，這引發了地主抗爭與訴訟風險；若無法順利調降保證租金，則會直接侵蝕代管業務的營業利益率（目前約 11.7%）。
- **EPS 衝擊量化推估**：
  - 包租代管業務每年貢獻集團營運利益約 820 億日圓（每股約 ¥247.59）。
  - **情境推估**：若空屋率壓力導致平均合約保證租金被迫調降 1%，或代管毛利率下滑 1–2 個百分點，預估每年減少營業利益約 80 億–120 億日圓。
  - **每股 EPS 影響**：扣除稅額後，每股純利益（EPS）預估將受衝擊 **¥24.00–¥36.00 日圓**，約佔目前全年 EPS（¥299.01）的 **7.5%–12.0%**。
- **公司的因應對策**：轉向三大都市圈發展、提高多戶型住宅比重、導入 AI 用地開發工具「WHERE」、並跨足飯店與存量不動產開發事業（如 Ascot, THE Global, Unito 合作案）以減緩鄉村建設缺口。

#### Q2: 建築成本上漲與高負債率（約 63.6%）對利潤率及財務安全性的影響？
- **建材與工資成本上漲影響**：受鋼材、水泥價格上揚及日本營造業缺工（「2024 年問題」工時上限）影響，單位建築成本（坪單價）持續高企。這使得地主新建建物的投資報酬率下降，地主下單意願減弱，導致 FY2026 建設事業營業利益年減 4.2%（至 492.5 億日圓）。公司透過「提高售價、挑選高利潤案件」維護毛利率，但承接總量遭受壓抑。
- **高負債率（63.69%）真實結構與財務安全性**：
  - **帳面總負債**：8,709.04 億日圓（換算每股總負債 **¥2,674.64**），總負債比率 63.69%。
  - **有利息負債（銀行借款、社債、租賃債務）**：僅 **2,341.72 億日圓**（換算每股有利息負債 **¥719.17**），占總資產比率僅 **17.12%**。
  - **無息營運負債**：高達 **6,367.32 億日圓**（換算每股無息負債 **¥1,955.47**），占總負債比例高達 **73.11%**。主要包含包租修繕準備金（¥2,347.2 億）、預收租金（¥1,247.7 億）、未完工預收工程款（¥444.7 億）與租客押金（¥306.4 億）。
  - **結論**：63.69% 的負債率主要來自「商業模式運作產生的免費資金」，公司大量善用租客與客戶的預付款，利息負擔極低。即便日本央行升息，對公司直接利息支出的衝擊相當微小，財務安全性極高。公司更於 2026 年 7 月首度發行 3 年期個人社債鎖定低利率資金。

- **期中加權平均股數（損益表科目用）**：`331,195,031 股`（資料來源：FY2026 決算短信 p.3 注記）

### 4.2 每股金額計算公式與還原
1. **FY2026 營收每股化**：  
   $$\text{每股營收} = \frac{1,984,743 \text{ 百萬日圓}}{3.31195031 \text{ 億股}} = \mathbf{\yen 5,992.67}$$
2. **FY2026 營業利益每股化**：  
   $$\text{每股營業利益} = \frac{135,256 \text{ 百萬日圓}}{3.31195031 \text{ 億股}} = \mathbf{\yen 408.39}$$
3. **FY2026 母公司純利益（EPS）**：  
   $$\text{最新 EPS} = \frac{99,030 \text{ 百萬日圓}}{3.31195031 \text{ 億股}} = \mathbf{\yen 299.01}$$
4. **FY2027 預估 EPS**：  
   $$\text{預估 EPS} = \frac{108,000 \text{ 百萬日圓（公司指引）}}{3.31195031 \text{ 億股}} = \mathbf{\yen 326.00}$$
5. **每股總資產**：  
   $$\text{每股總資產} = \frac{1,367,502 \text{ 百萬日圓}}{3.25615811 \text{ 億股}} = \mathbf{\yen 4,199.74}$$
6. **每股總負債與負債比率**：  
   $$\text{總負債} = 1,367,502 - 496,598 = 870,904 \text{ 百萬日圓}$$
   $$\text{每股總負債} = \frac{870,904 \text{ 百萬日圓}}{3.25615811 \text{ 億股}} = \mathbf{\yen 2,674.64}$$
   $$\text{負債比率} = \frac{870,904}{1,367,502} \times 100\% = \mathbf{63.69\%}$$
7. **有利息負債與無息負債每股化**：  
   - 有利息負債（借入金+社債+租賃負債）= $234,172 \text{ 百萬日圓}$
     $$\text{每股有利息負債} = \frac{234,172 \text{ 百萬日圓}}{3.25615811 \text{ 億股}} = \mathbf{\yen 719.17} \quad (\text{占總資產 } 17.12\%)$$
   - 無息營運負債 = $870,904 - 234,172 = 636,732 \text{ 百萬日圓}$
     $$\text{每股無息負債} = \frac{636,732 \text{ 百萬日圓}}{3.25615811 \text{ 億股}} = \mathbf{\yen 1,955.47} \quad (\text{占總負債 } 73.11\%)$$
8. **OPM（營運利潤品質比率）計算**：  
   $$\text{營業利益率} = \frac{135,256}{1,984,743} = 6.8148\%$$
   $$\text{稅前淨利率（經常利益率）} = \frac{139,169}{1,984,743} = 7.0119\%$$
   $$\text{OPM} = \frac{6.8148\%}{7.0119\%} \times 100\% = \mathbf{97.19\%}$$

## 8. 名詞對照表（Glossary）

| 專有名詞 / 縮寫 | 全名 / 原文 | 一句白話解釋 |
| :--- | :--- | :--- |
| **1878.T** | 大東建託株式會社（東證 Prime） | 日本最大的租賃住宅興建與包租代管上市公司，股票於東京證券交易所 Prime 市場交易。 |
| **一括借上** | 一括借上制度（35年包租） | 大東建託的核心商業模式：向地主承租整棟公寓 35 年，保證支付租金，並全權負責管理與維修。 |

| **入居率** | 出租率 / 入住率 | 管理的租賃住宅中實際有人承租居住的比例，大東建託長期維持在 97.9% 的超高水準。 |
| **家賃減額** | 租金調降爭議 | 定期檢討 35 年包租合約時，因市場行情下滑而向地主提出降低保證租金的要求，易引發糾紛。 |
| **経常利益** | 税前經常利益 | 日本會計特有科目，代表「本業營業利益 ＋ 常態性業外收支」的常態總獲利能力。 |
| **決算短信** | 季度/年度業績快報 | 日本上市公司依規定發布的官方財務簡報檔案（相當於美股 10-K/10-Q 快報）。 |
| **OPM** | Operating Profit Quality Margin | 本報告自定義指標：$\text{營業利益率} \div \text{稅前淨利率} \times 100\%$，用於評估營業利益占經常利益的比重（本業獲利純度）。 |
| **有利子負債** | 有利息負債 | 必須向銀行、債券持有人支付利息的負債（如短期/長期借款、公司債、租賃負債）。 |
| **非有利子負債** | 無息營運負債 | 營運過程中產生的不用付利息的負債（如預收租金、未完工工程款、修繕準備金、租客押金）。 |
