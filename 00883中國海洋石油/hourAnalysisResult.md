## 2. 三句話看懂（完全不用術語）

1. **它在賺什麼錢**：中國海油專門在海裡（不是陸地）鑽井，把原油和天然氣挖出來賣掉，2025 年賣了 3,982.20 億元人民幣（**每股 8.378 元 RMB／9.730 HKD**），是中國唯一有權和外國公司合作開發中國海域油氣的公司。
2. **現在賺得好不好**：非常好。挖一桶油的總成本只要 27.9 美元，賣價卻有 66–99 美元，2025 年淨賺 1,220.82 億元人民幣（**每股 2.569 元 RMB／2.984 HKD**），2026 年第一季再賺 391.44 億元（**每股 0.824 元 RMB／0.957 HKD**，比去年同期多 7.1%）。
3. **最該擔心什麼、最值得期待什麼**：最該擔心油價，因為賺多少幾乎全看油價——油價每跌 10 美元，每股就少賺 0.37～0.54 元 RMB。中東的荷姆茲海峽談判在推進，但截至本輪查證**仍未真正重開**、8/8 還有油輪遭攻擊，油價會不會快速下跌仍有變數。最值得期待的是這個月底的半年報：第二季油價衝到平均 103 美元，上半年每股可能就賺到 1.869 元 RMB（2.171 HKD），中期股息可能從去年的 0.73 港元跳到 0.98 港元。

### 6.2 【專題 2】油價 50 美元時，EPS 是多少？

> **白話導讀**：這題在問「最壞情況下我這 1 股還能賺多少」。答案是**每股約 1.567 元 RMB（1.820 HKD）**，公司仍然賺錢，但獲利只剩基準情境的 44%。本題用兩種方法各算一次再調和，因為單一模型在極端油價下都會失真。

```
【方法一：邊際稅率法】從 2026E 基準（實現油價 82.58、淨利 1,688 億元）逐級距往下折算至實現油價 45.7：
  82.58 → 80.0（跌 2.58，係數 18.73）→ −48.3 億元
  80.0  → 75.0（跌 5.0，係數 19.75）→ −98.8 億元
  75.0  → 70.0（跌 5.0，係數 20.77）→ −103.9 億元
  70.0  → 65.0（跌 5.0，係數 21.79）→ −108.9 億元
  65.0  → 45.7（跌 19.3，免暴利稅，係數 25.86）→ −499.1 億元
  ────────────────────────────────
  淨利減少合計 = 859 億元 → 預估淨利 = 1,688 − 859 = 829 億元 RMB
  → EPS 1.744 元 RMB（2.026 HKD）　※ 未扣天然氣長約跟跌與海外減值 → 偏樂觀

【方法二：成本結構法】直接用「收入 − 成本」重建（實現油價 45.7、天然氣 7.2 美元／千立方英尺）：
  原油收入   = 602 百萬桶 × 45.7 = 27,511 百萬美元
  天然氣收入 = 1,068 十億立方英尺 × 7.2 = 7,690 百萬美元
  總收入 = 35,201 百萬美元 ÷ 780 百萬桶油當量 = 每桶油當量 45.13 美元
  完全成本（低油價下資源稅、暴利稅自動減輕）≈ 每桶油當量 27.4 美元
  毛利 = (45.13 − 27.4) × 780 = 13,829 百萬美元
    減 非油氣淨支出（銷管、利息淨額等）2,700　減 額外資產減值 800 → 10,329 百萬美元
  × (1 − 25.2% 有效稅率) = 7,726 百萬美元 × 6.7420 = 人民幣 520.9 億元
  → EPS 1.096 元 RMB（1.273 HKD）　※ 全額課稅、未計海外權利金隨價下降 → 偏保守

【本報告採用的調和中樞】以方法一為底，逐項扣掉方法一漏算的兩件事：
  ① 天然氣長約跟跌：售價 7.69 → 7.20，× 1,068 十億立方英尺 = −523 百萬美元
     × (1−25.2%) × 6.7420 = −人民幣 26.4 億元（每股 −0.056 元 RMB）
  ② 海外資產減值擴大：由 2025 年的 38.09 億元擴大至約 115 億元，增 77 億元
     × (1−25%) = −人民幣 57.8 億元（每股 −0.122 元 RMB）
  ────────────────────────────────
  預估淨利 = 829 − 26.4 − 57.8 = 745 億元 RMB
  預估 EPS = 745 億 ÷ 475.2995 億股 = 1.567 元 RMB（= 1.820 HKD）
  合理區間：EPS 1.096–1.744 元 RMB（1.273–2.026 HKD）← 兩法上下限
  現價 23.26 HKD 對應本益比 = 23.26 ÷ 1.820 = 12.78 倍
  45% 派息 → 每股股息 0.705 元 RMB（0.819 HKD）→ 現價殖利率 3.52%
```

### 6.3 【專題 3】油價損益平衡點（四個層次 · 兩套模型交叉驗證）

> **白話導讀**：「保本」有四種問法——不倒貼現金？帳面不虧損？付得起擴產的錢？還發得出股息？答案完全不同。本輪起**每一層都用兩套模型各算一次**，取中樞並公布誤差區間，避免單一模型誤導。

```
【2025 年桶油完全成本 27.9 美元的拆解】（自 2025 年報還原；分母用銷量 757.6 百萬桶油當量、匯率 1 USD = 7.145 RMB）
  作業費用       402.73 億 ÷ 757.6 =  7.44 美元（年報揭露 7.46 ✓）
  除所得稅外稅金 181.94 億 ÷ 757.6 =  3.36 美元 ← 含資源稅與暴利稅，會隨油價自動增減
  勘探費用       153.65 億 ÷ 757.6 =  2.84 美元
  折舊折耗攤銷   797.71 億 ÷ 757.6 = 14.74 美元 ← 這是「不用付現金」的成本
  合計 = 28.38 美元（年報揭露 27.90，誤差 1.7%，勾稽相符 ✓）；現金部分 = 28.38 − 14.74 = 13.64 美元
```

**重要口徑提醒**：上述成本是「每**桶油當量**」，但油價是「每**桶原油**」，兩者不能直接相減，因為天然氣折成桶油當量後售價較低。低油價情境下每桶油當量收入 = **0.7718 × 實現油價 + 8.90（天然氣貢獻）**（算法：原油銷量 602 ÷ 780 = 0.7718；天然氣 1,068 × 6.5 ÷ 780 = 8.90）。

| 層次 | 問題 | **布蘭特門檻（中樞）** | 兩法區間 | 白話意義 |
| :--- | :--- | :---: | :---: | :--- |
| **層次 0** | 挖油會不會倒貼現金？ | **約 14 美元** | 僅成本結構法可算 | 現金成本 12.64 美元／桶油當量＋非油氣現金淨支出 3.46；天然氣本身就有現金貢獻，這門檻低到幾乎不可能觸及。 |
| **層次 1** | 帳面會不會虧損？ | **約 26 美元** | 18–33 | 邊際稅率法 18、成本結構法 33。**史上僅 2020 年 4 月短暫跌破**。 |

```
【層次 3 的完整算式（邊際稅率法）】
  營運現金流 ≈ 淨利 + DD&A 810 億元
  條件：淨利 + 810 ≥ 資本支出 1,170 + 0.45 × 淨利
     → 0.55 × 淨利 ≥ 360 → 淨利 ≥ 654.5 億元（每股 1.377 元 RMB／1.599 HKD）
  由 §6.1 表：淨利 829 億元對應布蘭特 50；再往下每 1 美元減 25.86 億元
     → (829 − 654.5) ÷ 25.86 = 6.7 美元 → 布蘭特 50 − 6.7 = 43.3 美元

【層次 3 的完整算式（成本結構法）】
  設 X = 每桶油當量收入 = 0.7718 × 實現油價 + 8.90
  營運現金流／桶 = 0.748X − 8.33　｜　資本支出／桶 = 22.25　｜　淨利／桶 = 0.748 × (X − 30.84)
  條件：0.748X − 8.33 ≥ 22.25 + 0.45 × 0.748 × (X − 30.84)
     → 0.4114X ≥ 20.20 → X ≥ 49.10 → 實現油價 ≥ 52.1 → 布蘭特 ≈ 56.4 美元
  → 兩法中樞 = (43.3 + 56.4) ÷ 2 ≈ 50 美元
```

> **一句話結論**：**布蘭特 50 美元是「股息政策安全線」，58 美元是「股息金額不縮水線」**。上一版確認收盤日（8/7）為 83.55 美元，緩衝約 40%；本輪查得 8/11 盤中報價已達 87.7 美元（⚠️非收盤確認價），緩衝約 43%，**方向不變、緩衝略為加寬**；**即使 EIA 最悲觀的 2027 年 65 美元成真，也還在安全線之上 30%。**
>
> **模型適用範圍（避免誤用）**：**成本結構法**逐項重建收入與成本，正確處理固定成本，適合算**極端低油價**下的保本點（偏保守）。**邊際稅率法**只算油價變動的稅後邊際影響，適合算**現價附近 ±30 美元**的敏感度（偏樂觀）。兩法在布蘭特 50 美元處分別得出淨利 521 億元與 829 億元，差距 37%——這就是本報告的模型誤差區間，§6.2 已取調和中樞 745 億元。
