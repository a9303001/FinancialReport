## 2. 三句話看懂（白話總結 · 完全不用術語）

1. **在賺什麼錢**：富邦金是台灣最大的金融集團，底下有富邦人壽（賣保單、拿保費去買股票債券賺投資收益）、台北富邦銀行（賺存款放款的利差）、富邦證券（賺股票買賣手續費）、富邦產險（收車險火險保費）。
2. **現在好不好**：非常好——2026 年光前 6 個月每股就賺了 6.67 元（去年同期 5.97 元，成長近兩成），創歷史同期新高；第 2 季每股淨值又一口氣從 67 元附近跳到 83.7 元。
3. **最該擔心什麼**：獲利和淨值都有一大塊來自股市（人壽的股票投資與保單評價）。台股或美股若大跌，這兩塊都會縮水；另外新台幣若快速升值，會墊高人壽海外資產的避險成本。

- **2026 年推導（以共識 10.55 元）**：H1 實績 6.67 元 ＋ H2 推估 3.88 元 ＝ 10.55 元。
  - H2 假設：台股高檔震盪，人壽資本利得回落至常態，月均 EPS 約 0.6～0.65 元。**此為推估、可能不準**，公司未給正式財測。

- **為何 2028 回落至 9.72 元**：市場預期 2026–2027 含較多股市資本利得（非常態），2028 回歸常續性投資收益。**這是共識的保守化，並非衰退**。
- **與上一版差異**：預估數字不變（仍採 FactSet 中位數 10.55／10.78 元），本輪補上「Q2 淨值大增支撐 2027 配息底氣」的新論據。

## 12. 名詞對照表（Glossary）

| 術語 / 縮寫 | 全名 / 原文 | 一句白話解釋 |
| :--- | :--- | :--- |
| **2881.TW（台交所）** | 富邦金融控股（台灣證交所代碼 2881） | 台灣市值最大、獲利最高的上市金控。 |
| **EPS** | Earnings Per Share（每股盈餘） | 每一股平均幫股東賺到的稅後淨利。 |
| **BPS** | Book Value Per Share（每股淨值） | 總資產減總負債後，每一股分到的帳面價值。 |
| **P/B（股價淨值比）** | Price-to-Book Ratio | 股價 ÷ 每股淨值；看「用幾倍帳面價值在買」。 |
| **DPS** | Dividend Per Share（每股股利） | 每一股實際配發的股利金額。 |
| **ROE** | Return on Equity（股東權益報酬率） | 拿股東的錢去賺利潤的效率（稅後純益 ÷ 股東權益）。 |
| **FVOCI** | Fair Value through Other Comprehensive Income | 按公允價值衡量、市價波動先計入權益，處分時才轉入獲利的金融資產。 |
| **FVTPL** | Fair Value through Profit or Loss | 按公允價值衡量、市價波動直接計入當期損益的金融資產，使月度 EPS 波動大。 |
| **IFRS 17** | International Financial Reporting Standard 17（保險合約） | 讓保險公司負債評價更貼近真實市場利率的國際會計新制。 |
| **OPM（自訂）** | 本報告自訂比率 | 營業利益率 ÷ 稅前淨利率 × 100%，衡量業外損益侵蝕程度。 |
| **Forward EPS** | 預估每股盈餘 | 法人預測未來年度每股能賺的金額。 |
| **FactSet** | FactSet 分析師調查 | 彙整多家券商預估的財經資料庫，中位數常用作市場共識。 |
| **TTM** | Trailing Twelve Months（近 12 個月） | 用過去連續四季累計數據計算。 |
| **CAGR** | Compound Annual Growth Rate（年均複合成長率） | 一段期間內每年平均的等比成長速率。 |
| **國安基金** | 國家金融安定基金 | 政府在股市大跌時進場護盤的基金；入列名單被散戶視為政策撐盤訊號。 |
| **主動式 ETF** | Active ETF（如 00991A 復華未來50） | 由經理人主動選股、可頻繁換股的 ETF，其進出是短線籌碼波動來源。 |
| **填息** | — | 除息後股價漲回除息前價位，代表市場認同其配息與獲利。 |
