### 6.4 業務改善處分（業務改善勧告）對 EPS 影響
**專題核心：業務改善處分/建議對 EPS 影響**
- **處分背景**：
  - 2026 年 5 月 18 日，日本經濟產業省電力・瓦斯取引監視等委員會對光通信旗下電力零售子公司**株式會社 Haruene（ハルエネ）**發出「業務改善勧告」（第二次行政處分）。
  - **處分起因**：部分外包行銷代理商在進行電話行銷時，未明確告知公司名稱、或冒充大型電力公司（如東京電力）誘導中小企業切換電力契約。
- **公司因應措施**：
  1. 終止違規代理商之合作契約。
  2. 導入全通話 AI 語音識別與 100% 錄音保全系統。
  3. 增設合規審查部門並加強契約成立後的二次確認電話（Welcome Call）。
- **對 EPS 之財務量化影響**：
  - **1. 合規與系統建置成本（一次性）**：預估支出約 10~15 億日圓（÷ 4,382 萬股 = 每股 **-22.8 ~ -34.2 JPY**）。

## 12. 名詞對照表（Glossary）

| 術語 / 代碼 | 全名（原文） | 一句白話解釋 |
| :--- | :--- | :--- |
| **EPS** | Earnings Per Share（每股盈餘） | 公司持有每 1 股股票在該期間內所賺到的稅後純益（日圓）。 |
| **PE** | Price-to-Earnings Ratio（本益比） | 用目前股價買進後，依目前獲利速度需要幾年才能回本。 |
| **PB** | Price-to-Book Ratio（股價淨值比） | 目前股價相對於每股淨資產的倍數（越接近 1 代表越便宜）。 |
| **BPS** | Book Value Per Share（每股淨值） | 公司若清算，每一股股票背後所擁有的股東權益淨值。 |
| **ROE** | Return on Equity（股東權益報酬率） | 公司運用股東投入的資本所創造的年化純利百分比。 |
| **DPS** | Dividend Per Share（每股股利） | 公司發放給每一股股票的現金分紅金額。 |
| **OPM** | Operating Profit Margin (自定義營業利益佔比) | (營業利益 ÷ 稅前淨利) × 100%，反映本業獲利佔總利潤的比例（越低代表業外投資賺越多）。 |
| **CAGR** | Compound Annual Growth Rate（年均複合成長率） | 一段期間內每年平均幾何複合增長的比率。 |
| **AUM** | Assets Under Management（資產管理規模） | 基金或投資顧問公司代客操作管理的總資金市值。 |
| **Capital-Light** | 輕資產營運模式 | 不需投入大筆自有資本建廠買資產，僅靠專業技術或品牌抽取高毛利佣金的商業模式。 |

| **決算短信** | 決算短信（Kessan Tanshin） | 日本上市公司每季最快公布的官方財務速報。 |
| **有価証券報告書** | 有價證券報告書（Yuho） | 日本上市公司的年度法定正式財務年報，內容極為詳盡。 |

| **売上収益** | 売上収益（Uriage Shuueki） | IFRS 會計準則下的總營業收入或營收。 |
| **営業利益** | 営業利益（Eigyo Rieki） | 扣除營業成本與管理費用後的本業營業獲利。 |
