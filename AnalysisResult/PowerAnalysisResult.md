## 2. 各公司深度分析

### 2.1 関西電力 Kansai Electric Power（9503.T）

**核心利多（成長動能）**
1. **7座核電機組已全數再稼働**（美浜3號、高浜1-4號、大飯3-4號），核電為低燃料成本高毛利發電來源，是日本再稼働進度最快的電力公司之一（[電気事業連合會](https://www.fepc.or.jp/sp/re-operation/)）。對毛利率有結構性正面影響。
2. 子公司きんでん TOB 應募產生一次性特別利益約¥105.0億，帶動FY2027 Q1稅後淨利年增38.2%（[Nikkei 2026/04/27](https://www.nikkei.com/nkd/disclosure/tdnr/20260427511752/)）。
3. 股利政策上修為配息率25-35%指引，FY2027/3預估年配息¥80/股（較FY2026/3之¥75提升）。
4. 財務體質顯著改善：自己資本比率自FY2022/3的19.2%回升至36.3%（FY2027 Q1），有息負債比率由262%降至102%。
5. 成長事業擴張：2024年增資募得資金¥1,650億投向數據中心（Data Center，受AI用電需求成長帶動）、不動產與再生能源。

**核心風險（潛在隱憂）**
1. **核電機組非計畫性停機頻發**：2026/08/10 大飯3號機自動停止、2026/05 美浜3號機停止，直接衝擊發電穩定性與獲利（FY2027 Q1營業利益驟降84.2%）。對財務表現具體損害：單季獲利波動可達數十億円等級。
2. 獲利歷史波動極大（FY2023近乎虧損打平），財測屢次大幅修正，經營能見度偏低。
3. 法規遵循疑慮未完全落幕：2019-2020金品受領醜聞衍生訴訟延續至今；2023年遭經產省兩度業務改善命令、公正取引委員會反壟斷認定違法。
4. 用過核燃料處置路徑不明朗，牽動未來延役許可的社會接受度。
5. 增資使股本大幅稀釋（+18.9%），加上未來15兆円（至2040年）鉅額資本支出，若ROIC-WACC利差不如預期將壓抑股東報酬率。

**每股化（FY2026/3）**：營收約¥3,639/股、營業利益約¥392.4/股、稅後淨利¥340.9/股（＝EPS）、資本支出約¥520.8/股、自由現金流約¥72.2/股。

### 2.2 九州電力 Kyushu Electric Power（9508.T）

**核心利多（成長動能）**
1. 川內核電廠1、2號機分別於2026/01與2026/04結束定檢恢復正常運轉，核電為低成本基載電力來源。
2. **FY2027/3 Q1（2026年4-6月）財報優於預期**：淨利¥610.98億，年增+30.71%，主因核電稼動率提升＋LNG轉售利益。
3. **熊本TSMC/JASM半導體廠效應**：預估滿載後用電需求增加30-40萬kW（占九州整體需求3-4%），帶動變電所擴建投資與企業增產設廠潮，是九州電力最獨特的長期需求催化劑（[日本経済研究所](https://www.jeri.or.jp/survey/tsmc%E6%B3%A2%E5%8F%8A%E5%8A%B9%E6%9E%9C%E3%81%A8%E4%B9%9D%E5%B7%9E%E3%81%AE%E7%9B%AE%E6%8C%87%E3%81%99%E5%A7%BF/)）。
4. 股東權益比率自福島核災後低點9%回升至19.9-20.9%，財務結構持續修復。
5. 5年ROE中位數12.88%為四家中最高，且PE僅5.73倍為四家最便宜，估值/獲利品質性價比突出。

**核心風險（潛在隱憂）**
1. **公司FY2027/3全年財測預估獲利下滑**（營業利益-6.61% YoY、經常利益-13.07% YoY），與Q1亮眼表現形成落差，反映燃料成本上升壓力，能見度存疑。
2. **負債比率高達79-80%，為四家最高**，財務槓桿風險最突出，若獲利不如預期，槓桿放大下檔風險。
3. 獲利對燃料/匯率高度敏感，歷史上FY2020、FY2023均出現虧損（FY2023淨損¥-564.29億）。
4. 子公司九州電力送配電發生客戶資訊外洩事件，存在聲譽與法遵風險。
5. 政府電費補貼自2026年3月起大幅縮減（每度¥4.5→¥1.5），可能影響零售端銷售利潤空間。

**每股化（FY2026/3）**：營收約¥4,739/股、營業利益約¥474/股、淨利¥326.92/股（＝EPS）、資本支出約¥804/股、自由現金流約¥116/股。

### 2.3 華潤電力控股 China Resources Power（00836.HK）

**公司身分澄清**：主業為火電（燃煤，約占權益裝機50%）＋風電/光伏/水電，**非核電業務**（中國核電為另一家央企中國廣核集團，代號01816.HK，與本次題目提及之「中廣核」字樣需注意區分，本報告依題目所附實際代號00836.HK進行分析）。

**核心利多（成長動能）**
1. 煤價回落改善火電盈利結構：FY2025核心業務溢利+9.9% YoY；市場預期2026年煤價續降約6%。對淨利之潛在財務影響：有望延續近兩年獲利修復趨勢。
2. 新能源裝機加速擴張，目標「十五五」期間可再生能源占比推升至60%以上，分散對煤價循環之依賴。
3. **分拆「華潤新能源」於深交所主板上市**（001248.SZ），2026/4/28已獲上市委同意，募資約人民幣245億元，有望透過分部估值釋放集團新能源資產價值。
4. 股息具吸引力且相對防禦：FY2025全年股息HK$1.127/股，派息比率40.2%，殖利率約6.2-6.8%，優於兩家日股同業。
5. 分析師目標價普遍高於現價：Investing.com共識平均目標價HK$20.81（+13.8%）、大摩HK$23.8、UBS（2026/6）上調至買入並給予HK$33.60目標價（惟Citi/JPMorgan同期轉為看淡，分歧甚大）。

**核心風險（潛在隱憂）**
1. **電力市場化改革／現貨市場推行**：容量電價政策調整、供需趨鬆，2026年多地電價面臨下行壓力，大摩已因此下修FY26/27獲利預測。對毛利率具體損害：可能壓縮火電板塊價差。
2. 煤價循環反彈風險：2021年煤價暴漲曾使淨利率壓至2.37%，歷史顯示火電獲利對煤價高度敏感。
3. 華潤新能源分拆稀釋母公司對新能源板塊權益，可能拉低0836合併EPS成長速度。
4. 負債/總資產約67.35%，五年總負債增長60.6%以支應擴張，財務彈性受限。
5. 綠電上網電價走弱：2025年新能源業務利潤雙位數下滑（儘管裝機增加），若持續恐拖累整體利潤率結構。

**PE偏低原因總結**（本題重點）：①火電板塊整體估值折讓（同業中國電力02380 PE同樣僅7-9倍）；②電力市場化改革降價疑慮；③新能源分拆稀釋疑慮；④高槓桿（負債比67%）；⑤國企/H股結構性折讓；⑥煤炭資產長期減值/雙碳政策下的能源轉型疑慮。

**每股化（FY2025）**：營收約HK$19.71/股、營業利益約HK$4.28/股、股東應佔溢利HK$2.80/股（＝EPS）、全年股息HK$1.127/股。

### 2.4 華能國際電力 Huaneng Power International（00902.HK）

**核心利多（成長動能）**
1. 煤電盈利大幅修復：FY2025歸母淨利潤RMB144.10億，年增+42.17%，主因煤價回落。
2. 清潔能源裝機占比提升至41.01%（+5.19個百分點），綠電轉型持續推進。
3. 經營現金流大幅改善：2025年經營活動現金流量淨額+33.02%至RMB672.13億，財務體質改善。
4. **股息率最具吸引力**：TTM殖利率8.10%，四家中最高，對存股型投資人具吸引力。
5. 分析師預估獲利持續成長：10家券商共識2027年淨利RMB140.08億、2028年RMB149.72億（惟2026年預估小幅下滑，需留意）。

**核心風險（潛在隱憂）**
1. 電價市場化改革下行壓力：燃煤發電市場交易電價浮動範圍擴大，上網電價存在持續下行風險。
2. 煤價雖趨穩但下行有限，仍是成本波動主要變數。
3. 資產減值侵蝕利潤：2025年Q4業績受電廠及存貨資產減值規模較大拖累。
4. 負債比率66.3%，財務槓桿偏高，利率環境變化影響財務費用。
5. **5年ROE中位數僅6.10%，四家中最低**，反映2021-2022年深度虧損（ROE分別為-9.35%、-8.04%）對整體獲利品質的長期拖累，顯示公司歷史上抗煤價循環風險能力弱於華潤電力。

**每股化（FY2025）**：營收約RMB14.61/股、營業利益約RMB1.93/股、歸母淨利RMB0.918/股（官方EPS口徑為RMB0.74，兩者落差推測與少數股東權益結構有關）。

## 3. 誰的長期投資報酬率比較高？綜合評比

依「估值(PE)＋獲利品質(ROE)＋財務體質(負債比率)＋股息(殖利率)＋營運效率(營業利益率)」五維度綜合評估：

| 排序 | 公司 | 評分邏輯 |
|---|---|---|
| 1（並列） | **華潤電力 00836.HK** | 營業利益率最高（21.73%）、ROE中位數穩健（11.49%）、股息具吸引力（6.64%）、估值便宜（PE 6.5倍）＋新能源分拆估值釋放催化劑；風險在於電價改革與槓桿 |
| 1（並列） | **九州電力 9508.T** | PE最便宜（5.73倍）、ROE中位數最高（12.88%）、TSMC需求催化劑獨特；但負債比率最高（79-80%）、FY2027財測預估獲利下滑，風險與機會並存 |
| 3 | **関西電力 9503.T** | 財務體質改善最快（負債比率最低63.7%）、7部核電機組全復歸、股利政策上修；但獲利波動性大、增資稀釋18.9%、非計畫性停機頻發是持續性隱憂 |
| 4 | **華能國際 00902.HK** | 股息率最高（TTM 8.10%）具存股吸引力，但5年ROE中位數最低（6.10%），歷史抗風險能力較弱，獲利修復雖快但基期效應明顯 |

**結論（信心度：中）**：若追求「估值便宜＋獲利品質＋股息」的均衡配置，**華潤電力（00836.HK）與九州電力（9508.T）**是本輪比較中風險調整後報酬率較優的兩檔；関西電力適合看重財務體質改善與核電全復歸題材、能承受獲利波動的投資人；華能國際則較適合高股息偏好、能承受中國電力監管與煤價循環風險的投資人。**無一家可稱「無腦優選」**，四者均有各自結構性風險，建議依個人風險偏好分散配置或緊盯下一輪追蹤項目後再決斷。

## 4. 下一輪追蹤項目（Next Iteration Topics）

### 關鍵催化劑與政策變數
1. **関西電力**：FY2027/3全年實際獲利能否消化核電非計畫性停機衝擊；KX2040（至2040年累計15兆円投資）的ROIC-WACC利差執行成效；用過核燃料處置路徑最終定案時點。
2. **九州電力**：FY2027/3全年財測（預估減益）是否應驗，或Q1的+30.71%成長動能能否延續；TSMC/JASM熊本廠滿載後實際用電需求增量是否符合預期；負債比率能否持續改善。
3. **華潤電力**：華潤新能源（001248.SZ）A股掛牌後的實際募資與市場反應，能否有效釋放分部估值；中國電力市場化改革（現貨市場全面推行）對容量電價/上網電價的實質衝擊幅度。

### 黑天鵝／灰天鵝風險
