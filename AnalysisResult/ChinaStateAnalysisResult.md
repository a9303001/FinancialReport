### 0.2 一句話心法（初級分析師必背）

> 買美國、日本的 REIT，你買的是「**永久產權（Freehold）＋ 租金**」；
> 買中國物業的港股 REIT，你買的是「**一段有到期日的現金流**」。
> 所以看到 8%～12% 的高殖利率，第一個要問的不是「配息穩不穩」，而是「**這筆錢是租金，還是在退還你的本金？**」

# 第 8 章：重要名詞對照表（Glossary）

| 術語 / 縮寫 | 英文全名 / 原文 | 一句白話解釋 |
| :--- | :--- | :--- |
| **REIT** | Real Estate Investment Trust | 房地產投資信託基金；把物業的租金打包起來分配給投資人 |
| **DPU** | Distribution Per Unit | 每基金單位分派；類似股票的「每股配息」，是 REIT 最重要的觀察指標 |
| **NAV** | Net Asset Value | 資產淨值；每單位背後的帳面資產（需要警惕「假便宜」） |
| **P/NAV** | Price-to-NAV Ratio | 股價 ÷ 每單位 NAV；<1 表示折讓（但需判斷 NAV 品質） |
| **NPI** | Net Property Income | 物業收入淨額；租金收入扣掉物業開支後的數字 |
| **LTV** | Loan-to-Value Ratio | 貸款對物業估值比率；越高代表槓桿越大、財務壓力越重 |
| **合營期** | Joint Venture Term | 中外合資企業的合作年限；到期後資產歸屬依合同約定 |
| **土地使用權** | Land Use Right | 中國土地是國有制，企業買的是「有期限的使用權」而非所有權 |
| **甲級寫字樓** | Grade-A Office | 高標準商業辦公樓；空置率和租金是商辦 REIT 的核心指標 |
| **以價換量** | Trade-down Strategy | 降低租金/售價來保住出租率/銷售量；表示市場供過於求 |
| **87001** | Hui Xian REIT（匯賢產業信託） | 李嘉誠旗下，持有北京東方廣場、重慶及瀋陽物業的 REIT |
| **01426** | Spring REIT（春泉產業信託） | 持有北京 CBD 華貿中心辦公樓及惠州商業物業的 REIT |
| **CCP** | China Central Place（北京華貿中心） | 春泉 01426 的核心資產，位於北京 CBD |
| **Oriental Plaza** | 北京東方廣場 | 匯賢 87001 的核心資產，位於北京長安街 |
| **PIR** | Price-to-Income Ratio（房價所得比） | 住宅均價 ÷ 家庭年收入中位數；越高越難負擔，需求越弱 |
| **Freehold** | 永久產權 | 土地和建物永久屬於業主（美、日等地適用） |
