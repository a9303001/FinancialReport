### 0.2 硬性門檻（全過才評分）

| 代號 | 門檻 | 判定方式 |
|:-:|:---|:---|
| G1 | 市佔前 3 | 第三方市佔資料，名次 ≤ 3（§4.2） |
| G2 | 本益比 | `5.0 < TTM PE < 15.0` |
| G3 | 營業利益率 | `> 10.0%`（最新年度與 TTM 皆須符合） |
| G4 | ROE | `> 10.0%`（最新年度） |
| G5 | 財務安全 | 依產業別五選一（下表） |

> 💡 四個 csv 已依 G2～G4 預篩，**不必另花力氣搜尋這三項是否達標**；但評分時查到的**即時數值**若不符 G2～G4，仍視同未過 → 程序 A。（csv 值只決定抽樣優先序，不能當判定依據。）

**G5 財務安全指標（依產業別五選一）**：

| 產業別 | 指標 | 門檻 |
|:---|:---|:---|
| `一般` | 負債比率（總負債 ÷ 總資產） | `< 70.0%` |
| `銀行` | 資本適足率（CAR） | `≥ 10.5%` |
| `金控` | 集團資本適足率 | `≥ 100%` |
| `保險` | RBC（美）／SMR（日）／SCR（歐） | `≥ 200%` |
| `REIT` | 貸款價值比（LTV） | `< 50.0%` |

🔴 產業別只能填上述五個值；一檔只套一種指標，且必須與 §0.3 財務安全公式、總覽「安全指標值」欄一致。

**判定結果**：
- 任一門檻沒過、查不到、無法驗證、口徑不明、來源衝突、落在邊界值、EPS ≤ 0 → **當場**跑程序 A（§2.2）→ 重抽。
- **唯一例外**：G1 查不到第三方市佔資料（或資料 > 36 個月）但產業可判定 → **不剔除**，標 `⚠️ 市佔資料不足`，依 §4.2 降分計算。

### 0.3 五個評分公式（總分 100）

```text
市場地位(25) = 名次分 + min(4.0, 市佔率% × 0.1) + 護城河k
               名次分：第1名=18.0、第2名=14.0、第3名=10.0
               護城河k：只能是 0 / 1 / 2 / 3（整數）
               整體 clamp 到 0 ~ 25.0

成長性(25)   = clamp(0, 15.0, 5年淨利CAGR% × 0.75)
             + clamp(0, 10.0, 10年淨利CAGR% × 0.50)

獲利品質(20) = max(0, 8.0 − |OPM% − 100| × 0.1)
             + min(6.0, 營業利益率% × 0.20)
             + clamp(0, 6.0, 5年ROE中位數% × 0.30)
               其中 OPM% = (營業利益率 ÷ 稅前淨利率) × 100

估值(20)     = clamp(0, 12.0, 12.0 × (15.0 − PE) ÷ 10.0)
             + min(8.0, 5年殖利率中位數% × 1.60)

財務安全(10) = 一般：clamp(0, 10.0, 10.0 × (70.0 − 負債比%) ÷ 70.0)
               銀行：clamp(0, 10.0, (CAR% − 10.5) × 2.0)
               金控：clamp(0, 10.0, (集團適足率% − 100) ÷ 5.0)
               保險：clamp(0, 10.0, (RBC% − 200) ÷ 15.0)
               REIT：clamp(0, 10.0, 10.0 × (50.0 − LTV%) ÷ 50.0)

總分 = 五個維度直接相加
clamp(下限, 上限, x) = 把 x 壓在下限與上限之間
精度：子項取小數 2 位 → 各維度四捨五入到小數 1 位 → 五維度相加
```

### 0.4 十條鐵則（違反任一條＝本輪失敗）

1. 標的**只從** `StkScreenerResult\*.csv` 抽，不可自行生成或用外部標的遞補。
2. 門檻判定**只用即時查到的最新數據**；csv 值僅決定抽樣優先序。
3. 任一門檻沒過 → **當場**跑程序 A 刪列再重抽。
4. **一次只處理一檔**：評分完、md 寫完、總覽更新完，才碰下一檔。
5. csv **只刪列**：不刪檔、不清空、不新增列、不另存、不合併。
6. PE、營益率、ROE、安全指標**禁止寫 `>10%` 交差**，一律查出並寫到具體小數。
7. 公司地位**必須具名**：產品、市場、名次、市佔率、贏過誰、憑什麼，六項都要有。
8. 每輪**開場必跑程序 B、收尾必跑程序 C**。
9. 稽核必須**重新查證最新數據**；只比對舊值就宣告通過＝沒做。
10. 對話框**只回 §8 精簡摘要**，禁止貼完整檔案內容或大表格。

## 2. CSV 刪列：三支程序

### 2.1 csv 安全讀寫規則（三支程序共用）

🔴 **唯一正確做法**：
1. csv 當**純文字**整份讀入。
2. 逐行比對第一欄代號。
3. 移除命中行。
4. 其餘行**一個字元都不改**，寫回原路徑。

**絕對不要**解析成表格再重新序列化（會破壞 BOM、引號、千分位、換行）。

**代號比對**：去掉引號與 BOM 後做**完全比對**。港股保留前導 0（`00836` ≠ `836`）；美股不分大小寫但必須全等（`CF` ≠ `CFG`）；**只比對該市場對應的 csv**。

| csv | 編碼 | 表頭第一欄 | 引號 | 注意 |
|:---|:---|:---|:---|:---|
| `TW.csv` | UTF-8 BOM | `代號` | 無 | 末欄為長文字 |
| `US.csv` | UTF-8 BOM | `代碼` | 無 | 英文代號 |
| `hk.csv` | UTF-8 BOM | `"代碼"` | 全欄雙引號 | 5 位、含前導 0 |
| `jp.csv` | UTF-8 BOM | `"代碼"` | 全欄雙引號 | 千分位逗號如 `"1,861"` |

**寫回後驗證**：BOM 還在、表頭完好、`原列數 − 刪除數 = 新列數`、被刪代號查無。

**寫入失敗**：門檻判定與總覽刪列照樣有效；把該列記進「五、下一輪待辦 → 待刪 csv 列」，下輪步驟 1 補刪。

### 2.2 程序 A：淘汰刪列

- **觸發**：§0.2「判定結果」列出的任一情況（含新標的初篩與稽核踢出）。
- **例外**：市場歸屬判不出 → 列留在 csv，記「四、待查」；G1 `⚠️ 市佔資料不足` → 不淘汰（§4.2）。
- **步驟**（做完才可抽下一檔）：確認所屬 csv → 代號比對 → 刪列 → 寫回 → 驗證 → 記 `<代號> 從 <csv> 移除 — 卡在 G<X>` 進「二、修正紀錄」。

### 2.3 程序 B：孤兒列清理（步驟 2 與步驟 4.5 各跑一次）

**核心規則**：總覽每列必須有對應個股 md。**檔不存在 ＝ 已移出 Top 500** → 刪列。

**步驟**：
1. 逐列取出總覽的排名／代號／公司／市場／連結檔名（一列都不可略過）。
2. 以檔案系統為準，檢查連結檔名在 `StkScreenerResult\` 底下是否存在。
3. 🔴 不存在 → 直接刪總覽該列（不重新分析、不補寫 md）→ 依市場欄到對應 csv 刪列（§2.1）。
4. 每刪一檔記「二、修正紀錄」；此時**不重排名次**（步驟 9 統一處理）；數量寫進「一、執行摘要」。

**易誤判情況**：

| 情況 | 處理 |
|:---|:---|
| 排名前綴不同（md 是 `12-`、連結寫 `11-`） | **不是孤兒列**：用代號＋公司名找得到檔即存在 → 依 E8 修連結 |
| 檔名含空白、括號或 `)` | 🔴 最常誤判！用完整檔名字串比對 |
| 總覽列沒有連結（純文字） | 用 `*-<代號>-*.md` 搜尋：找到 → 補連結；找不到 → 孤兒列 |
| 代號在 csv 找不到 | 正常（已刪過） |
| 清理後不足 500 檔 | 正常，嚴禁放寬門檻湊數 |

🔴 **禁止**：為維持列數而保留沒 md 的列，或補寫 md 讓孤兒列「復活」。

### 2.4 程序 C：榜單同步刪列（步驟 10，每輪必做）

**核心規則**：csv 是候選池，Top 500 的標的不可留在任何 csv。

- **觸發**：步驟 9 完成後，🔴 **無條件執行**（榜單沒變也要跑）。
- **步驟**：取 Top 500 全部代號 → 依市場分四組 → 各組只比對對應 csv → 依 §2.1 刪列寫回 → 驗證 → 寫摘要。
- **邊界**：csv 找不到 → 正常；同代號多列 → 全刪；落榜標的**不回填** csv。

## 3. 執行步驟 1～11

> 步驟編號＝執行順序，不可跳、不可換。步驟 2、4.5 見 §2.3。

### 3.1 步驟 1：讀入狀態

1. 讀本規格檔。
2. 讀主結果檔（不存在 → 用 §7 骨架新建；🔴 **讀取失敗時絕不可用空骨架覆蓋**）。
3. 讀「一、執行摘要」的 Checkpoint 與「五、下一輪待辦」，確定本輪稽核區間（§3.3）。
4. 讀 `StkScreenerResult\` 底下**所有** `.csv`，建立候選池，記錄各市場剩餘檔數。
5. 🔴 「五、下一輪待辦 → 待刪 csv 列」不為空 → 立刻補刪並驗證。
6. **開場一致性檢查**：抽查 Top 500 代號是否誤留 csv → 有就立刻補做程序 C。

### 3.2 抽樣母體規則（供步驟 5 使用）

- csv 與 Top 500 **互斥**。抽到已在榜上的代號 → 屬上輪程序 C 遺漏 → 直接刪列、記修正、不佔額度、重抽。
- 曾入榜又落榜的標的**不會回到 csv**。

**市場歸屬判定（依序命中即採）**：

| 順序 | 依據 | 規則 |
|:-:|:---|:---|
| 1 | 檔名 | `TW`/`台` → 台股；`US`/`美` → 美股；`HK`/`hk`/`港` → 港股；`JP`/`jp`/`日` → 日股 |
| 2 | csv 欄位 | `market`／`exchange`／`市場`／`交易所` |
| 3 | 代號格式 | 5 位含前導 0 → 港股；純英文 → 美股；4 位數字 → `市場不明` |

> 判不出 → 標 `市場不明`、跳過不抽、記「四、待查」、**不刪 csv**。

**抽樣優先序**（依 csv 值排序）：PE 6～14、營益率 > 12%、ROE > 12% 者優先。

**候選池耗盡**：停止抽樣，記入摘要與「四、待查」，並在「五、下一輪待辦」請使用者補充 csv。

### 3.3 步驟 3：稽核（每輪 20 檔，不佔額度）

**區間公式**：第 N 輪 ＝ TOP `20N−19` ～ `20N`（N = 1～25；第 25 輪 TOP 481～500 後回第 1 輪）。

- 榜單不滿區間上限 → 區間內有幾檔就稽核幾檔，不可挪用其他區間。
- 區間起點 > 榜單筆數（區間內 0 檔）→ 本輪直接改做第 1 輪，並在摘要註明。

🔴 **這是「重做一次分析」，不是「對帳」。禁止只比對舊數字就宣告通過。**

**單檔七個動作（一檔做完才做下一檔）**：

| # | 動作 |
|:-:|:---|
| A1 | **讀回**既有個股 md ①～⑦ 與總覽該列，記下目前總分 |
| A2 | **重查最新數據**（不沿用舊值）：收盤價、PE、EPS、營益率（年度＋TTM）、ROE（最新＋5 年中位數）、安全指標、殖利率、淨利 CAGR、市佔率；每項附來源＋日期 |
| A3 | **重驗 G1～G5**（標準同 §0.2，不因已在榜而放寬） |
| A4 | **重算五維度與總分**（依 §0.3 從頭算） |
| A5 | **套不變式 I1～I7**（違反 → 重算並記錄） |
| A6 | **抓錯**：跑 E1～E9（§3.3.1），命中就改 |
| A7 | **寫回**：新值寫入 md，更新「本區塊最後更新」與「本輪稽核」，同步總覽 |

**結果分流**：

| 結果 | 處理 |
|:---|:---|
| 全過、分數變動 < 3.0 | 更新 md 與總覽 → 計「稽核維持」 |
| 全過、分數變動 ≥ 3.0 | 同上，並記分數變動主因 → 計「稽核重評」 |
| 任一門檻沒過 | 🔴 踢出：刪 md、移除總覽列（名次於步驟 9 遞補重排） |
| 關鍵數據查不到 | 視同沒過 → 踢出，並記「四、待查」 |

> 被踢出者不回填 csv；空缺由新抽樣補上，嚴禁放寬門檻湊數。

**存檔節奏**：每完成 5 檔存一次；20 檔全做完再存一次。

#### 3.3.1 稽核錯誤清單 E1～E9

| # | 錯誤 | 怎麼抓 | 怎麼修 |
|:-:|:---|:---|:---|
| E1 | 算術錯 | ⑦ 子項 ≠ 維度分；五維度和 ≠ 總分 | 依 §0.3 重算 |
| E2 | 兩處不同步 | 總覽 ≠ 個股 md | 用新值覆蓋兩處 |
| E3 | 不變式違反 | I1～I7 任一條 | 重算並記錄 |
| E4 | 模板缺漏 | ①～⑦ 缺區塊；⑤-1／⑤-2／⑤-3 缺表 | 補齊 |
| E5 | 數值搪塞 | `>10%`、`約`、`逾`、空白、`N/A` | 補實際數值；確實查無 → 該子項 0 分 |
| E6 | 資料過期 | 股價/PE > 5 交易日；市佔 > 36 月，或 24～36 月未註日期 | 依 §4.3 重新取數或補註 |
| E7 | 禁用詞殘留 | §6.2 禁用詞且未接具名數據 | 改寫為具名格式 |
| E8 | 檔名/連結錯 | 補零錯、非法字元、連結指向不存在的檔 | 依 §1.2 更名並修連結 |

## 5. 五維度評分補充（公式見 §0.3）

### 5.1 市場地位（25）

- 名次與市佔率必須來自 ⑤-1 的具名資料；只寫「龍頭」沒具名 → 名次分、市佔分計 0。

### 5.2 成長性（25）

- 沒有 10 年數據但有 ≥ 7 年者可替代（須標註實際年數）；< 7 年 → 10 年子項計 0。

### 5.3 獲利品質與財務安全

- 稅前淨利率 ≤ 0 → OPM 子項 0 分，標 `OPM 不適用`。
- 財務安全公式必須與 §0.2 產業別一致。

### 5.4 不變式 I1～I7

任一條違反＝算術錯誤，當場重算並記錄。

| # | 不變式 | 抓什麼 |
|:-:|:---|:---|
| I1 | 市場地位 ＝ 名次分 + 市佔分 + k，k ∈ {0,1,2,3} | 護城河給了 0.5 |
| I2 | 每維度 ≤ 配分上限（25／25／20／20／10） | 子項溢位 |
| I3 | 估值 PE 子項落在 (0, 12.0) 開區間 | 落在端點 ＝ PE 不在 (5, 15)，違反 G2 |

| I5 | 標 `⚠️ 市佔資料不足` → 市場地位 ≤ 3.0 | 沒具名卻高分 |

| I7 | 總覽五維度與總分 ＝ 個股 md ⑦，逐字相同 | 兩處不同步 |

### 5.5 同分排序

依序比較：① PE 較低 → ② 5 年淨利 CAGR 較高 → ③ 財務安全分較高 → ④ 代號升冪。

### 5.6 缺失值處理

| 情況 | 處理 |
|:---|:---|
| 評分子項查無 | 該子項 0 分，標 `資料缺漏`，嚴禁臆測 |
| 稅前淨利率 ≤ 0 | OPM 子項 0 分，標 `OPM 不適用` |
| 引用絕對金額 | 標來源日期，並**強制換算每股金額**（÷ 最新流通在外股數） |
| 財務安全 | 寫明產業別、指標與代入值 |

> 門檻相關數據（G1～G5）查無不適用本表，一律依 §0.2 跑程序 A。

### 5.7 計算範例

輸入：市佔第 1 名 57.0%、護城河 2；5 年 CAGR 18.0%、10 年 12.0%；營益率 52.5%、稅前淨利率 55.0%、5 年 ROE 中位數 21.0%；PE 6.73、5 年殖利率中位數 4.5%；一般、負債比 27.09%。

```text
市場地位 = 18.0 + min(4.0, 5.70) + 2 = 24.00 → 24.0
成長性   = clamp(0,15, 13.50) + clamp(0,10, 6.00) = 19.50 → 19.5
獲利品質 : OPM% = 52.5 ÷ 55.0 × 100 = 95.45
           7.54 + min(6.0, 10.50) + clamp(0,6, 6.30) = 19.54 → 19.5
估值     = clamp(0,12, 9.92) + min(8.0, 7.20) = 17.12 → 17.1
財務安全 = clamp(0,10, 10.0 × (70.0 − 27.09) ÷ 70.0) = 6.13 → 6.1
總分     = 24.0 + 19.5 + 19.5 + 17.1 + 6.1 = 86.2
```
