### 0.2 七道門檻（全過才評分）

| 代號 | 門檻 | 判定 |
|:-:|:---|:---|
| G1 | 市佔前 3 | 第三方市佔資料，名次 ≤ 3 |
| G2 | PE | `5.0 < TTM PE < 15.0`（不含邊界） |
| G3 | 營業利益率 | 年度 `> 10.0%` **且** TTM `> 10.0%` |
| G4 | ROE | 5 年中位數 `> 10.0%` **且** 最新 `> 10.0%` |
| G5 | 財務安全 | 一般 負債比 `< 70%` ／ 銀行 CAR `≥ 10.5%` ／ 金控 集團適足率 `≥ 100%` ／ 保險 RBC `≥ 200%` ／ REIT LTV `< 50%` |

**任一道沒過 → 立刻跑程序 A（從 csv 刪列）→ 重抽。**

### 0.3 五個評分公式（總分 100）

```text
市場地位(25) = 名次分 + min(4.0, 市佔率% × 0.1) + 護城河k
               名次分：第1名=18.0、第2名=14.0、第3名=10.0
               護城河k：只能是 0 / 1 / 2 / 3（整數）
               整體 clamp 到 0 ~ 25.0

成長性(25)   = clamp(0, 15.0, 5年淨利CAGR% × 0.75)
             + clamp(0, 10.0, 10年淨利CAGR% × 0.50)

獲利品質(20) = max(0, 8.0 − |OPM% − 100| × 0.1)
             + min(6.0, 營業利益率% × 0.20)
             + clamp(0, 6.0, 5年ROE中位數% × 0.30)
               其中 OPM% = (營業利益率 ÷ 稅前淨利率) × 100

估值(20)     = clamp(0, 12.0, 12.0 × (15.0 − PE) ÷ 10.0)
             + min(8.0, 5年殖利率中位數% × 1.60)

財務安全(10) = 一般：clamp(0, 10.0, 10.0 × (70.0 − 負債比%) ÷ 70.0)
               銀行：clamp(0, 10.0, (CAR% − 10.5) × 2.0)
               金控：clamp(0, 10.0, (集團適足率% − 100) ÷ 5.0)
               保險：clamp(0, 10.0, (RBC% − 200) ÷ 15.0)
               REIT：clamp(0, 10.0, 10.0 × (50.0 − LTV%) ÷ 50.0)

總分 = 五個維度直接相加
clamp(下限, 上限, x) = 把 x 壓在下限與上限之間
精度：子項小數 2 位 → 維度四捨五入到小數 1 位 → 五維度相加
```

### 0.4 十條鐵則（違反任一條＝本輪失敗）

1. 標的**只從** `StkScreenerResult\*.csv` 抽，不可自行生成。
2. 門檻判定**只用即時查到的最新數據**，csv 值僅決定抽樣優先序。
3. 任一門檻沒過 → **當場**跑程序 A 刪列再重抽。
4. **一次只處理一檔**：評分完、md 寫完才碰下一檔。
5. csv **只刪列**，不刪檔、不清空、不新增列、不另存。
6. G3、G4 **禁止寫 `>10%` 交差**，一定要寫到小數點。
7. 公司地位**必須具名**：產品、市場、名次、市佔率、贏過誰、憑什麼，六項都要有。
8. 每輪**開場必跑程序 B、收尾必跑程序 C**。
9. 稽核必須**重新查證最新數據**，只比對舊值就宣告通過＝沒做。
10. 對話框**只回精簡摘要**（§8），禁止貼完整檔案內容。

## 2. CSV 刪列：三支程序

### 2.1 csv 安全讀寫規則（三支程序共用）

🔴 **唯一正確做法**：
1. csv 當**純文字**整份讀進來。
2. 逐行比對第一欄代號。
3. 移除命中行。
4. 其餘行**一個字元都不改**，寫回原路徑。

**絕對不要**解析成表格再重新序列化（會破壞 BOM、引號、千分位）。

**代號比對規則**：去掉引號與 BOM 後做**完全比對**。港股保留前導 0（`00836` ≠ `836`）。美股大小寫不敏感但必須全等（`CF` ≠ `CFG`）。**只比對該市場對應的 csv**。

**各 csv 格式**：

| csv | 編碼 | 表頭第一欄 | 引號 | 注意 |
|:---|:---|:---|:---|:---|
| `TW.csv` | UTF-8 BOM | `代號` | 無 | 末欄長文字 |
| `US.csv` | UTF-8 BOM | `代碼` | 無 | 英文代號 |
| `hk.csv` | UTF-8 BOM | `"代碼"` | 全欄雙引號 | 5 位含前導 0 |
| `jp.csv` | UTF-8 BOM | `"代碼"` | 全欄雙引號 | 千分位逗號如 `"1,861"` |

**寫回後驗證**：BOM 還在、表頭完好、`原列數 − 刪除數 = 新列數`、被刪代號查無。

**寫入失敗時**：門檻判定與總覽刪列照樣有效。把「待刪列」記進「五、下一輪待辦」，下輪開場補刪。

### 2.2 程序 A：淘汰刪列

**觸發時機**：七道門檻任一道沒過（含查不到、無法驗證、口徑不明、來源衝突、邊界值）。
**唯一例外**：「市場歸屬判不出來」→ 列留 csv，記進「四、待查」。

**五個動作（做完才准抽下一檔）**：
1. 確認來自**哪一個 csv**
2. 用**代號完全比對**找到那一列
3. 只刪這一列
4. 寫回原路徑
5. 重讀驗證 → 記 `<代號> 從 <csv> 移除 — 卡在 G<X>` 進「二、修正紀錄」

⏱ 順序：`判定不合格 → 刪列 → 存回 → 驗證 → 才准抽下一檔`

### 2.3 程序 B：孤兒列清理（每輪開場 + 抽樣前各做一次）

**核心規則**：總覽每列必須有對應個股 md 檔。**檔不存在 ＝ 已移出 Top 160** → 刪列。

**觸發時機**：
- **步驟 2**：讀完主結果檔與 csv 之後、跑稽核之前
- **步驟 4.5（抽樣前驗證）**：進入抽樣迴圈前再做一次最終確認（中間步驟可能產生新孤兒列）

**執行步驟**：
1. 逐列取出總覽的排名／代號／公司／市場／連結檔名（一列都不可略過）
2. 檢查連結檔名在 `StkScreenerResult\` 底下**是否真的存在**（以檔案系統為準）
3. 檔案存在 → 保留
4. 🔴 檔案不存在 → **直接刪掉總覽該列**（不重新分析、不補寫 md）
5. 依該列市場欄找到對應 csv，用代號完全比對刪列（照 §2.1）
6. 每刪一檔記「二、修正紀錄」
7. 清理後不用馬上重排名次（步驟 9 統一重排），但稽核區間用清理後順位計算
8. 寫數字進「一、執行摘要」

**易誤判的邊界情況**：

| 情況 | 處理 |
|:---|:---|
| 檔案在但排名前綴不同（md 是 `12-` 連結寫 `11-`） | **不是孤兒列**，用代號+公司名能找到檔就算存在 → 屬 E8 改連結 |
| 檔名含空白或括號（如 `53-00316-東方海外國際 (OOIL).md`） | 🔴 最常誤判！`)` 會截斷連結 → 用完整檔名字串檢查 |
| 總覽列沒有連結（純文字） | 用代號去目錄找 `*-<代號>-*.md`：找到 → 補連結；找不到 → 判孤兒列 |
| 代號在 csv 找不到 | 正常（已刪過），不算錯誤 |
| 清理後不足 160 檔 | 正常，嚴禁放寬門檻湊數 |

🔴 **禁止**：為維持 160 列而保留沒 md 的列，或補寫 md 讓孤兒列「復活」。

### 2.4 程序 C：榜單同步刪列（每輪收尾必做）

**核心規則**：csv 是「還沒入榜的候選池」。Top 160 標的不可留在任何 csv。

**觸發時機**：步驟 9 排名整合完成後，本輪最後一次動 csv。

🔴 **無條件執行**：就算本輪榜單沒變，仍然拿 Top 160 全部代號重跑一次。

**執行步驟**：
1. 取定案後 Top 160 **全部**代號
2. 依市場欄分成台／美／港／日四組
3. 每組**只比對該市場的 csv**
4. 依 §2.1 讀檔、比對、移除、寫回
5. 重讀四個 csv 驗證
6. 寫「同步刪列 X 檔／各市場剩餘候選數」進「一、執行摘要」

**邊界**：代號在 csv 找不到 → 正常。同代號多列 → 全刪並記錄。落榜標的**不回填 csv**。

🔴 **禁止**：刪檔、清空、合併 csv、新增列。

### 3.1 步驟 1：讀入狀態

1. 讀本規格檔。
2. 讀主結果檔（不存在就用 §7 骨架新建；🔴 讀取失敗時絕不可用空骨架覆蓋）。

5. 🔴 「五、下一輪待辦 → 待刪 csv 列」不為空 → 立刻補刪並驗證。
6. **開場一致性檢查**：抽查 Top 160 代號有無誤留 csv → 有就補做程序 C。

### 3.2 抽樣母體：csv 候選池

- csv 與 Top 160 **互斥**。抽到已在榜上的代號 → 代表上輪程序 C 遺漏 → 直接刪列、不佔額度、回頭重抽。
- 曾入榜又落榜的標的**不會回到 csv**。

**市場歸屬判定（依序，第一個命中就採用）**：

| 順序 | 依據 | 規則 |
|:-:|:---|:---|
| 1 | 檔名（優先） | `TW`/`台` → 台股；`US`/`美` → 美股；`HK`/`hk`/`港` → 港股；`JP`/`jp`/`日` → 日股 |
| 2 | csv 市場欄位 | 有 `market`/`exchange`/`市場`/`交易所` 欄就採用 |
| 3 | 代號格式 | 5 位含前導 0 → 港股；純英文 → 美股；4 位純數字 → 台/日分不出來，標 `市場不明` |

> 判不出來 → 標 `市場不明`，本輪跳過不抽，記「四、待查」，不刪 csv。

**抽樣優先序**（只影響先抽誰，不影響過不過）：優先抽 PE 6～14、營益率 > 12%、ROE > 12% 的列。🔴 門檻判定一律以**即時查證最新數據**為準。

**候選池耗盡**：停該市場，在摘要與待查記錄，在待辦請使用者補充 csv。不得用外部標的遞補。

### 3.3 步驟 3：稽核（每輪 20 檔，不佔額度）

**輪次對照表**：

| 輪次 | 區間 | 輪次 | 區間 |
|:-:|:---|:-:|:---|
| 1 | TOP 1～20 | 5 | TOP 81～100 |
| 2 | TOP 21～40 | 6 | TOP 101～120 |
| 3 | TOP 41～60 | 7 | TOP 121～140 |
| 4 | TOP 61～80 | 8 | TOP 141～160 → 下輪回 1 |

> 榜單不滿 160 時，區間內有幾檔就稽核幾檔，不可挪用其他區間。

🔴 **這是「重做一次分析」，不是「對帳」。禁止只比對舊數字就宣告通過。**

**單檔七個動作（一檔做完才做下一檔）**：

| # | 動作 |
|:-:|:---|
| A1 | **讀回**既有個股 md ①～⑦ 與總覽該列，記下目前總分 |
| A2 | **重查最新數據**（不沿用舊值）：收盤價、EPS、營益率（年度+TTM）、ROE（最新+5年中位數）、安全指標、殖利率、淨利 CAGR、市佔率。每項要有來源+日期 |
| A3 | **重驗 G1～G7**（標準同 §4，不因在榜而放寬） |
| A4 | **重算五維度與總分**（依 §5 從頭算） |
| A5 | **套不變式 I1～I7**（違反 → 重算並記錄） |
| A6 | **抓錯**：跑 E1～E9（§3.3.1），命中就改 |
| A7 | **補新資料**：新值寫回 md，更新「最後更新」與「本輪稽核」，同步總覽 |

**重驗結果分流**：

| 結果 | 處理 |
|:---|:---|
| 全過、分數變動 < 3.0 | 更新 md 與總覽 → 「稽核維持」 |
| 全過、分數變動 ≥ 3.0 | 同上 + 記錄分數變動主因 → 「稽核重評」 |
| 任一門檻沒過 | 🔴 踢出：刪 md、移除總覽列、名次遞補重排 → 「稽核踢出」 |
| 關鍵數據查不到 | 視同沒過 → 踢出，記「四、待查」 |

> 被踢出的標的不回填 csv。空缺由新抽樣補上，嚴禁放寬門檻湊數。

**存檔節奏**：每 5 檔存一次；20 檔全做完再存一次。

#### 3.3.1 稽核錯誤清單 E1～E9

| # | 錯誤 | 怎麼抓 | 怎麼修 |
|:-:|:---|:---|:---|
| E1 | 算術錯 | ⑦ 子項 ≠ 維度分；五維度 ≠ 總分 | 依 §5 重算 |
| E2 | 兩處不同步 | 總覽 ≠ 個股 md | 用新值覆蓋兩處 |
| E3 | 不變式違反 | I1～I7 | 重算並記錄 |
| E4 | 模板缺漏 | ①～⑦ 缺區塊；⑤-1/⑤-2/⑤-3 缺表 | 補齊 |
| E5 | 數值搪塞 | `>10%`、`約`、`逾`、空白、`N/A` | 補實際數值；查無 → 0 分 |
| E6 | 資料過期 | 股價/PE > 5 交易日；市佔 > 24 月 | 重新取數 |
| E7 | 禁用詞殘留 | §6.2 禁用詞無具名數據 | 改寫為具名格式 |
| E8 | 檔名/連結錯 | 補零錯、連結指向不存在的檔 | 依 §1.2 更名修連結 |
| E9 | 每股化缺漏 | 提及絕對金額卻沒換算每股 | 補上每股金額 |

> E1～E3 是算術一致性，E4～E9 是內容品質，兩類都要跑。

### 3.4 步驟 4：算說明缺口，分配額度

```text
說明缺口 = 總覽筆數 − 內容完整的個股 md 檔數
           （完整 ＝ ①②③ 齊全 且 ⑤ 市佔已具名）
```

| 缺口 | 額度分配 |
|:---|:---|
| > 10 | 全部補 md，不抽新股，補完跳步驟 9 |
| 1～10 | 先補滿缺口，剩下才抽新股 |
| = 0 | 全部抽新股（共 20 檔，跨市場混合抽樣） |

## 5. 五維度評分（滿分 100）

> 公式在 §0.3，本章講用法、特殊情況、自檢。

| 維度 | 配分 |
|:---|:-:|
| 市場地位 | 25 |
| 成長性 | 25 |
| 獲利品質 | 20 |
| 估值 | 20 |
| 財務安全 | 10 |

### 5.1 市場地位（25）

- 名次與市佔率必須來自 ⑤-1 的具名資料。只寫「龍頭」沒具名 → 子項 1、2 計 0 分。
- 護城河每加 1 分要在 ⑤-3 附量化證據。四選項：高轉換成本/網路效應/規模經濟/特許獨佔。
- 🔴 護城河**只能給 0/1/2/3 整數**。

### 5.2 成長性（25）

- 沒有 10 年數據但有 ≥ 7 年可替代（要標註）。< 7 年 → 子項 2 計 0 分。

### 5.3 獲利品質與財務安全

- `OPM% = (營業利益率 ÷ 稅前淨利率) × 100`。接近 100% 分數愈高。
- 稅前淨利率 ≤ 0 → OPM 子項 0 分，標 `OPM 不適用`。
- 財務安全公式必須與 §4 產業別一致。

### 5.4 不變式 I1～I7

任一條違反＝算術錯誤，當場重算並記錄。

| # | 不變式 | 抓什麼 |
|:-:|:---|:---|
| I1 | 市場地位 ＝ 名次分 + 市佔分 + k，k 只能 0/1/2/3 | 護城河給了 0.5 |
| I2 | 每維度 ≤ 配分上限（25/25/20/20/10） | 子項溢位 |
| I3 | 估值子項 1 在 (0, 12.0) 開區間 | ≥12 代表 PE≤5 應被 G2 擋 |
| I4 | 總分 ＝ 五維度（各四捨五入到 1 位）直接相加 | ⑦ 驗算列 ≠ 五項和 |
| I5 | 標 `⚠️ 市佔資料不足` → 市場地位 ≤ 3.0 | 沒具名卻高分 |
| I6 | 總覽 PE/營益率/安全指標值都是具體數值 | 抓 `>10%` |
| I7 | 總覽五維度與總分 ＝ 個股 md ⑦ 逐字相同 | 兩處不同步 |

### 5.5 同分排序

總分相同依序比：① PE 較低 → ② 5 年淨利 CAGR 較高 → ③ 財務安全較高 → ④ 代號升冪。

### 5.6 缺失值處理

| 情況 | 處理 |
|:---|:---|
| 子項查無 | 0 分，標 `資料缺漏`，嚴禁臆測 |
| 稅前淨利率 ≤ 0 | OPM 0 分，標 `OPM 不適用` |
| 引用絕對金額 | 標來源日期，**強制換算每股金額** |
| 財務安全 | 寫明公式類型與代入值 |

### 5.7 完整計算範例

**輸入**：市佔第 1 名 57.0%、護城河 2 項；5 年淨利 CAGR 18.0%、10 年 12.0%；營業利益率 52.5%、稅前淨利率 55.0%、5 年 ROE 中位數 21.0%；PE 6.73、5 年殖利率中位數 4.5%；一般、負債比 27.09%。

```text
市場地位 = 18.0 + min(4.0, 57.0×0.1=5.70) + 2 = 24.00 → 24.0
成長性   = clamp(0,15, 18.0×0.75=13.50) + clamp(0,10, 12.0×0.50=6.00) = 19.50 → 19.5
獲利品質 : OPM% = 52.5÷55.0×100 = 95.45
           子項1 = max(0, 8.0−|95.45−100|×0.1) = 7.54
           子項2 = min(6.0, 52.5×0.20=10.50) = 6.00
           子項3 = clamp(0,6, 21.0×0.30=6.30) = 6.00
         = 19.54 → 19.5
估值     : 子項1 = clamp(0,12, 12.0×(15.0−6.73)÷10.0=9.924) = 9.92
           子項2 = min(8.0, 4.5×1.60=7.20) = 7.20
         = 17.12 → 17.1
財務安全 = clamp(0,10, 10.0×(70.0−27.09)÷70.0=6.13) → 6.1
總分     = 24.0 + 19.5 + 19.5 + 17.1 + 6.1 = 86.2
```
