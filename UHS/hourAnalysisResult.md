## 2. 三句話看懂（白話總結）

1. **這家公司在賺什麼錢**：UHS 是全美前幾大的私立醫院集團，一邊經營綜合醫院（急診、開刀、生產），一邊經營精神／心理專科醫院（全美龍頭）。收入來自向病人、民間保險、以及政府的窮人醫療補助（Medicaid）收取住院與看診費。
2. **現在營運狀況好不好**：本業很會賺（股東權益報酬率 ROE 約 21%），2026 上半年營收還年增 8.9%；但股價被打到超便宜（本益比只有 6.9 倍，同業約 13 倍），因為市場很怕未來政府砍補助。
3. **最該擔心什麼**：川普 2025 年簽的「大而美法案」會從 2028 年起分年砍 Medicaid 補助，全面實施（2032 年）時估計每股獲利會少掉約 **5.4～6.0 美元**。好消息是衝擊分好幾年才發生，公司每年用現金大買庫藏股（減少股數）來緩衝時間。

## 6. 專題分析與計算拆解

### 6.1【EXTRA 核心問題 1】大而美法案（OBBBA）對 UHS 影響，EPS 會掉多少？

**這段結論**：全面實施時每股稅後 EPS 約砍 **-$5.39～-$5.99**，但分階段從 2028 拖到 2032，公司有時間用買庫藏股緩衝。

- **法案內容**：川普於 2025-07-04 簽署《One Big Beautiful Bill Act（大而美法案，OBBBA）》。重點是限制州政府給醫院的 Medicaid「補充給付」——分兩條線砍：
  - **州定向給付（State-Directed Payments, SDP）**：自 2028 州財政年度起，既有給付方案每年最多砍 10%，砍到「Medicare 給付率」為止。有擴大 Medicaid 的州（Expansion States）上限＝Medicare 的 100%；沒擴大的州＝110%。
  - **醫療提供者稅（Provider Tax）安全港比率**：從現行 6% → **FY2028 降到 5.5%** → **FY2032 降到 3.5%**。這會縮小州政府拿聯邦配合款的空間，間接減少醫院補助。
- **公司揭露的衝擊規模**：UHS 在 SEC 申報揭露，法案於 **2032 年全面實施**時，每年來自 Medicaid 補充給付的淨利益預計減少 **4.32 億～4.80 億美元（稅前）**。對照 2025 年 UHS 的 Medicaid 淨補充給付高達 13.39 億美元（每股 $22.12），佔全公司營業利益約 67%——所以這是「極高」重要性風險。
- **每股衝擊試算**（股數 6,054 萬股、有效稅率 24.5%）：
  - 稅前每股衝擊 = 年減金額 ÷ 股數 = $432M～$480M ÷ 60.54M = **-$7.14～-$7.93／股**
  - 稅後 EPS 衝擊 = 稅前每股 × (1 − 0.245) = **-$5.39～-$5.99／股**（常態性）
  - 相較 2025 實績 EPS $23.42，降幅約 **23.0%～25.6%**。
- **緩衝機制（時間換空間）**：衝擊非一次到位，**2028 開始第一階段、2032 才 100%**。公司每年用自由現金流買回約 8～9 億美元庫藏股；若 2028–2032 年股數降到 5,200～5,500 萬股，每股稀釋壓力會被實質稀釋掉一部分。

### 6.3 個股基本面五項（依 AGENTS.md）

1. **主要產品與服務**：①**急症照護部門（Acute Care, AHS）**——約 30 家綜合醫院，內外科／急診／產科／心血管，約佔 55% 營收；②**行為健康部門（Behavioral Health, BHS）**——340+ 家精神專科與社區照護，治創傷後壓力（PTSD）、成癮、青少年精神疾病，約佔 45% 營收、利潤率較高。
2. **市佔率與競爭對手**：全美前三大私立醫院集團之一。急症對手 HCA（NYSE: HCA）、Tenet（NYSE: THC）、Community Health（NYSE: CYH）；行為健康（精神科）居**全美龍頭**。
3. **護城河**：①**設立許可（Certificate of Need, CON）**——多數州限制新設醫院／精神床位，行政進入門檻極高；②**精神照護專科壁壘**——需專業人力與特化設施、監管嚴；③**區域規模經濟**——在德州、佛州、內華達等地形成醫療網，提高對保險公司議價力。
4. **成長潛力**：全美精神／心理健康需求持續上升；Medicare 住院給付年年調升；區域擴建與新院（如華府 Cedar Hill）陸續投產。
5. **風險與挑戰**：OBBBA 政策砍補助（2028 起）、加州護理配比新法（每股 -$0.49）、醫療糾紛與責任準備金上升。

## 12. 名詞對照表（Glossary）

| 術語／縮寫 | 全名（原文） | 一句白話解釋 |
| :--- | :--- | :--- |
| **OBBBA** | One Big Beautiful Bill Act（大而美法案） | 美國 2025-07 簽署的預算法案，含削減 Medicaid 政府醫療補助上限。 |
| **Medicaid** | 美國醫療補助計畫 | 聯邦與州共同出資、補助低收入戶的醫療保險制度。 |
| **SDP** | State-Directed Payments（州定向給付） | 州政府額外給醫院的 Medicaid 補助款，OBBBA 要從 2028 起分年砍。 |
| **Provider Tax** | 醫療提供者稅 | 州向醫院課的稅，用來套取聯邦配合款；安全港比率 6%→5.5%→3.5%。 |
| **IPPS** | Inpatient Prospective Payment System（住院預估支付制度） | Medicare 對醫院住院的年度定額給付，每年由 CMS 調整。 |
| **CMS** | Centers for Medicare & Medicaid Services | 美國聯邦主管 Medicare 與 Medicaid 的機關。 |
| **DPP** | Directed Payment Program（定向給付方案，如佛州 DPP） | 州政府針對特定醫院的補助方案；UHS 佛州 DPP 帶來一次性利益。 |
| **AHS / BHS** | Acute Care / Behavioral Health（急症／行為健康部門） | UHS 兩大事業：綜合醫院 vs 精神專科醫院。 |
| **Forward EPS** | 預估每股盈餘 | 未來特定年度每股預估能賺的淨利。 |
| **OPM（自訂）** | 營業利益率 ÷ 稅前淨利率 × 100% | 本報告自訂，看利息支出對利潤的侵蝕程度。 |
| **ROE** | Return on Equity（股東權益報酬率） | 淨利 ÷ 股東權益 × 100%，衡量用股東的錢賺錢的效率。 |
| **BPS / PB** | Book value Per Share／Price-to-Book | 每股淨值／股價相對每股淨值的倍數。 |
| **FCF** | Free Cash Flow（自由現金流） | 營業現金流扣掉資本支出後、真正能自由運用的現金。 |
| **10-K / 10-Q** | SEC 年報／季報 | 美股公司依法向 SEC 申報的年度（10-K）與季度（10-Q）財報。 |
