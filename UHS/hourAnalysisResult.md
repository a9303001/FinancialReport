## 2. 三句話看懂（白話總結）

1. **這家公司在賺什麼錢**：UHS 是美國前幾大的醫療院所集團，主要經營綜合醫院與精神照護中心，透過提供看診與住院服務，向病人、私人保險公司及政府醫療保險（如 Medicaid 低收入補助）收取費用。
2. **現在營運狀況好不好**：公司目前本業相當賺錢（獲利效率指標 ROE 高達 21.4%），但股價被市場壓得非常低（本益比僅約 6.5-6.7 倍），主因是市場非常擔心川普總統簽署的「大而美法案」未來會大幅削減政府給醫院的低收入補助款。
3. **最該擔心什麼與未來展望**：雖然這項新法案預計在 2032 年全面生效時，會讓每股獲利少掉約 5.13 至 5.70 美元，但衝擊要到 2028 年才開始分階段發生；公司目前靠強勁的現金流每年大量買回自家股票（註銷股數），有足夠的緩衝時間來抵銷政策利空。

## 3. 最新結論摘要與核心問題解答

### 3.1 核心問題 1：大而美法案（One Big Beautiful Bill Act, OBBBA）對 UHS 影響，EPS 會掉多少？

- **法案背景**：美國總統川普於 2025 年 7 月 4 日簽署《One Big Beautiful Bill Act》（大而美法案）。該法案針對醫療補助（Medicaid）進行重大改革，限制聯邦對州政府「定向給付（State-Directed Payments, SDP）」與「醫療提供者稅（Provider Tax）」的補助比例上限，同時新增 Medicaid 工作要求審查。
- **獲利衝擊規模（公司官方揭露）**：
  - UHS 於 SEC 申報檔案揭露，當該法案對 Medicaid 補充給付上限的限制於 **2032 年全面實施**時，預計將使公司每年來自 Medicaid 補充給付的淨利益減少 **4.32 億至 4.80 億美元**（Pre-tax 稅前，換算每股稅前利益減少 $6.79 至 $7.55 美元）。
  - 作為對照，2025 年 UHS 的 Medicaid 淨補充給付高達 13.39 億美元（每股 $21.05 美元，佔全公司營業利益約 67%）。
- **每股金額（EPS）衝擊數值**（以最新流通股數 6,360 萬股、有效稅率 24.5% 計算）：
  - **稅前（Pre-tax）每股利益減少**：**-$6.79 至 -$7.55 美元 / 股**。
  - **稅後 EPS 淨減少量**：**-$5.13 至 -$5.70 美元 / 股**（相較 2025 年 EPS $23.42 減少約 21.9% – 24.3%）。
- **時程與緩衝機制**：
  - 衝擊並非即刻發生，而是從 **2028 年開始分階段（Phase-in）實施**，至 2032 年達到最大值。
  - 公司每年透過強勁自由現金流買回約 8 億至 9 億美元庫藏股（每股約當 $12.58 至 $14.15 美元）。若 2028–2032 年間流通股數持續下降，每股金額的稀釋影響將獲得實質減緩。

## 4. 詳細計算與拆解（可還原公式）

### 4.1 大而美法案（OBBBA）EPS 衝擊計算拆解
- **計算公式**：
  $$\text{稅前每股衝擊} = \frac{\text{法案造成的年利益減少金額}}{\text{最新流通在外稀釋股數}}$$
  $$\text{稅後每股衝擊 (EPS Impact)} = \text{稅前每股衝擊} \times (1 - \text{有效稅率})$$
- **數據代入**：
  - 法案影響金額：4.32 億美元（下限，每股 $6.79）至 4.80 億美元（上限，每股 $7.55）。
  - 最新流通在外股數：63,600,000 股（6,360 萬股，來源：2026 Q1/Q2 10-Q 申報）。
  - 有效稅率（Effective Tax Rate）：24.5%（來源：2025 10-K 財報腳註）。
- **計算結果**：
  - 下限（$4.32 億）：稅前每股衝擊 = $\$432,000,000 \div 63,600,000 = \$6.79$ 美元/股。稅後 EPS 衝擊 = $\$6.79 \times (1 - 0.245) = \mathbf{-\$5.13}$ **美元/股**。
  - 上限（$4.80 億）：稅前每股衝擊 = $\$480,000,000 \div 63,600,000 = \$7.55$ 美元/股。稅後 EPS 衝擊 = $\$7.55 \times (1 - 0.245) = \mathbf{-\$5.70}$ **美元/股**。

### 4.2 未來 3 年 EPS 預估算式與邏輯拆解
- **2026 FY EPS 預估 ($22.97)**：
  - 算式：$\text{Q1/Q2 實績 EPS } (\$11.63) + \text{Q3/Q4 預估 EPS } (\$11.34) = \$22.97$。
  - 假設：公司官方下修後 Guidance 區間 $22.28–$23.65 之取中位數。
- **2027 FY EPS 預估 ($25.28)**：
  - 算式：$\text{2026 EPS } (\$22.97) \times (1 + \text{本業淨利成長率 } 6.2\%) \div (1 - \text{庫藏股註銷率 } 3.6\%) = \$25.28$。
  - 假設：參考華爾街最新共識，Medicare IPPS 給付調升 2.4% 帶動營收，華盛頓特區新院虧損止蝕，庫藏股買回註銷使股數降至約 6,130 萬股。
- **2028 FY EPS 預估 ($26.43)**：
  - 算式：$\text{2027 EPS } (\$25.28) \times (1 + \text{本業成長 } 8.0\%) - \text{OBBBA 首年衝擊 } (\$1.15) + \text{庫藏股效益 } (\$0.95) \approx \$26.43$。
  - 假設：參考華爾街最新共識，OBBBA 於 2028 開始實施第一階段（約總衝擊量之 20%），被強勁的行為健康部門營收成長與持續庫藏股註銷所抵銷。

### 4.3 財務絕對金額每股化及比率算式
- **2025 年主要財務指標每股化（基期流通股數 6,360 萬股）**：
  - 營業收入：158.4 億美元 $\div 6,360 \text{ 萬股} = \mathbf{\$249.06 \text{ 美元/股}}$。
  - 營業利益：20.3 億美元 $\div 6,360 \text{ 萬股} = \mathbf{\$31.92 \text{ 美元/股}}$。
  - 資本支出（CapEx）：8.5 億美元 $\div 6,360 \text{ 萬股} = \mathbf{\$13.36 \text{ 美元/股}}$。
  - 自由現金流（FCF）：11.2 億美元 $\div 6,360 \text{ 萬股} = \mathbf{\$17.61 \text{ 美元/股}}$。
- **負債比率**：
  $$\text{負債比率} = \frac{\text{總負債}}{\text{總資產}} \times 100\% = \frac{\$8,189,200,000 (\$128.75/\text{股})}{\$15,530,400,000 (\$244.18/\text{股})} \times 100\% = \mathbf{52.73\%}$$
- **OPM（自訂：營業利益率 / 稅前淨利率）**：
  $$\text{OPM} = \frac{\text{營業利益率}}{\text{稅前淨利率}} \times 100\% = \frac{12.83\%}{12.69\%} \times 100\% = \mathbf{101.10\%}$$

## 7. 名詞對照表（Glossary）

| 術語 / 縮寫 | 全名 / 原文 | 一句白話解釋 |
| :--- | :--- | :--- |
| **OBBBA** | One Big Beautiful Bill Act（大而美法案） | 美國 2025 年 7 月簽署的預算調解法案，包含稅改常態化與削減 Medicaid 政府醫療補助上限。 |
| **Medicaid** | Medicaid（美國醫療補助計畫） | 美國聯邦與州政府共同出資、資助低收入戶與特定弱勢族群的醫療保險制度。 |
| **SDP** | State-Directed Payments（州定向給付） | 州政府透過特定機制向醫院提供額外 Medicaid 補助款，以彌補醫療成本與保險給付差額。 |
| **Provider Tax** | Provider Tax（醫療提供者稅） | 州政府向醫院課徵的特定稅捐，用以套取聯邦政府同比例的 Medicaid 匹配補助資金。 |
| **IPPS** | Inpatient Prospective Payment System（住院預估支付制度） | 美國 Medicare 針對醫院住院服務的年度定額給付制度，每年由 CMS 調整給付比率。 |
| **CMS** | Centers for Medicare & Medicaid Services（聯邦醫療保險與醫療補助服務中心） | 美國聯邦政府負責管理 Medicare 與 Medicaid 制度的主管機關。 |
| **Forward EPS** | Forward Earnings Per Share（預估每股盈餘） | 市場法人或公司官方預估未來特定年度（如 2026/2027 年）每股能賺到的淨利潤。 |
| **OPM** | Operating Margin / Pre-tax Margin Ratio（自訂營業利潤比率） | 本報告自訂公式：`營業利益率 ÷ 稅前淨利率 * 100%`，用以評估利息支出對利潤的侵蝕程度。 |
| **ROE** | Return on Equity（股東權益報酬率） | 公司拿股東投資的錢能創造多少淨利潤的效率指標，`淨利 ÷ 股東權益 * 100%`。 |
| **10-K / 10-Q** | SEC Form 10-K / 10-Q（美股年報 / 季報） | 美國上市公司依法向證券交易委員會（SEC）定期申報的年度（10-K）與季度（10-Q）財務報告。 |
