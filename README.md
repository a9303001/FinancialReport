## 📌 研究重點與流程
每次進行個股基本面分析時，均會遵循以下基本架構，以確保研究品質：
1. **主要產品和服務** 與 **市佔率/競爭對手**。
2. **護城河分析**。
3. **成長潛力與未來展望**。
4. **風險因素和挑戰**。
5. **重要財務指標每股化**（如每股營收、每股自由現金流等，以便跨期比較）。
6. **社群與論壇輿情收集**（PTT, Dcard, Yahoo Finance, Reddit, 雪球等）。
