## 附錄 A：白話名詞表
| 名詞 | 白話 |
|---|---|
| 分派（DPU） | 每一個基金單位發給投資人的錢，香港 REIT 通常一年發 2 次 |
| NPI | 租金收入扣掉物業直接經營開支，是房託分派的源頭現金流 |
| 可分派收入 | 扣除物業公平值重估變動等非現金項目後，實際能拿來發錢的收入 |
| P/NAV | 股價 ÷ 每單位資產淨值；< 1 代表市價比獨立估值師評定的物業淨值便宜 |
| 槓桿比率 | 借款總額 ÷ 資產總值；香港證監會法定上限為 50%，高於 45% 警戒 |
| HIBOR | 香港銀行同業拆息，浮息港元借款利率之定價基準 |
| 續租租金調整 | 舊租約到期換約續租時，新租金相較舊租金的升跌幅度 |
